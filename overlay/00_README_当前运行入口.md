# 观察研究长程覆层入口

本覆层负责身份、准确来源、派发、回交、去重和合法续作。专业内容取本次配置、真实任务和 `source_reads`，不在运行层重复定义。[professional](../../professional/README.md) 是当前导航。

协调者日常入口为 [08](08_自然语言运行提示_v0.3.md)，机械校验见 [12](12_管理接收与地图校验.md)，回交接续见 [13](13_角色回交与主控接续协议.md)。管理与专业角色按实际职责读取 [DR00](../dual_route_execution/DR00_START_HERE.md)，Worker 按原签发 Pro 的技术工单执行，不因工具成功自行裁决业务。

新方法准备、启动及旧运行隔离见 [运行指南](../operations/CASE_OBSERVATION_RUN_GUIDE.md)；当前是否存在真实采用关系见 [ADOPTION_STATUS](../config/ADOPTION_STATUS.md) 和该 run 记录。本入口不维护另一份 GO/进度，也不把历史 release 包或旧任务当作当前默认要求。
