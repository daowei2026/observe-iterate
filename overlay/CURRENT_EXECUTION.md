# 长程覆层的当前采用入口

本层只处理运行。当前专业方法由本次锁定的 `runtime/config/COORDINATOR_DISPATCH.json`、真实 task/binding 与 `source_reads` 给出；候选导航见 [professional/CURRENT_EXECUTION.md](../../professional/CURRENT_EXECUTION.md)。

操作端依 [08](08_自然语言运行提示_v0.3.md)、[12](12_管理接收与地图校验.md)、[13](13_角色回交与主控接续协议.md) 办理身份、运输和合法接续，不临时编业务目标或新前置。

[ADOPTION_STATUS](../config/ADOPTION_STATUS.md) 说明本分支准备边界；实际运行进度只取相应 run 的准确记录。新方法发布不改变旧 run 授权、在途、已发字节或已接收结果。没有真实新 GO 和管理采用，不启动本批。
