## BI01

完整目标是利用既有大／中／小尺度贴近点及其关系，逐步形成可验证的前瞻选择认识：在当时可知的信息下识别哪些品种更值得继续观察、目标是哪种后续市场过程，并允许诚实结论为“没有可靠候选”。

当前正式任务 `BI-01-CO-04-CASE-INITIAL-ASOF` 先取得一个可消费的 as-of 多品种判断循环，同时检查最近的自然挑战、失败候选或合法无候选。任务 mode 为 `CASE_OBSERVATION`。它不是固定方法发布，也不是单图试跑。

管理采用、独立 Reader、实际派发、专业提交、独立专业审查、管理接收及 Owner 反馈分别记录。当前 Workmap Reader 状态在 Intake 中按事实保存；未记录完成前不宣称 dispatch preflight 已通过。
