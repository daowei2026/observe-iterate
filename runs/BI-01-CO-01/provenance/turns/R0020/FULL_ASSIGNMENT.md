# 多品种差异用例研究：目标、产出与边界

## 1. 最外层意图

让 AI 逐渐能够像投资者一样观察多个品种，研究如何依据此前信息，提前区分哪些品种的后续运动可能相对较好、哪些可能较差。事后识别差异和回看历史是为这一目的服务的；不能以已经发生的路径描述替代辨别依据与逻辑的研究。

当前从偏单边走式的品种选择角度开始，例如持续推进与反复回吐、小尺度反复是否破坏主方向、成员先强后弱等。这些是帮助理解意图的例子，不是固定分类、必选题目或预先指定赢家。

U2/U3 为这一业务范围提供已有抽象、词汇和设计参考，不是所有观察必须依次走完的处理流水线。当前目标不是验收完整 U2/U3，也不是直接形成交易指令、盈利策略或普遍预测结论。

## 2. 本批范围

一次研究 **3–5 个有差别的用例**，每例从开始就是多个品种共同观察。优先选择在相近或可合理对照的市场情境中有明显好坏分化的位置，而不是先选单品种赢家再补陪衬。

“有差别”意味着本批能给 Owner 多一些实际观察信息；不能把同一段行情稍微移动边界就凑成多例。不要求先建立分类学、每类配额、统一评分或用例间依赖关系。几个都好或几个都差不是本批主要研究对象，暂不扩成另一套验证工程。

数据 **必须通过 aidata 的正式接口及交付取得**。起步用完整可用历史范围的多品种 1d 数据找位置；选中用例后提供 1d 概览与各例 30min 大尺度图及对应数据。实际品种、历史范围、数据上下文在真实任务与调用中明确；不得把讨论中的示例日期或旧 ZIP 自动当作本批输入。

## 3. 产出一：具体多品种差异用例

每例须交出以下能被下一步直接使用的实物内容，不以“已扫描”“已发现”代替：

| 内容 | 要回答的问题 |
| --- | --- |
| 位置与对象 | 具体品种、主要差异时段、必要的关键日期/位置在哪里？ |
| 对照事实 | 每个品种怎样运动，彼此共同点和差别是什么，差别怎样发展？ |
| 业务价值 | 为什么这一差别值得从品种选择、有利/不利条件角度研究？不能只列最终涨跌幅。 |
| 图数定位 | 用例 ID、aidata run/node、数据文件和统一平台页面内的图标题/位置怎样对应？ |
| 研究问题 | 希望向此前追问哪一项具体差异？哪些只是事后已知结果？ |

用例的核心差异区间、展示的前后留量范围、实际回看的信息范围分别记录。三者不必相同，也不由统一固定长度代替。

产出一成立，不意味着已经证明当时应当选择某品种；它只是准确交出了值得研究的市场对照。

## 4. 产出二：该例的提前辨别逻辑研究

从投资者视角自主研究此前信息，形成**业务范围明确、主干基本完整、合理且可返回行情核对的初始业务用例**，包含对尚未知后续的有依据的条件性辨别。以已有 U3 人读叙事为主要表达参照，但更贴近本例真实市场情境。成果应独立讲清市场情境、关系、变化及希望形成的业务认识，供阅读、反馈与后续按需复用；本轮不提前承担完整处理过程、WMF 选型、算法、控制器、参数或 Fao 设计，也不以未来可能使用为理由在本任务内启动其他工作。

### 4.1 初始业务用例正文

正文应当正面、连续地讲清业务，而不以日期点对、排名、冲突辨析或限制声明作为整个故事。初版可以限定范围，但下列主要含义不能由后续细化者自行猜测；这是内容要求，不是固定步骤、章节模板或市场模式：

| 内容 | 需要讲清的业务含义 |
| --- | --- |
| 情境与运动过程 | 正在研究什么市场情境、哪类或哪一轮运动，“此前”“本轮”“下一次”各指什么，局部运动与较大过程怎样关联。大拐头只是可能背景，不统一指定；计算边界可待细化，业务所指不能缺失。 |
| 多品种关系及演变 | 在什么属性、过程和比较语境下，哪些对象表现出接近、共同性、差异或分化；有依据时形成怎样的关系组、组内外差别及成员变化，这些关系怎样参与业务理解。不以逐品种打分、排名或关注顺序代替网络叙事，也不将排名领先者直接改称“核心”。 |
| 条件性辨别 | 此前哪些事实和关系支持对尚未知后续的不同倾向，必要条件是什么，什么变化会改变这项认识；不只说“此前较好，未来可能较好”，也不强求成功预测、唯一赢家或因果机制。 |
| 预期业务认识与用途 | 希望以后持续取得什么业务表达，哪些重要差别及变化应被保留，结果怎样帮助品种比较并返回原用例观察。说明结果要表达什么，不要求此时定字段、公式、图形或实现结构。 |

多品种关系优先使用 [04](04_SOURCES_AND_REUSE.md) 的已有网络业务语义。接近须说明接近的方面；关系、组形成、组自身质量和组外差距不能混成一个排名。按本例实际需要使用，不强迫每例成组、使用全部词汇、画网络图或先运行正式 U2/U3。

“原行情能核对故事依据”与“以后特征结果要表达这项业务认识”是两个不同问题，均不能只由一个平台链接或几句形容词代替。初始用例应让后续知道细化什么，而不要求现在把方法都定完。

### 4.2 研究依据与观察迭代材料

与主要正文分开组织，保存实际回看的位置、品种、尺度及选择理由，准确日期、原价、计算、信息可知时间、支持与反证、竞争解释、失败记录和当前未决问题；已识别的后续观察重点可一并保留。不要求穷尽所有反例、建立完整测试库或验证普遍预测能力才允许初版向后推进。已有原件准确引用，不重复复制，不删去正确事实。

**分用途，不分断联系。** 业务判断自身必需的条件、支持和反对关系仍属于正文；某个历史检验怎样失败、原句怎样被修订及未来如何继续检查，主要放在配套材料。已明确推翻当前主张的事实必须纠正正文，不能借“留待下轮观察”维持错误；只是不确定或尚未完成泛化验证的部分，保留候选强度及必要边界，不反复打断叙事。后续消费者采用正文时须同时取得与该采用直接相关的依据和限制。

事实与推断应对应，不以结果证明结果；实际点、确认时间和当时可知信息分清，不能等后续形成后才把结果称作提前辨别，也不要求给出最早 T。主要依据及相互关系在所交图的适当范围/缩放下应相对明确，仅靠数字表或难分辨的细小差异不算图上清楚；非图上直接可见的信息注明来源和作用。

认真研究后仍不能区分、只能部分解释或有多个解释，均可如实交出实际尝试和具体缺口；不能用“不确定”代替能做的工作，也不能把业务主体仍缺失的材料称为合格初版。图形相关、同步或先后本身不证明驱动因果；过去质量好也不自动证明未来风险小。研究角度、参照、窗口和方法仍由专业者选择，需要补数时沿 aidata 取得，不预设某种解释必然成立。
