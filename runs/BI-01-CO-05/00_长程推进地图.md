# BI-01-CO-05 长程推进地图

<a id="goal"></a>
## 1. 完整目标

最终投资目的，是基于既有特征表达的对象、衍生对象、属性及多对象关系，发现市场运动中的现象和候选规律，并在后续尚未知时帮助判断哪些品种可能走势更好、机会更大、反向风险更小；也允许诚实得出暂时没有足够好候选。

本 Run 的直接目标不是重新选择一项容易验证的预测题，也不是把一次脚本、图页或技术调用变成方法通过，而是通过多轮真实专业实践检验并迭代 Owner 的初版用例形成方式：明确特征范围；沿当时可知信息向前观察大尺度背景怎样形成、改变和失效；检查其中是否有足够的中尺度结构；在具体背景内形成、挑战并更新初版用例和前瞻判断；把所得业务认识与过程反馈交回管理和 Owner。

权威来源见 [Owner GO](OWNER_START.md)、[最终投资目的](../../professional/exploration/00_BUSINESS_OBJECTIVE.md)、[当前探索目标](../../professional/exploration/06_EXPLORATION_STAGE_GOAL.md)、[Owner 完整过程](../../professional/exploration/05_OWNER_PROCESS_EXPLANATION.md)及[Owner 全段时间纠正](OWNER_CHANGE_20261102_R0005_TIME_COVERAGE.md)。

## 5. 全部重要剩余

1. **一次性条件重入工单**：原 Professional 按 R0010 既定内容签新 order，不重新设计图数、不重做来源调查。
2. **合法派发与低成本探针**：控制器在 exact commit 机械校验后派发；Worker 在同一目标身份先 `open/read` 精确日历文件，记录时间、字节、SHA-256、exit/stderr、mount source 和无替代来源。
3. **条件全段执行**：探针通过即在同一 Worker 执行中从头运行 R0008 原脚本一次，fresh dynamic run_id；探针失败则在昂贵调用前停止，且不再签第三个同路径工单。
4. **正式图数与覆盖**：成功时实际开全段主图和七个辅助图，读取 manifest/index/KLine/large/mid，核图数同 run/core、实际首末、缺失、重复、warm-up 与哈希。
5. **证据资格**：原 Professional 核字段层级、方向来源、无方向点、actual/confirm/event/revision、日历和当前发展部分。
6. **完整第一层实践**：沿信息到达顺序找至少一段可解释的大尺度背景形成—变化过程，或用真实证据说明为何不能形成；同时判断中尺度结构何时足够。
7. **第二层业务形成**：在有价值背景内定位中尺度对象，形成具体用例/候选规律，提出截至 T 的后续判断或有证据的无候选，并随新信息更新。
8. **挑战和反证**：检查确认滞后、阶段错位、短后续空间、反向负担、邻近失败和替代解释，不只保留成功片段。
9. **过程反馈**：逐项说明 Owner 初版过程哪些已实际使用、哪些有用、哪些受市场/特征/工具/方法限制，给出保留、局部修改、待证或需 Owner 决定的建议。
10. **失败分支决定**：若同路径探针再次失败，Management 不再重复 Worker，决定以环境成本终止当前 Case，或向 Owner 明示提出改变 calendar source/正式入口的方案及影响。
11. **管理消费**：核首个真实业务包的价值、证据资格与方法反馈，决定 same-work、下一问题、Reviewer、Owner 校准或停止。
12. **长程收拢**：多轮真实实践后才判断是否形成稳定方法、规范、Agent 或评分器；当前不提前固化。
