# BI-01-CO-05 长程推进地图

<a id="goal"></a>
## 1. 完整目标

最终投资目的，是基于既有特征表达的对象、衍生对象、属性及多对象关系，发现市场运动中的现象和候选规律，并在后续尚未知时帮助判断哪些品种可能走势更好、机会更大、反向风险更小；也允许诚实得出暂时没有足够好候选。

本 Run 的直接目标不是重新挑选一项容易验证的预测题，也不是把一次画图变成方法通过，而是通过真实专业实践检验并迭代 Owner 的初版用例形成方式：明确特征范围；沿当时可知信息向前观察大尺度背景怎样形成、改变和失效；检查其中是否有足够的中尺度结构；在具体背景内形成、挑战并更新初版用例和前瞻判断；把所得业务认识与过程反馈交回管理和 Owner。

权威来源见 [Owner GO](OWNER_START.md)、[最终投资目的](../../professional/exploration/00_BUSINESS_OBJECTIVE.md)、[当前探索目标](../../professional/exploration/06_EXPLORATION_STAGE_GOAL.md)及[Owner 完整过程](../../professional/exploration/05_OWNER_PROCESS_EXPLANATION.md)。

## 5. 全部重要剩余

1. **真实输入与证据资格**：Professional 选择最低成本且真正适配的实际输入，取得图与正式数据，记录来源、参数、覆盖、对象字段和时间语义；已完成绘图实践只在适用时复用。
2. **完整第一层实践**：沿信息到达顺序找至少一段可解释的多品种大尺度背景形成—变化过程，或用真实证据说明当前输入下为何找不到；同时判断这种背景的可辨认性、常见困难与中尺度结构是否足够。
3. **第二层业务形成**：在有价值背景内定位实际中尺度对象，形成一个或多个具体用例/候选规律，提出截至 T 的后续判断或无候选，并随新信息更新。
4. **挑战和反证**：检查最近自然挑战、失败候选、替代解释或不适用区间，不只保留成功片段。
5. **过程反馈**：逐项说明 Owner 初版过程哪些实际使用、哪些有用、哪些受市场/特征/工具/方法限制，给出保留、局部修改或替代建议。
6. **管理消费**：核专业结果的业务价值、证据资格与方法反馈，决定同工作续作、下一具名问题、独立业务审查、Owner 校准或停止。
7. **长程收拢**：多轮真实实践后才判断是否形成稳定方法、规范或 Agent；当前不提前建立评分器、全市场分类或重型回放基础设施。

## 6. 管理决定与优先级

### 当前优先级

1. 先取得真实市场观察和用例形成过程；
2. 只补直接阻断上述观察的具体数据、制图或字段核验缺口；
3. 首个可消费实践包到达后立即管理复看，不为了填满预算继续加厚；
4. 重要候选规律或方法变更出现后，再决定独立业务 Reviewer 或 Owner 校准。

### 已明确处置

- 不沿用 CO-04 的固定 query snapshot、固定 T、rb/hc/i 或其 `as-of` 合同；这些不是当前任务。
- 不把 1d 概览、30m、三品种、small/mid/big 参数或既有页面设为默认；实际需要由本 Run 输入决定。
- 不把全面 native first-seen/revision 回放工程设为全部观察前置；能合法重建到何种 as-of 范围就只在该范围主张，缺口精确限制受影响结论。
- 不预签 Worker，不先做全仓审计，不建第二套当前任务/进度系统。
- 首次 Workmap Reader 不派；首个业务 Reviewer 也暂不派，因为尚无具体专业主张可审。
- Professional 仍承担当前任务完整范围；首个 Case/图/局部修通不是主动停点。
