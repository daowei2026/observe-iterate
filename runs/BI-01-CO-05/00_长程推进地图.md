# BI-01-CO-05 长程推进地图

<a id="goal"></a>
## 1. 完整目标

最终投资目的，是基于既有特征表达的对象、衍生对象、属性及多对象关系，发现市场运动中的现象和候选规律，并在后续尚未知时帮助判断哪些品种可能走势更好、机会更大、反向风险更小；也允许诚实得出暂时没有足够好候选。

本 Run 的直接目标不是重新挑选一项容易验证的预测题，也不是把一次画图或脚本通过变成方法通过，而是通过真实专业实践检验并迭代 Owner 的初版用例形成方式：明确特征范围；沿当时可知信息向前观察大尺度背景怎样形成、改变和失效；检查其中是否有足够的中尺度结构；在具体背景内形成、挑战并更新初版用例和前瞻判断；把所得业务认识与过程反馈交回管理和 Owner。

权威来源见 [Owner GO](OWNER_START.md)、[最终投资目的](../../professional/exploration/00_BUSINESS_OBJECTIVE.md)、[当前探索目标](../../professional/exploration/06_EXPLORATION_STAGE_GOAL.md)、[Owner 完整过程](../../professional/exploration/05_OWNER_PROCESS_EXPLANATION.md)及[Owner 时间覆盖纠正](OWNER_CHANGE_20261102_R0005_TIME_COVERAGE.md)。

## 5. 全部重要剩余

1. **全段可执行输入**：原 Professional 用 Owner 固定全段范围提交新脚本和新正式 Worker 工单；保留当前对象/频率/特征/Context，具体决定全段主图可读配置和必要辅助分段。
2. **合法技术执行**：控制器对新工单 exact commit 机械校验并真实派发；Worker 在固定环境执行、普通兼容修通、实际开图和读取正式数据，结果回原 Professional。
3. **证据资格**：核真实 run/core、manifest/FILE_INDEX、全段/实际有效覆盖、图数同身份、日历、方向来源、actual/confirm/event/revision、重复/缺失和当前发展部分。
4. **完整第一层实践**：沿信息到达顺序找至少一段可解释的大尺度背景形成—变化过程，或用真实证据说明为何不能形成；同时判断常见困难与中尺度结构何时足够。
5. **第二层业务形成**：在有价值背景内定位中尺度对象，形成具体用例/候选规律，提出截至 T 的后续判断或有证据的无候选，并随新信息更新。
6. **挑战和反证**：检查最近自然挑战、失败候选、阶段错位、替代解释或不适用区间，不只保留成功片段。
7. **过程反馈**：逐项说明 Owner 初版过程哪些已实际使用、哪些有用、哪些受市场/特征/工具/方法限制，给出保留、局部修改、待证或需要 Owner 决定的建议。
8. **管理消费**：核首个真实业务包的业务价值、证据资格与方法反馈，决定 same-work、下一问题、Reviewer、Owner 校准或停止。
9. **长程收拢**：多轮真实实践后才判断是否形成稳定方法、规范或 Agent；当前不提前建立评分器、全市场分类或重型回放基础设施。
