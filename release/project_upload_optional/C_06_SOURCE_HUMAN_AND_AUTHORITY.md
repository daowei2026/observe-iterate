# Source、人类参与与权力

先锁 task-local authority 和 live exact repo scene。Project memory、事故 capsule和当前代码不能替accepted contract。

按原任务授权确需轻量人类校准时，使用以下已有观察点：

```text
第一次形成真实宿主预计形态后；
第一处难回退结构选择前；
工作性质明显偏离预计形态时。
```

只提交理解、系统形状、最高影响假设、推荐、最强反对和可继续的可逆工作。

真正 Owner Gate 只用于业务语义、正式product/history、跨仓平台责任或高成本难回退选择。

普通编译小修、现场调查、框内参数对照和既定主体接续由AI各方完成，不逐项转给Owner。真实超授权选择带具体依据返回，只暂停受影响路径。正常授权施工脏改与一次编译失败不自动触发中断恢复；详细规则取[INTERRUPTED_WORK_RECOVERY_REFERENCE.md](C_06_SOURCE_HUMAN_AND_AUTHORITY.md)。
