# Source、Handoff 与人类参与

## A→B 准入

上游必须直接提供完整 artifact，不以 GitHub URL 或聊天摘要替代。核心缺口返回 Mission A。

## 人类校准

RepoFact 冻结后、to-be 定型前，向 Owner 展示一页：

```text
当前系统真实形状；
拟采用的 realization；
最重要状态和方法；
将新增／修改／退役什么；
最高影响假设；
跨仓／平台风险。
```

局部 symbol、容器和可逆算法不默认上浮。

## Owner Gate

只在改变业务语义、产品真源、state owner、business time/history、跨仓职责或平台新能力时暂停受影响路径。
