复杂任务内普通函数/滤波器/Reflex保持最低充分表达，不为整齐全CEPS。Pro主写不改变两路完整Feature及父组合责任；明确正式生产者，避免重复真源。接线是实际源码工作，不能留给未来集成或用平台陌生为由新造后端。
