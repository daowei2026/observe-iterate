# 观察研究长程执行入口：角色分工、专业来源与管理接收

本层沿用 DR/Overlay 通用运行语义。专业内容由本次有权任务与准确方法来源提供，候选材料或结构测试不证明现场运行。当前准备及采用见 [运行指南](../operations/CASE_OBSERVATION_RUN_GUIDE.md) 和 [采用状态](../config/ADOPTION_STATUS.md)。

**协调者只走 [Overlay08](../overlay/08_自然语言运行提示_v0.3.md)。** 普通专业者走下面相应角色方法；两者不合并为一套必读负担。固定运行规则、模板与选源由 repo 维护，协调者不判业务，业务聊天不重编控制面。

| 角色 | 共同入口 | 完整方法 |
| --- | --- | --- |
| 专业执行 Pro | DR12、DR13 和当前 Binding | 本次 source_reads 指定的完整专业方法及实际 Source/Method |
| Worker Codex | DR03/DR10/DR11 的适用委派规则 | 原 Pro 技术工单、数据/源码/工具及写权；无工单不自动授权 |
| 管理 Pro | DR06/DR08、DR13 管理题、管理 Harness | 本次完整目标、实际进展与重要未完 |
| 独立审查 Pro | Overlay10/13、实际审查委派 | 具名 exact 被审对象和有资格方法；未形成不能宣称 PASS |

[DR12](DR12_PROFESSIONAL_QUESTION_CATALOG.md)只定位方法，DR13 负责工作联动/读取/管理题，DR14 负责绑定/回交/触发。题号不授 mode 或写权，不要求题数等于轮数。首次/新上下文/失效取必要全文，已读未变且仍可用则复用，题面不替方法。

新旧专业任务由其自己的 goal_ref、task 和 source_reads 区分。不在本文件预定特征、数据 ZIP、工作项数量、观察尺度或业务顺序。普通内部步骤不机械增加管理 Gate；任务明确的跨工作依赖仍需真实交付和相应认可。

管理以最快有效完成完整目标为责，旧计划/候选/自己旧结论都需核适用；局部进展不证明投入合理。及时采用合理首版、停止无当前价值深化，保留必需主体/真实验证，更新同一终点的预测、地图和实际后继。具体方式不强制问卷、评分、方案数或逐项轮数。

普通承办者交完整分析/产物/证据和原任务内接续，不维护公共图和全局预算；专业分析成果仍属原执行 Pro。提示已归档只引用。管理与审查兼任分别完成，参与形成不能自称 fresh。独立审查/Owner 实际权限/跨仓保护保持。

主续作、已签独立接收与到期非阻塞管理分别保留；一项继续不能覆盖另一项。管理条件预先明确，采用 `WHILE_WORK_ACTIVE` 的既定投入间隔在工作 ACTIVE 时持续有效，运行端核真实事实、按段去重和派发，不临场判业务重要性或重选预算。UNKNOWN 不能当未触发，回交报告存在不等于决定已消费；暂停、合法交接或完整接收后停止循环，既有未受影响工作继续。

工具核结构/来源/载荷，不证明授权、语义或实际送达。旧 gate 冲突具名处理，不全局绕过。业务源码、build、真实数据依相应实际任务，最短诚实正式链后早反馈。规范修改同步导航，生成视图回规范根，不造平行真源，旧 seal 不证明新版本。
