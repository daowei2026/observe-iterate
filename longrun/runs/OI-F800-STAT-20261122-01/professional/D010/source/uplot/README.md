## [1.0.0] - 2023-10-20
### Init
- 项目初始化
- 支持使用特征和特征别名定义CAE图，特征和特征别名的用法和时序特征一致
- 目前支持了的特征：
  - # 用于表达画图特征字段信息的特征 
    - OneFieldPlot:指定要画的单个特征字段及相关画图属性
    - MulFieldsPlot:指定要画的多个特征字段及相关画图属性
    - OneFieldMulSymPlot:指定要画的多个特征字段及相关画图属性中,多个特征来源为单个特征的多品种的形式
    - MainFig:指定主图的K线信息
    - Mulfigs:指定要画的多个图的多个特征字段及相关画图属性   
        - # todo:1.解决多个图的图名一致的bug;2.进一步包装简化用户表达,用户不直接使用lamdba函数
    - 另外,支持了`BasePlotter`的所有子类(也就是上述所有特征)之间进行“+”操作  
  - # CAE图特征:CAEGraph
