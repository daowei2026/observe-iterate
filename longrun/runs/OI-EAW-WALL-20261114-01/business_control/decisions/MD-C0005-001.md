## 4. 限域冻结预期｜`EV-WALL-LEGACY-NORMAL-v1.0`

### 4.1 冻结身份

- `expectation_version`：`EV-WALL-LEGACY-NORMAL-v1.0`

### 4.2 适用范围

只适用于：

```text
historical legacy material

exact upstream artifact + exact legacy product leaf
wall_local_no = 1
UTI = 72335299, 72335302, 72335308

```

不适用于 current canonical runtime、跨 artifact 身份、Dormant/恢复、active map、diagnostic identity、duplicate/conflict、same-firing transaction、End 后同号事件、late/out-of-order 或完整 suitability。

### 4.3 冻结命题

#### `FN-IDENTITY-01`｜artifact-scoped identity continuity

在同一 exact feature artifact/run namespace 内，连续 occurrence 的 local number、ref 和 UTI 应能无歧义指向 producer 已认出的同一 Wall；不得把裸 local number 跨 artifact 连接。

- 可反驳条件：样本无法在 exact artifact 内连续连接，或出现相同标识对应不同 Wall 且无修订/冲突合同。

#### `FN-START-01`｜normal Start publication

正常生命周期由 `Start Present` 建立；被接受的 Start 应在同一 writer firing 中具有可追溯 occurrence Start 和 current Present update。

- 可反驳条件：接受的 normal Start 缺 O 或 C，或状态/身份不一致。

#### `FN-BAND-01`｜nontrivial BandUpdate continuity

同一 Wall 的非平凡 BandUpdate 应保持 identity 和 presence，同时更新 band/core；被接受的更新应在同一 writer firing 中具有可追溯 occurrence BandUpdate 和 current Present update。

- 可反驳条件：identity/presence 无合同改变、band/core 未反映变化，或 O/C 无法对账。

#### `FN-END-01`｜normal End publication

正常 End 应在同一 writer firing 中具有可追溯 occurrence End 和 current Ended update。

- 可反驳条件：End 被接受但缺 O 或 C、identity/time 无法对账，或 current 状态不是 Ended。
- 明确排除：本命题不声称 FRP active map 已被物理观察删除，也不声称 End 后同号行为合理。

### 4.4 固定比较解释规则

- `wall_current_view` 在本轮按 update/delta rows 解释，不按全量快照解释；
- 缺行不得补造成“状态未变”；
- current source只能作为静态解释上下文，不得绑定为 legacy product generation version；
- End occurrence 的 `0 + not_present` 不得解释为真实价格 0；必要时回源 producer evidence；
- 四条命题逐条使用 `SUPPORTS / COUNTERS / MISSING / AMBIGUOUS / NOT_APPLICABLE / PENDING`，不以总体分数替代。

冻结后若要改变命题、范围或解释规则，必须建立新版本，不能无痕修改 `v1.0`。
