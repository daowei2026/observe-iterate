## 3. 现有联合材料能恢复什么

核对的是 C0002 已验证版本的 Wall、Build、Absorb、Segment、Formation、Barrier 与相关历史，没有假定四类特征按固定顺序发生或消费彼此。使用每个完成的 producer tick 的 occurrence 切点；这不是实际 FRP publication 时间认证。

Build 的匹配源码直接取启动时该 Wall 侧的 `best_vol_t` 为 `baseline_vol`，后续 ratio 是累计 reload proxy/基准。源码没有把该基准定义为之后每个切点的核心价库存。因此 N2-01/02/05 的“同 Wall、另一个最佳价基准”符合实际度量语义；本次未证实实现错误。

Absorb 的实际公开补充代理为 `P=max(R+C−I,0)`，I 为启动可见量，C 为累计 hit/consumed proxy，R 为**方法口径** visible_remaining：

- 当前 Milestone 的 ratio 或 Resolved 的 consumed_ratio_proxy 为正时，可由 C/ratio 恢复 I；缺少该比率但原窗口含 track 起点时，可用起点 L1 核对 I。这两种依据分开记录。
- P>0 且 I 已知时，R=P+I−C 是等式。4,526 条正式 occurrence 中，2,080 条属此代数情形；其中 2,076 条有当前有效 L1 可核对，全部与方法余量相符。2,076 中仅 1,990 条 tracked price 当前可见，另 86 条是离档后的方法零值，不能称旧价真实库存为零。当前正式 ratio 即可恢复且仍可见的有 1,384 条；其余部分需要原起点 L1。
- P=0 且 I 已知时，只能得 0≤R≤I−C，不能一律用 R=I−C。2,439 条可核对记录均满足上界，其中 642 条截零前残差严格为负，179 条仍在 tracked price 可见，涉及 109 个 track；这 179 条中 120 条仅用当前正式 ratio 就知道 I。三品种实例：rb 的 I=1737/C=500/P=0，实际 R=1176 而等式误反算 1237；hc 为 686/3/0，R=674 而非 683；i 为 687/669/0，R=13 而非 18。
- 7 条缺少可恢复的 I，保持 unknown。源码在离档时将方法 R 置零，私有 visible_min 也可能因此变为零；不能直接将其包装成“实际旧价最薄量”。截零前负残差更不是真实净撤单或独立方向真值。

对 867 次复见，专门核了“复见当 tick 有 Build Start 基准”和“复见当 tick Absorb 正 P 且 I 已知”两种具体恢复：前者 0，后者 8，其中 5 可只用当前正式 ratio，3 需原起点 L1。127 次明显退薄复见中未出现这两种当切点恢复。这**只说明所测方法的覆盖**，不证明穷尽所有潜在联合推导，也不说明其余正式材料没有业务信息。已有 L1 直接恢复可见量，不必等待全部 FRP/P2 材料。

## 4. 设计位置与最小信息试查

针对“当前防守条件”的问题，若仅凭 Wall 存续、Build 活动或旧接触量去回答，首先受限的是量的角色与稀疏属性语义；没有证据说原行情在接触时不可观测。离开 L1 最佳价后的旧价量则本来不可见，必须记 unknown。加入已有同批 L1 后，当前可见切点的问题可恢复，所以本次**不提交 P1 必增字段或新事件要求**。实际消费者在哪一层丢了该信息仍未取证；这里提出的是有业务依据的上层组合需求。

N2 的最小设计输入：以 exact Wall 身份、侧、核心价和完成的 source 切点为关联键，组合 `current_visible_quantity` 与 `visibility_state`。同价可见时取该侧 L1；离档或无有效 quote 时量为空并保留可见状态。旧接触量与 Build/Absorb 活动属性各自保留其参考时点、价位和量义，不冒充当前量。对 Absorb 代数恢复需标明“等式/上界/未知”的条件，不用代理量补成真实消耗或撤减。当前探针是独立研究表，没有设计完整算法或改变生产接口。

在六深入 PG 之外，按预先保存的哈希规则每 PG 选一条、共 18 PG/18 对，每对读上次接触、首次离档和复见三个切点，共 54 行。baseline 为明确构造的“保留旧量”读法，不是实际 P2 产品。补两字段后，18 个离档行均记量为空，18 个复见行均取当前原 L1 的量；18 对都有数值变化，但其中 12 对仍在旧量 ±10% 内。因此不能以“18/18 不相等”冒充 18 次严重误读或实际改进率。

这是同批探索性追加，全部候选曾在本次扫描中暴露；不宣称严格样本外或盲测。试查表明既有信息足以在这些切点区分 unknown、骤薄、增大和近似不变。稀疏化成本尚未测量；可优先做按需读口关联，是否值得物化少量关键点由实际消费者场景和成本决定，不能从 867 次复见直接推出生产事件量。

N2 与 N1 分开：N1 解决业务区间/闭合/Formation 可得时钟的展示投影；N2 解决当前可见量、历史活动基准和对象关系的联合角色。即使 N1 的时钟全部保留，也不会自动把某次 Build 基准变成当前核心价量。
