# 通用专业任务接入合同

本文件只规定运行层如何消费本 Run 的专业定义，不定义任何具体业务流程。对每个新 Run 使用同一合同，无需针对每类任务新增接入文件或改运行指南。

## 1. 三类输入

- 专业任务定义：目标、边界、专业方法、工作关系/后继、完成条件、产出。可来自完整任务书、Owner 原始任务说明、既有 Workflow 和 Skill、或其混合；Workflow 和 Skill 均非强制文件形式。
- 任务实例：对象、数据、代码及版本、已有成果、实际待查项等按适用填写。
- 执行配置与授权：manager/executor/可选 worker 的平台、模型/强度、工作区、实际可写范围和结果保存目标；由真实 GO 选择，不由业务阶段推断。

上述信息可以位于同一文件或多份来源。主控在 OWNER_START.md 逐字保存真实 GO，记录本次采用的准确来源/适用章节与执行配置、专业依据、运行协议和 cgpterm 实现版本。对 Git 来源固定 repo@40位commit:path；原始聊天任务若未持久化，在授权运行记录中保存原文并取得精确引用。允许专业依据跨仓/跨 commit；同一 Run 的角色必须采用同一组来源及其适用关系。新提交不自动升级。运行中增加证据引用不等于修改任务授权或专业方法。

已确定事项直接执行；任务中确有影响目标的实质不确定性或困难时，按 [通用工作方法](professional/TASK_WORK_PRACTICE.md) 在实际授权内组织统筹与问题解决。不要求选择任务类型，不增加流程、必填字段或管理 Gate；参考讨论不自动成为专业要求。

## 2. 专业工作如何进入 D

D 是 manager 签发的具名专业工作，不是 Skill 实例的专用运输。D 的 task_ref 指向实际专业工作依据（任务书、Skill、正式任务说明等），章节/工作范围在 DELEGATION.md 中明确；若为多份来源，在正文与 input_refs/source_refs 列出精确引用。business_context_ref 指任务上下文。expected_outputs 来自实际任务依据；不可将 manager 自拟的专业验收条件写入 D。

- 任务已有固定步骤：按其步骤、依赖和后继推进，不另行设计审批计划。
- 任务已有 Skill：按实际采用 Skill 方法及原生完成条件；不把内部小步骤默认拆为独立 D。
- 任务书直接提供方法：按对应章节直接执行，不创建伪 Skill。
- 任务部分开放或结果驱动：executor 在原任务边界和证据内提出有依据的下一项专业工作；manager 依据该回交组织接续。不得把初始未知解释成任意扩权，或未做分析先宣布完成。

D 粒度依任务规定、依赖、实际产出和恢复需要，可覆盖多个连续专业步骤、跨多个 C；由 manager 组织。步骤保存产物不等于必须逐步签 D 或上传全部中间材料。不为每个命令、小步骤或普通专业选择增加交接、审批。并行仅当依赖与写面允许。局部缺失先按实际价值尝试解决，再记录影响、已完成部分和恢复条件，原 D 内及其他不依赖该缺失的合法工作继续。不要将专业待核事项、未采用的资料或可选产物变成运行启动前置。

## 3. 回交与进展

executor 依任务原件形成实际成果、自检、专业状态和剩余范围，以 V2 Return 回原 manager。manager 消费真实回交、更新依赖/有效版本及进度，签发下一 D 或同 D 续接；必要时有据结束。主控验证真实身份和传输事实，不另写专业方法、Gate、完成标准或业务结论。按 V2 最小必要回交，允许在实际可访问且授权的工作区保留专业大表、图、脚本和原始证据，通过正式报告的准确引用交接；不要求全部中间产物先发 GitHub。

TASK_PROGRESS.md 使用通用恢复模板；BUSINESS_PROGRESS.md 使用通用阅读模板并按实际任务形成章节、结论和成果入口。若已采用的专业任务明确有专用模板则使用该模板（补足通用恢复/阅读最低信息即可），不修改原专业模板。两视图引用同一真实成果，不是第二套专业事实；普通推进不要求额外审批、独立管理决定或新 schema。

## 4. 权威及兼容

通用运行协议规定真实身份、授权、资源、回执、去重/恢复；专业任务决定业务方法、完成标准；物理执行配置决定平台和模型。任何一层不能覆盖另一层的权限与事实。旧 Run 按原精确来源接续，主控必须可读旧合同，不回写其采用记录或状态。新 Run 不因同仓存在旧业务文件而默认采用它们。已结束任务若由 Owner 新 GO 安排关联的新 Run，允许以旧成果及未决为业务输入，新的身份、权限和资源独立核实；不改写旧 Run，不机械重做有效工作。具体业务不需要改公共运行文件即可启动；只新增正常 Run 原件/成果。
