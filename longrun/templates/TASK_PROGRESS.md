# TASK_PROGRESS｜通用运行状态与恢复

本模板仅供真实 Run 使用。由 manager 根据实际专业产物与可信回执更新，不替代动作账本/专业事实。任务可采用已有专用模板；不得因任务类型不同修改公共模板。

## A. 身份、采用来源及资源

- run_id / work_id / business_case_id：
- 真实 Owner GO 引用、任务目标与边界：
- 采用的专业依据（任务书/Workflow/Skill及适用章节）、实例输入和版本：
- 运行协议/主控实现版本及物理 profile：
- manager/executor/worker 的逻辑与物理绑定引用：
- 工作区/realpath、授权及外部写面核验引用：
- snapshot_status: current / stale / not_yet_verified
- 最新已消费的结果/回执精确引用；已知尚未纳入的事实：

| 工作身份/范围 | 有效输入、依赖/版本 | 实际执行角色与 D | 当前状态 | 原生产物/回交引用 | 未完成/失效/恢复及后继 |
|---|---|---|---|---|---|
| | | | | | |

工作身份及专业状态由任务决定；无需预置业务阶段、finding 或 Release。区分未开始、在途、已完成、局部受限/阻断、失效和待核实；不把运输状态等同专业完成。

## D. 本次更新与接续

- 新取得且已核实的事实和成果引用：
- 复用、失效及重验范围：
- 尚未持久化/未知效果及核查条件：
- 下一 D 或原 D 续接、等待条件/有据收束：
- BUSINESS_PROGRESS 同步到的真实依据：
- 更新时间：

同一 Run 恢复使用当前可信记录与实际绑定。UNKNOWN 先对账，不凭此模板重发。任务允许部分受限时保留已完成与剩余范围。未完成不得写成完成。
