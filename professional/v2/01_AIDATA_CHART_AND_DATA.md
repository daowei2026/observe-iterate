# V2 S2：先基础行情图发现业务位置，再以 aidata 对照 U2/U3

## 1. 不是先把全部预计算字段画完

业务起点是 [00 业务目标](00_PURPOSE_AND_THREE_STEP_FLOW.md)与[07 业务场景观察方法](07_BUSINESS_SCENE_OBSERVATION_METHOD.md)：根据原 U2/U3 叙事要处理的共同方向机会及组内成员质量差别，**先用上游 K 线、small Zig、mid 贴近转折等基础行情画图/给出同源数据**，从真实过程寻找有研究价值的位置，然后才按实际业务问题显示 U2 位置/成员/组外与 U3 四个方面或既有 N 的相关层。不要把 U2 raw 索引直接当全部值得看的位置，也不要按 aidata 默认 big/mid/small 重新替业务选择 Case。

不预先规定场景分类、好做阈值或一次需要多少图。对于用户能够直接消费的少量有价值位置，优先交 **基础原图 → 选择理由 → U2/U3 图层 → 当前证据/后续检验**，再按真实需要扩展；不先大规模导出图层或让 Worker 根据技术便利挑选赢家。复用原已验算数据、已生成且版本相符的图，能复用的不重新施工。

## 2. 输入、图与 AI 数据对应

两份固定预计算 ZIP 的身份、实际路径与字段资格见 [05](05_BI01_FIXED_INPUT_DATA.md)。从 `/dwdhome/fy/资金管理` 只读获取；Worker aidata 工作区 `/dwdhome/fy/BASE_E6_2`。Owner 已确认基础执行环境和共享传输路径做过检查，不再作为重复预检工程。真实使用仍应记录代码 commit、数据身份、实际指令和图数据。

图与 AI 取得的同源数据必须绑定相同 run/node/timespan/As-Of、实际物理行、原源、显示/knowledge/retrospective 标记。基础图供 Owner 看行情是否构成有意义的机会；之后可与 U2 原 raw/reference 状态、U3 R02 或已有 C0/N 基线同位置对照。**完整 U3 只在一个参考 Case 的有限时点提供**，未产出部分不能通过制图器计算、模拟或者填零。

在发现业务场景时，未来显示上下文可用于回顾性定位，但不能作为历史 As-Of 下已经知道的事实。设计质量的后续验证要明确合法 Outcome End/Horizon 或写为探索性路径，不能用显示窗口末端冒充正式 Outcome。

`daowei2026/aidata` 是唯一业务图和图层数据工具。按实际锁定版本阅读 `README.md`、`OWNER_INTENT_AND_RATIONALE.md`、`TODO.md`、`docs/DEVELOPMENT_GUIDE.md`、`docs/RUN_BRIEF_INPUT_CONTRACT.md` 及真实 API。候选入口包括 `build_chart_run`、`build_board_run`、`render_review_nodes`、`export_plot_view_data`，实际支持须核，不能假称从任意 CSV 直接导入。

旧 `BI-01-V2-01` Worker 已交 320 图/包、所选51请求展开的图数，作为**历史可复用技术产物**：在当前运行中如核实旧图、输入、参数和版本匹配，可引用其完整原图与同源数据，不因新 run 重新生成同样的320图；但旧 S1 选样和专业结论**不继承为新运行的已完成或已通过**。历史 R10 的部分场景可以启发重新观察，须注明已知结论对选样的影响，不能称严格独立预测检验。

本轮不让 AI 看渲染图片；专业 Agent 读取与 Owner 图对应的结构化真实数据，不自称视觉看图。Owner 最终可点击图与读图说明，有条件时由 Worker 实际操作浏览器核验显示/图层，记录做过几页，未打开的不写成已视觉检查。

## 4. 工具变更边界

优先只读使用现有 aidata；必要时定向配置或复用现成图页。不在 `observe-iterate`/`cgpterm` 另做可替代的 CSV 分析/绘图器。**只有确证通用能力缺口才在 aidata 的全新独立分支施工**，不能改受保护原分支。不得重算 U2/U3 参考特征来绕过输入限制。图不能正常显示时具体说明受影响页面、组件与验证实物，其他不受影响的业务观察继续。

## 5. S2 完成要交什么

按有权专业问题交：基础行情图及何以选择该位置的证据、后续 U2/U3 对照图层、正确 run/node/As-Of、图的真实浏览器可看状态、对应同源 CSV/原行与方法/数据版本、Current/retrospective 区分、图中值得 Owner 定位的价点与人物可读说明，以及尚未提供的字段。成功绘图不等于后续强弱判断已经正确，也不等于业务场景覆盖完成。
