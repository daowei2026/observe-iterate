# 两层观察方法：从当前设想到具体品种判断

这是首版专业方法，不是已验证算法。完整目标见 [00](00_PURPOSE_AND_OUTPUTS.md)，当前优先设想见 [05](05_INITIAL_SCENARIO.md)，输入和图面含义见 [03](03_FEATURE_DATA_AND_VIEWS.md)。

## 1. 消费实际特征输入，不重复建设工具

先读本次交付说明，核对实际品种、共同可读范围、尺度配置、转折方向、实际点与确认点、线段和当前发展状态的含义。只补影响当前观察的缺口，不先审计全部数据或重做环境测试。沿正式来源使用数据，已有适用交付可直接复用；不得用旧Case价格表或最终图形代替本次特征输入。

结构化数据与人看图相互配合：AI可以定向读取、辅助计算、定位对象，不把算过数称为已经看过图；图上的差异要能回到数据。人和AI交流时指明同一观察时刻、品种、尺度及对象位置。输入不足与市场规律不成立是不同问题。

## 2. 沿当时可知信息推进

选择有必要前史的观察起点。每到T，更新截至T真正可取得的特征对象、属性和当前部分，不使用未来确认点、最终端点或最终长度。实际时间定位对象，确认及信息可取得时间决定使用资格；一个更新可能补出或修订多个对象，不机械把最后一条确认记录的方向当成当前方向。

完整历史图可以辅助理解和事后检验，但不能凭最终走势、最终是否整齐来倒选当时背景。若已看过后段，标明这是探索性历史重构，不声称盲测或当时真实预测。最后数据只有确认字段而缺少必要历史状态时，只在可核范围内重构，不能宣称已恢复完整发布和修订过程。

观察可以聚焦新确认、当前对象显著变化及必要比较位置，不要求逐根写流水账；也不能只在确认事件到达时思考而忽略已可见的重要变化。一次跳到较后时点，应消费期间相关更新，不能跳过不利过程。

## 3. 第一层：定位候选背景，再看中尺度结构

先问此刻哪些品种处于什么已知大尺度状态。背景是观察中的候选认识，不等于最终大尺度线段的交集，也不表示已确认未来会继续同向。

下表是假想的看图思路，帮助明确要分析什么，不是固定状态机、数据事实或必须逐步打勾的流程：

| 随时间出现的信息 | 此刻怎样处理 |
|---|---|
| 开始观察 | 取得各品种必要前史、最近相关确认和当前部分。图左端不是转折起点；未知就标未知，不用未来补定。 |
| A确认转上，B尚未确认或仍向下 | 回指A的实际位置，核A当前已知发展及B状态；不把共同背景提前写到A的实际低点。 |
| B后来确认转上 | 重新核A此刻状态及其间更新。若当时信息支持共同向上，提出候选，描述已知起点错开、当前长度与阶段差别；不预知它能持续多久。 |
| A开始回落，但尚未确认新的大尺度转下 | 区分当前变化、特征确实提供的候选状态与已确认转向；可降低背景确定性，不提前采用未来高点，也不把未转下当成安全保证。 |
| A随后确认转下，B仍向上 | 随新信息更新、暂停或结束共同背景的认识，记录此前何时提出、现在何时改变；不因后来复杂而删去原候选。 |
| A再确认转上，B仍是原向上过程 | 明确A已多次往返而B未换段，判断能否继续比较或另起候选，不拼接A的多段冒作一段。 |

实际起点接近不等于确认接近；一个品种已向上较久、其他品种刚加入，也不自动不可比。用当时对象和已知阶段说明。若只先观察部分成员，保留当时成员范围及后来调整理由，不根据最终赢家筛成员。

共同观察区间与各品种自身线段分开。可覆盖线段一部分，但不抹去中间反向，不按第几段机械配对，不预先画出后来才知道的结束边界。“先找对得较好”仅指当时对象关系较清楚，不保证后来始终简单。

候选背景已有所指后，检查当前范围里有哪些已确认中尺度点和线段、哪些未完成、如何分布及是否跨边界；不默认跨尺度端点严格嵌套，不将截入部分称作完整线段。够不够丰富，相对于当前要研究的现象而言，不按固定数量打分。

查找中逐渐记录曾遇到哪些候选、如何变化及常见困难，不能只统计最后成功延续的片段，也不重复计相邻切片。首轮先形成实际发生机会的认识，不先做全历史频率工程。

**已有对象足以开展具体研究，就进入第二层，不等大尺度结束或全窗分段完。** 局部困难只处理到不妨碍实际问题的程度；反复受阻时说明实际代价和缺口，反馈当前框架，而非开发通用分段器。

## 4. 第二层：利用具体现象形成后续判断

在所选背景内先对齐真实对象：“前一段中尺度向上推进”“本次中尺度向下线段（回落）”“当前未完成部分”各是什么。再看转折时间、推进、侵蚀、保持和它们的多品种关系，有什么可利用的现象与候选规律。需要时进入小尺度，不预设所有属性已有输出。

每项主要判断应讲清：截至T已知哪些对象及表现，利用什么候选规律，认为哪个或哪些品种在什么尚未知后续中可能推进较好、反向较小，或暂不选择。推进、保持与风险分别有依据，不能只列当前强弱，也不强求一个综合分数或唯一赢家。

新信息到来后，先保存原判断，再说明哪项依据新增、改变或被反对，判断怎样维持、降低、撤销或改选。背景也可变，必要时返回第一层；不能事后选择“背景失效”的边界来排除此前失败。

对照判断后的实际对象和运动，分别看推进、回吐、反复及出现位置。未结束的后续只报当前所得；后来才确认的线段可以用于结果检验，不能回填此前依据。出现差距不等于曾经能提前辨别，最终上涨不抵销途中反向。

优先用有限的实际过程把一种情形讲实，并继续核遇到的相似与相反表现。过去较好继续较好只是候选之一，不为迎合设想制造机制解释或把每次失败改名为新成功用例。

## 5. 两层反馈、权限与协作

背景和结构不足可改框架；背景存在但判断长期只剩事后描述，同样可以反问框架是否选错。原用例中普通失效、阶段变化和措辞澄清优先定向修订；业务对象或判断逻辑实质不同，才考虑另立用例。是否改变首轮优先框架由有权专业/管理依实际范围决定，超出授权再向Owner提出具体问题。

普通观察不逐条审批，已有资料不无故重算。Owner可看图快速反馈，专业者将其对应到对象和判断并更新准确版本；无反馈时继续能独立开展的授权工作。有实际必要才签Worker补数、补图或核字段，结果回原签发Pro消费；技术修复不能反过来成为业务主任务。

管理关注目前是否推进了现象辨认、具体品种判断和用例修订。方法仍不合适应带实物说明，不能只写更多流程文件。当前用例、观察材料及主要修订按 [02](02_OWNER_DELIVERY.md)交付，不把每个内部动作拆成新R或新Gate。
