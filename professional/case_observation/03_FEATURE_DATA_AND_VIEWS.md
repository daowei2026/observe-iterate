# 既有特征、正式数据与观察视图

## 1. 本轮输入是实际特征交付，不是预设旧数据

先消费本次正式交付的大、中尺度贴近转折及可取得的衍生对象；小尺度和其他特征按实际问题补充。品种、范围、参数及文件位置由交付确定，不默认旧rb/hc/i、2021起点、四Case窗口或mid单尺度已适用。

正式数据沿现有aidata接口及正式交付取得；Owner提供的已有数据包先核正式来源和适用语义，能直接消费就不重复取数。不另建直连数据库/KLine或图层反导的平行证据来源。合法辅助计算可以消费既有输出，但必须说明对象和含义，不能冒称已有正式特征字段。

大中小是特征尺度，K线频率和平台节点层级是其他概念，不默认big节点就是大尺度贴近转折，也不假设不同尺度转折点严格嵌套。

## 2. 数据到达时的最小适用性核对

| 核对内容 | 要明确什么 |
|---|---|
| 实际覆盖 | 品种、共同可观察期、必要前史、缺项和边界；请求末界不自动等于包含末日全天。 |
| 特征及衍生对象 | 真实类/配置/版本，转折方向语义，线段如何形成，已完成与当前部分如何区分；不凭名字猜方向或运行状态。 |
| 时间 | 实际点与确认点的时间/坐标含义，确认后可取得什么，发布或修订是否另有信息；不把字段xConfirm自动当作真实历史接收时间。 |
| 属性 | 起止、长度、时长、推进与侵蚀等哪些已有，哪些可从当时对象计算，哪些缺失；未结束部分不使用最终属性。 |
| 图数对应 | 图入口、图名、品种/尺度、对象或行定位及实际可读范围；缺图与缺数据分别报告。 |

只核影响本轮观察的部分，不开展全数据审计、重装环境或从零验证所有接口。无法取得某项必要信息时说明影响：先做不依赖它的工作，依赖它的判断保留未定，确有必要再请求具名补充。

## 3. 实际发生、确认和观察T分别使用

实际点用于定位历史过程；确认及可取得时间决定何时能使用其转折身份和衍生信息。确认可能回指较早位置、一次涉及多个对象或修订已有状态，须按实际设计和交付解释。不得机械把最近确认方向等同当前方向。

到T只使用当时可取得的点、线段、属性及当前部分。图上后来画出的完整线段，不是早期已知线段；未确认候选只有特征实际提供时才能引用并标清。新信息可更新对过去的解释，不能覆盖原来当时的判断。

若仅有最终点集及确认字段，先核能否支持所需T的可知状态。缺少历史修订或当前状态时不假装完整重放，也不因此要求先开发完整回放平台；可用有限的已核对象和关键T说明，无法支持的主张明确限制。

## 4. 图面需要表达的业务信息

| 内容 | 人看图应能理解什么 |
|---|---|
| 多品种时间对应与当前T | AI此刻站在哪里、比较谁、哪些信息尚未来到；跨日历/坐标差异须说明。 |
| 大、中尺度方向与连接 | 哪个点/线段属于哪个尺度和方向，当前部分不冒作已完成线段；小尺度按需展开。 |
| 实际点与确认点的对应 | 可用编号、关联标记或配套表指向同一对象。没有确认价格坐标不编造价格点，可放时间标记区。 |
| 当时可知范围 | 未到确认时间的最终转折不作为已知对象显示；未来终点不提前画。完整历史图另作回看，淡化未来信息仍不等于严格遮蔽。 |
| 候选背景变化 | 区分指向哪段实际过程、何时形成当前背景认识；不预画事后才知道的结束边界。 |
| AI说明的定位 | 关键T、新确认、对象和判断能直接在图或配套状态中找到。 |

优先使用现有图和关键T快照/状态说明，不先建交互系统。颜色主要用于品种区分，尺度和方向可用其他清晰标记；具体画法以现有能力和可读性决定。图被打开、对象画对、当时可知范围正确、业务判断成立是不同结果。

## 5. 工具复用与权限

既有aidata三接口分别建立core、生成平台图、形成正式数据切片；不是每轮必须全调。仅消费已有交付时记录原来源即可，确需新增调用按实际版本README/API和工单执行。旧用法和成功/失败实物的精确入口在 [04](04_SOURCES_AND_REUSE.md)，不复制旧固定参数为默认。

旧经验仍适用：窗口切片不等于全历史，图层不是正式数据来源，UTI/时间标签/日历须按实际语义转换；reuse_core不自动追加节点，页面参数保存或HTTP成功不等于图面通过。以上仅在相关操作确实发生时定向处理。

数据、图面或字段缺口由专业者说明业务影响并签适用Worker工作，技术结果回原签发Pro消费。现场路径不是代码或服务写权；共享服务部署、重启、注册、存储维护等不因观察任务获得授权。旧故障不自动继承为新阻塞，也不假定已经恢复，按本次实际依赖判断。
