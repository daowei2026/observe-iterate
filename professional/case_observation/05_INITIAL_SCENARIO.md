# 初版场景设想：先试同向大尺度背景下的中尺度差异

这是启动时的候选设想，不是已发现规律或固定分类。形成方式见 [01](01_RESEARCH_METHOD.md)；运行后实际采用的修订在本Run保存，说明改变了什么、依据是什么，不把后来的认识改写成最初已知。

## 1. 当前先试什么、为什么先试

先以向上单边机会为例：沿当时可取得的特征信息，在多个品种可辨认的同向大尺度背景中，观察中尺度贴近转折及线段的推进、向下线段（回落）、转折先后和成果保持，利用发现的现象与候选规律，对后续品种表现提出不同判断。必要时看内部小尺度反复。

先试这一框架，是因为当前对象和问题已经较具体，并暂时减少大尺度方向这一方面的差别，便于开始观察；不是因为已经证明它最常见、最简单或最能选品种。同向不等于同阶段，不代表一定有利。大尺度方向不同暂不优先，不是不可比较或永久排除。

第一层不先要求看出谁好谁坏。某个候选在当时较清楚，后来复杂或失效也保留，不能用最后赢家、最终线段交集或后段整齐程度倒选。

## 2. 框架内已有的细节线索

下表仅帮助看图时想到具体问题，不是五个必须完成的用例，也不预先指定预测规则。所有点的使用按确认/可取得时间，当前部分不使用未来终点。

| 线索 | 判断前准备观察的特征对象 |
|---|---|
| 中尺度向上延续不同 | A、B的中尺度低位点实际发生时间接近并先后确认；后来B已确认转下、前一向上线段结束，A当前向上部分仍在发展。区分实际先后、确认先后及当前状态。 |
| 中尺度向下线段侵蚀不同 | A、B此前各有向上线段，随后出现向下线段（回落）；相对于各自前一向上线段，交还多少成果，哪些部分尚未结束。 |
| 中尺度转折先后与保持 | 某成员较早取得向上确认，其他成员较晚；到当前时点各自推进、回吐如何，早转者也可能已经明显受损，不能预定先转更好。 |
| 前后过程的成员差别改变 | 前一轮A推进、保持较好，新一轮却反复退回，B出现不同于此前的推进和保留；观察哪些当时信息改变原判断。 |
| 中尺度向上中的小尺度负担 | 中尺度仍向上，但其内部小尺度向下线段（回突）反复侵蚀成果；能否据已有表现排除部分成员或暂不选择。 |

具体要利用哪种已知表现判断哪种尚未知后续，由真实观察形成。不能只把A、B当前状态并列就称已形成规律，也不要求解释差异为何发生。

## 3. 尚待实际特征结果回答的前提

这些大尺度背景能否在有用时点被辨认？对象错位、确认延迟和多段对应会有多复杂？共同范围内已取得的中尺度结构是否足以研究当前想法？类似候选有多少实际发生机会？这些问题随查找逐渐认识，不先建立全历史对齐和分类系统。

“结构足够”相对于具体设想：比较多轮推进/回落需要相应线段，但其他候选规律未必需要很多段。不要追求越丰富越好，也不要用事后最终段数声称早期已经足够。

背景和结构成立，不保证后续判断有用。第二层若反复只得到事后描述，也应重新考虑框架，而不只修改措辞。同向背景下的近期差别可能延续，也可能反转；候选规律接受实际后续的支持和否定。

## 4. 怎样修正而不扩大任务

能通过新增信息解释原用例中的普通变化，先在同一用例修订。持续缺少结构、确认过迟或对齐成本妨碍业务进展时，带具体对象反馈框架。若需要改为其他主要观察对象或判断逻辑，依实际授权由专业/管理决定，不把每次失败都新建为成功用例。

初版只要在限定范围内把现象、当时依据、候选规律与具体判断讲实即可继续交付；不先穷尽所有框架、反例或尺度组合。是否发展为其他工作，另按真实任务安排。
