# 多品种差异用例观察与回看研究

本方法从真实市场用例出发，不从某个已实现特征的验收出发。它替换上一套具体特征四项工作。

## 当前完整任务

必须经 aidata 取得多品种历史数据，先以 1d 数据从事后角度找出 3–5 个有明显好坏差异、彼此能提供不同观察信息的用例。每例均回看此前相关信息，研究提前区分后续运动好坏的依据与逻辑，形成基本完整、合理、可在图上核对的辨别故事。一次性向 Owner 交付这一批结果；暂不深入用例间分类、关系或统一机制。

两项产出是：

1. **具体多品种差异用例**：在哪里、哪些品种、实际差在哪里、为何值得研究，并能在真实图和数据中定位。
2. **该例的提前辨别逻辑研究**：给出基本完整、合理、可在图上核对的辨别故事，说明此前依据怎样支持对后续表现的不同判断、适用条件与尚未解决的问题；不以事后路径描述代替。具体成果要求见 00，不预设研究角度或保证每例辨别成功。

这不是两个必须依次管理验收的阶段。找到一例即可研究该例，整批仍以 3–5 例完整交付为范围，不先交一个就自行收工。
