# 多品种差异用例观察与回看研究

本方法从真实市场用例出发，不从某个已实现特征的验收出发。它替换上一套具体特征四项工作。

## 当前完整任务

必须经 aidata 取得多品种历史数据，先以 1d 数据从事后角度找出 3–5 个有明显好坏差异、彼此能提供不同观察信息的用例。每例均回看此前相关信息，研究提前区分后续运动好坏的依据与逻辑，形成范围明确、主干完整、合理且可返回行情核对的初始业务用例。一次性向 Owner 交付这一批结果；暂不深入用例间分类、关系或统一机制，不免除每例内部的多品种关系研究。

两项产出是：

1. **具体多品种差异用例**：在哪里、哪些品种、实际差在哪里、为何值得研究，并能在真实图和数据中定位。
2. **该例的提前辨别逻辑研究**：以初始业务用例正文讲清情境、过程、网络关系及演变、条件性辨别和预期业务认识；与研究依据及观察迭代材料分开阅读而相互对应。前者作为独立可读的初始用例，后者支撑当前认识并供后续观察使用；本轮不绑定或启动其他任务，也不以穷尽验证作为初版前提。完整要求见 00，交付组织见 02。

这不是两个必须依次管理验收的阶段。找到一例即可研究该例，整批仍以 3–5 例完整交付为范围，不先交一个就自行收工；产出二的两类阅读内容也不另设 Gate 或重复文件。
