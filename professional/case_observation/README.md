# 基于既有特征的初始用例观察

当前任务从既有贴近转折特征及衍生对象出发，发现现象与候选规律，并利用它们提前判断后续品种走势好坏、机会与反向风险。优先形成一个有实质业务价值、可继续观察和修正的初始用例，不追求复杂结构或案例数量。

**观察方法与当前设想分开：** 00—04规定目的、研究、交付和来源；05给出本次先试的同向大尺度背景框架。框架是可修改的研究选择，不是单边业务的唯一条件。

| 文件 | 主要内容 |
|---|---|
| [00_PURPOSE_AND_OUTPUTS.md](00_PURPOSE_AND_OUTPUTS.md) | 业务目的、首轮产出、接收和边界 |
| [01_RESEARCH_METHOD.md](01_RESEARCH_METHOD.md) | 两层观察、确认信息下的时间推进、反馈与框架修订 |
| [02_OWNER_DELIVERY.md](02_OWNER_DELIVERY.md) | 当前用例、观察记录、图数入口及Owner交流 |
| [03_FEATURE_DATA_AND_VIEWS.md](03_FEATURE_DATA_AND_VIEWS.md) | 既有特征对象、实际与确认时间、图面表达和正式输入 |
| [04_SOURCES_AND_REUSE.md](04_SOURCES_AND_REUSE.md) | 本轮优先来源、U2/U3与网络语义、旧资料的定向复用 |
| [05_INITIAL_SCENARIO.md](05_INITIAL_SCENARIO.md) | 初版框架、为什么先试、细节线索及待检验前提 |

第一层沿当时可知信息寻找可共同观察的大尺度背景，检查其中已有中尺度结构是否足以研究；第二层在具体对象上形成后续品种判断并随新信息修订。二者不是固定阶段，不先扫完整个历史或建通用分段规则。有足够对象就开始具体研究，业务判断不成立也可以返回调整框架。

初版先使用大、中尺度，小尺度按实际问题补充；实际品种、时间范围、配置、数据和图入口由新交付确定。不能把K线频率、平台big节点和贴近转折尺度混同，也不继承旧三品种、四窗口、mid单尺度或五图阴影的固定要求。

数据与特征来源沿正式交付，已有适用实物直接复用。能讨论的业务进展及时从同一入口给人查看，不等待凑齐3—5例；当前用例与具体检验分用途组织、准确相连。技术通路不替代业务完成。
