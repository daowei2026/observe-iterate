# 多品种差异用例观察与回看研究

本方法从真实市场用例出发，不从某个已实现特征的验收出发。它替换上一套具体特征四项工作。

## 当前完整任务

必须经 aidata 取得多品种历史数据，先以 1d 数据从事后角度找出 3–5 个有明显好坏差异、彼此能提供不同观察信息的用例。每例均回看此前相关信息，以投资者视角尝试解释差异。一次性向 Owner 交付这一批结果；暂不深入用例间分类、关系或统一机制。

两项产出是：

1. **具体多品种差异用例**：在哪里、哪些品种、实际差在哪里、为何值得研究，并能在真实图和数据中定位。
2. **该例的回看解释研究**：实际回看了什么、依据怎样支持或不支持解释、哪些差异当时可能看出、哪些仍解释不清。

这不是两个必须依次管理验收的阶段。找到一例即可研究该例，整批仍以 3–5 例完整交付为范围，不先交一个就自行收工。
