## 当前差距及最小修改位置（本轮未实施）

**单 URL 目标未通过：实际为 overview URL + 三个 big URL，共四条。** 概览虽标出三个窗口，也没有内嵌三张 30m 图；没有把四条链接或截图包装成单链接通过。

差距位于 aidata 的**平台页面组装层**：`big_world_chart.py:386` 创建 overview，`:396` 逐 big 创建独立 `AidataBigWorldReviewCAE`；现有 `AidataRunOverviewCAE.layout()` 的 `page_children` 只有概览与辅助控件。`api.py:122` 是对应公开薄入口。Uplot 的 `CAEGraph.produce_widgets()` 本身可遍历多个 PlotSet，已有 Bokeh 布局也支持组合，底层具备组合基础；当前 aidata 入口未把四张图组装成一个持久平台 CAE 节点。

建议最小方案：在现有 `AidataRunOverviewCAE` 增加显式组合选项，按同一 run 冻结的 big 节点，复用已有 overview 与 big graph 注册/布局函数，把一张 1d 和三张 30m 布局放入同一个平台页面；公开 API 透传选项并返回单一 `report_url`。各图保留各自频率和 scope，复用现有 CAE 类可避免另加平台反序列化类型；无须改 CAEGraph/PlotSet 底层或重建定位/正式切片。本轮仅定位方案，未改任何源码。

另外，日期字符串按零点经 `feature_slicer.plotctx_uti_window()` 映射日历，当前三个测试窗口均未包含结束日的日盘收盘；完整历史概览与正式日线也均止于 2024-02-28 收盘。本轮保留原输入，未为扩大范围重跑。落盘 `context_ref.start_day/end_day` 为 null（当前序列化只取 snake_case），准确输入与日期另由 [原脚本](probe.py)、[参数记录](actual_parameters.json)、overview 记录和冻结节点索引留证。

本轮仅执行用户授权的两项工具链验证及页面/数据验收；新增平台图节点属于指定 `save=True` 调用结果，未编辑正式源数据、公共源码或长程业务仓库。
