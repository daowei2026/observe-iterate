# 具体特征观察：专业主干及其关系

## 1. 当前专业工作目标

以**具体已实现、可取得数据的特征**为研究对象，了解实际特征的含义、输入、输出与参数，在实际市场数据上探索怎样合理展示和理解它，检查特征正确性及其结果是否符合普通投资者对市场过程的正常解读。观察中产生的新认识可以反过来调整参数、展示方式和实际绘图安排。

这是一套**可迭代的工作起点**，不是要求运行前已经形成完美的方法体系。原有 U2/U3 总体设计按需要提供背景和原意图；不再以完成整套 U2/U3 业务观察作为本轮目标。

## 2. 四项专业工作

| 工作 | 本身解决什么 | 本轮需要考虑的内容 |
| --- | --- | --- |
| **1. 初始合理参数** | 让具名特征具备第一轮可观察的实际配置 | 先理解特征含义、输入、输出、参数及参数层次；基于既有实现和资料考虑初始参数 |
| **2. 特征展示方式与实际画通** | 决定画法，并由专业 Pro 负责 Uplot 实际成图、检查和修订 | 直接使用所采用 uplot/CAEGraph 的正常能力，在真实特征数据及行情上重新绘图、测通主附图、图元、单位、时间/状态及必要交互；交付可修订配置和实际执行成功、便于交互查看的 Jupyter Notebook |
| **3. 使用 aidata 组织观察与交付** | 消费工作2重新画通的画法与配置，组织平台观察位置和数据 | 实际核验 build_chart_run、build_big_world_chart_pages、build_board_run 的同 run 衔接，按需接入 feature_configs，交付正常平台 CAE 节点、可打开的 report_url 和同范围正式数据 |
| **4. 观察分析** | 从同节点正式数据与必要图形获得对特征的认识 | 主要消费工作3 board 的正式特征切片/交付，关联同范围行情和必要上游；N多表/as-known按需补正常OnlyRead。已有可靠正式数据允许先行分析；图用投影不代替正式结果 |

这四项是**工作内容**，不是四个硬性的串行阶段。通常可以先了解配置与展示，再实际绘图和观察；若后一步暴露前一步的问题，应返回修正，不能为维持阶段顺序而继续错误假设。

## 3. 边界

- **具体特征是本轮研究主体**；不是直接在 U2/U3 大叙事与细节字段之间来回跳转。
- U2/U3 的 Narrative、Use Case 或处理依赖，只在解释这个特征的原意图、来源及后续用途时按需查阅，不承担原来的整体业务验收目标。
- 旧 S1–S3 的专业工作划分退出；既有专业知识和工具经验是否复用，以对当前四项工作是否仍然适用为准。
- 工作2不止于设计或配置：由原专业 Pro 主导 Uplot 真实重新成图、实测和修订，可委派技术 Worker，但不能把画法能否画通推给工作3。正常主交付为实际执行成功、可交互查看及复现的 `.ipynb`，包含真实代码、参数/版本及数据入口；HTML仅可辅助，不要求或以PNG作为看图交付。使用Uplot不授其源码写权。
- 工作3消费工作2的画法/配置，按需放入 `aidata/feature_configs` 并核真实平台调用；提供平台图节点、实际打开核验的页面链接和同位置数据。standalone HTML、PNG或临时localhost不算平台链接；平台暴露画法问题返回工作2，定位/页面注册/交付问题由工作3处理。入库、调用及必要最小衔接遵守实际分支和写权，不另造平台。
- 对本轮BI-01-FO-01，Owner698b229已明确此前所有图一律不作为合格工作2成果，必须重新绘制、重新验证，不能补链接或补验证恢复资格。旧图文件/回交不删除或倒改；可信正式数据可核源复用，配置与技术记录可作未验证参考，均不能免除本次真实重新成图和Pro判断。
- 不把“先单品种还是多品种”作为工作 2 的独立设计任务或验收点。设计须兼顾最终多品种共同呈现，颜色优先留给品种身份，其他性质优先用线型、形状、位置或分图等区分；实际观察范围按问题确定。
- 展示不固化为单个 As-Of 的 6+6+Working 截面；须考虑沿市场时间查看变化和选择观察时点回看，区分发生、确认/可知、当时 As-Of 与后来修订。不预设逐拍绘图、逐拍重算或实时直播机制。
- 图形承担主要展示责任，表格按需辅助准确值、身份与核查，文字辅助说明；不要求画出全部输出和中间值，也不预设参数最终最优后才能画图。
- 本方案不预设四项工作各占一轮 Pro、四轮 R 或四个管理 Gate；实际推进由有权管理根据专业需要持续安排。

## 4. 怎样推进和返回

专业执行者依据特征实际情况决定本次重点，保留**为什么改变**的依据。例如看到结果后发现画法遗漏必要内容，可返回工作 2；发现图层配置不合理，可调整工作 3；发现某个参数使特征产生有疑问的结果，可返回工作 1。返回并不是重新开始全部工作，已有有效结果应沿用并记录变化。

专业探索中尚未确定的结论允许保留疑问；已知、可识别且会直接影响推进的重要执行障碍，不能仅以“交给后续迭代”为由忽略。对实际受影响的运行环节定向核查，保留不受影响的专业工作，不把历史准备阶段或尚无证据的工具疑问重设为全项前置。

## 5. 已知第一个观察对象的实际边界（背景事实）

CYF 当前第一项 U2NormalNodeBehaviorFrp 位于 U2 较上游，主要描述单品种单尺度近期已完成过程和当前未完成过程，而非直接识别跨品种同轮机会簇或完成 U3 的资金依据。CYF 已说明它值得进行一轮投资业务观察，但不能承诺收益预测增量或完整 U2 投资解释能力。

因此第一轮应以这个具体特征实际能输出和能观察的内容为范围；后续具体例子、参数、展示组合由四项专业工作实际推进，不由本纲要提前代做。
