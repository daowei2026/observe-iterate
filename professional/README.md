# 专业探索项目

当前处于**业务用例形成方法的探索与实践阶段**，不是已定型的专业规范或专用Agent。围绕Owner明确的业务目的，Management Pro理解整体意图、已有材料和各轮实践结果，决定并安排下一项具体专业工作；Professional Pro按本轮正式任务执行、提交真实业务发现与未完；Management Pro消化结果、更新整体认识并安排下一轮。多轮实践后，才判断哪些做法值得固定为规范或Agent。

本目录只保存相对稳定的探索背景，不承担每轮动态任务和进度管理，也不要求Management Pro在这里维护平行的当前任务。

## 动态管理工作面

当前Run的动态管理产出统一放在 runs/<RUN_ID>/ 下：README.md、00_长程推进地图.md、01_当前任务.md、reviews/management-Rxxxx/DECISION.md，以及 provenance/turns/Rxxxx/ 下的正式回交。

这些文件沿既有长程运行机制维护。Management Pro根据真实变化更新地图和当前任务，不要求每次管理调用都机械修改；没有改变整体状态或任务时，在本轮管理决定和回交中如实记录即可。**不要在professional下另建current_work、当前进度或第二套任务路由文件。**

00 说明最终目的，06 说明当前长程任务的直接目的，05 完整保留并随 Owner 明确纠正更新初版过程；02 只作摘要。Management Pro 应组织初版过程的实践与反馈，并向 Owner 明确呈现重要新增业务分析或偏离。

本目录的探索背景供Management Pro理解和按需读取；它不构成Owner GO、任务派发或Run采用。Professional Pro只执行本轮正式派发的任务，不从背景材料自行推断授权。
