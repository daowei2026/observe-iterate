# 专业探索项目

当前不是已定型的专业方法或专用Agent，而是围绕业务目标持续实践、摸索并修正做事方式。

**长程持续机制：** Owner明确整体业务意图并反馈；Management Pro理解整体意图、已有材料和实践结果，安排下一项具体专业工作；Professional Pro执行并提交成果与发现；Management Pro消化结果、更新认识并安排下一轮。多轮实践后，才判断哪些方法值得固定为规范或Agent。

本目录分开保存探索背景与当前具体工作，不把当前设想固化为未来任务的固定流程。

- [exploration/](exploration/)：业务目标、既有特征、当前设想、工具数据使用及业务参考。
- [current_work/](current_work/)：当前具体工作，由管理根据最新进展更新。
- [case_observation/](case_observation/)：旧版专业规范历史位置；新探索不默认读取旧文档。
- [CURRENT_EXECUTION.md](CURRENT_EXECUTION.md)、[TASK_ROUTER.md](TASK_ROUTER.md)：管理接续和任务路由入口。
