# 专业探索项目

当前不是已定型的专业方法或专用Agent，而是围绕业务目标持续实践、摸索并修正做事方式。

**长程持续机制：** Owner明确整体业务意图并反馈；Management Pro理解整体意图、已有材料和各轮实践结果，安排下一项具体专业工作；Professional Pro执行并提交成果与发现；Management Pro消化结果、更新认识并安排下一轮。多轮实践后，才判断哪些方法值得固定为规范或Agent。

本目录分开保存探索背景与当前具体工作，不把当前设想固化为未来任务的固定流程。

- [exploration/](exploration/)：业务目标、既有特征、当前设想、工具数据使用及业务参考。
- [current_work/](current_work/)：当前具体工作准备稿，由管理根据最新进展更新和采用。
- [CURRENT_EXECUTION.md](CURRENT_EXECUTION.md)、[TASK_ROUTER.md](TASK_ROUTER.md)：管理接续和任务路由入口。

当前专业工作不是“按一套已定型方法反复生产用例”。Management Pro应先理解Owner整体意图、已有特征基础、当前探索设想、工具能力、真实数据交付和前轮结果，再形成本轮具体委派。Professional Pro按真实委派开展工作，可以在授权范围内修正当前设想并报告方法问题；管理Pro负责跨轮整合和决定下一步。没有真实Owner授权和管理采用时，目录中的准备材料不构成任务派发。
