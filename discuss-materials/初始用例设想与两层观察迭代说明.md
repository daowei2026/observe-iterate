# 初始用例设想与两层观察迭代说明

> 汇报配套说明·当前整理版。以本次讨论及后续两次纠正为依据，后续在本文件继续更新。这是待结合实际特征图检验的观察设想，不是已验证的规律、已实施的绘图能力或已采用的长程任务规范。

当前要推进的是有业务价值的初始用例：基于既有特征表达的对象、属性和关系，发现现象与候选规律，并利用它们提前判断后续哪些品种可能走势更好、机会更大、风险更小。第一版不优先追求复杂，主要看所描述的情形是否有足够多的发生机会，以及能否实际用于品种判断。

整体设想是：**明确初版特征范围 → 提出初版用例设想 → 第一层沿时间查找大尺度背景、检查中尺度结构 → 第二层在选定背景内形成并修正具体用例。** 两层都接受数据反馈，不是先把全部历史分段完，再一次性研究所有细节。

## 一、初版要用到的特征

**以既有的大、中、小尺度贴近转折，以及它们形成的线段等衍生对象和对象属性为表达基础。** 不是脱离既有特征，直接根据原始行情自由编写故事。

| 特征及对象 | 初步用途 |
|---|---|
| 大尺度贴近转折点及线段 | 定位各品种的较大方向背景，观察其在时间上如何对应；从前往后寻找可以共同观察的背景。 |
| 中尺度贴近转折点及线段 | 先检查候选背景内是否有足够丰富的结构，再用于细看转折先后、向上推进、向下线段（回落）及成果保留等现象。 |
| 小尺度贴近转折点及线段 | 按需补充；中尺度表达不足时，进一步观察其内部的反复和反向负担。 |

需要看清转折方向、实际发生点、确认点及其对应关系，区分已确认的对象与尚在发展的部分。推进幅度、持续时间、对前一线段的侵蚀等是待观察的属性或比较内容，是否已有输出、能否由已有对象取得，需要核对，不能默认都已实现。

“大、中、小”指贴近转折的尺度，不把它们与K线频率、平台图节点层级混为一件事。初版先用大、中尺度，小尺度及其他必要特征可随实际研究补充。

## 二、初版用例设想：先保留一个框架，不急着扩展更多场景

**先以向上单边机会为例，尝试在多个品种当时可辨认的同向大尺度背景中，观察中尺度贴近转折对象及其关系，利用已有表现判断后续品种差异。** 大尺度方向不同的情形暂不优先，不代表没有价值。

当前并不知道：这样的背景是否经常能在当时被识别出来，其中的中尺度结构是否足够丰富，已有表现能否支持有价值的后续判断。这些正是两层观察要回答的问题。

框架下已有以下细节设想。它们是看图时可用的思考线索，不是已经成立的规律，也不是必须逐一完成的分类任务：

| 细节设想 | 图上准备具体观察什么 |
|---|---|
| 中尺度向上运动的延续不同 | A、B的中尺度低位转折在接近时间发生，并分别得到确认；后来B已确认转下，前一向上线段结束，A从已知低点开始的向上部分仍在发展。这里不使用A未来才确认的终点。 |
| 中尺度向下线段（回落）的侵蚀不同 | A、B此前各有中尺度向上线段，随后出现向下线段；比较各自交还了前一向上线段的多少成果。未结束部分只比较截至当时的表现。 |
| 中尺度转折先后与后续表现不同 | 实际转折先后、确认信息到达先后分别是什么；这些先后与已经取得的推进、回吐表现怎样共同对应后续。 |
| 前后中尺度过程中的成员差别改变 | 前一轮A推进、保持较好，新一轮却反复退回，B开始取得并保留更多推进；怎样根据新信息更新原判断。 |
| 中尺度向上部分内的小尺度反复较重 | 多个品种都有中尺度向上运动，但小尺度向下线段（回突）反复侵蚀成果；是否存在应排除的候选，或暂时没有足够好的品种。 |

这些内容归入第二层具体研究。第一层不先要求看出谁好谁坏，也不凭后来谁走得好来倒选大尺度背景。

## 三、第一层：按当时可知信息找大尺度背景，再看中尺度结构

### 1. 从查找背景开始，就要看确认时间

**“从前往后看”应沿当时能够取得的信息推进，而不是先看完整历史线段挑出整齐片段，再补查确认点。**

每走到一个观察时刻T，都要区分：

| 时间含义 | 在观察中怎样使用 |
|---|---|
| 转折实际发生时间 | 定位这个对象对应图上的哪个位置；不等于该时刻已经知道它是转折。 |
| 转折确认及信息可取得时间 | 决定从什么时候可以将该转折及相应对象作为判断依据。按既有特征实际语义核对；有发布、修订等区别时不能忽略。 |
| 当前观察时刻T | 只使用截至T已可取得的对象、属性和关系，未完成部分只使用截至T的状态，不使用最终端点、最终长度或最终持续时间。 |

一个确认更新到来时，它可能指向更早的实际位置，也可能更新不止一个对象。要看这次实际新增或修订了什么，不能预设每次只有一个新点，或机械地把新确认点的方向当成当前方向。

例如，A实际先转上，但确认晚于B：完整历史图上的实际先后与观察者收到信息的先后就不同。如果A转下的实际位置早于B转上的确认时间，B信息到来时还需要结合A当时已经能取得的状态判断，不能把两条最终线段的交集当作当时已经知道的共同背景。

确认到来后，可以回指历史位置、重新解释先前过程；**不能因此把较早时点的判断改成“当时已经知道”。** 数据若只有最终结果及确认字段，须说明能否据此还原历史可知范围；不能仅做时间过滤就冒称已复原真实发布、修订过程。

### 2. 沿时间向后的假想查找过程

下面只是假想的分析顺序，帮助明确看图时需要想什么；不预设真实行情、确认规则和复杂情况一定如此。T0、T1等表示依次观察的位置，不是算法阈值。

| 从前往后遇到的信息 | 当时该看什么、想什么 |
|---|---|
| **T0：开始观察。** | 先取得T0之前必要的已知特征状态：A、B各自最近已确认的转折、相关线段和当前发展部分是什么。图左端不是线段起点；前史不足时说明不足，不根据后来完整线段补定T0方向。 |
| **T1：收到A向上转折的确认信息，指向更早的实际低位。** | 核对这次确认给出了什么，A截至T1的当前部分怎样发展；再看B此时的已知方向。若B仍向下或尚不清楚，不立即认定A、B已经共同向上，也不把共同背景倒填到A的实际低位。 |
| **T2：B的最新价格也开始向上，但转折尚未确认。** | 已有价格变化可以看，正式转折尚不可当作已确认事实。只有既有特征确实提供候选状态时，才能引用该状态并注明未确认；不能用最终图上已画出的B低点替代当时信息。 |
| **T3：B的向上转折得到确认。** | 同时复查A此刻的已知状态，而不是只记住A之前转上。若当时信息支持二者均向上，才提出一段共同观察的候选背景。比较两者已知起点的错开、A已发展到哪里、目前是否明显阶段不一致；不预知这段背景还能持续多久。 |
| **T4：原候选背景中，A最新部分开始回落，但新的大尺度转折还没确认。** | 看当时已有对象和当前状态究竟能说明什么，区分价格回落、候选变化与正式大尺度转向。可以记录当前背景的不确定性，不能提前采用未来确认的高位转折点；也不能把“尚未确认转下”解释为以后一定仍会上行。 |
| **T5：A转下的确认信息到达，B仍处于原向上过程。** | 对照确认所指的实际高位及当时可知信息，更新或结束原“共同向上”的认识。保留何时曾认为对应较清楚、何时因新信息改变；不要因为最后图形复杂，就回头删除原候选或把它说成一开始就不该选。 |
| **T6：以后A又确认转上，B仍在原向上过程。** | 现在可能出现A第二次向上、B仍是第一次向上的对应。检查实际对象和时间关系，讨论是原观察过程中的新环节，还是另起候选；不能把A中间的大尺度向下线段抹掉，拼成一条向上线段。 |

实际可以有更多品种、不同确认先后及其他变化，需据图补充，不把上表当成固定的状态机。

**“先找对得比较好”，指在当前时点的信息下，优先讨论对象对应较清楚、暂时较容易理解的候选；不是保证它后来始终整齐。** 若还需要观察才能判断，就先保留待观察。即使事后它变复杂，前面的选择及后面的变化仍然有价值，不能只保留成功延续的片段。

### 3. 查找中可能遇到的复杂情况，先准备怎样思考

| 可能遇到的情况 | 要据实际对象判断什么 |
|---|---|
| 实际转折时间接近，确认时间却相差较大 | 哪个时刻才真正取得了足够信息？当时另一个品种已发展到什么位置？不能只凭实际低点接近就判定当时容易比较。 |
| 一个品种已向上较久，另一个刚确认向上 | 当时可以提出共同向上的候选，但二者阶段差异会不会妨碍本次观察？先用当前已有长度、时长及对象状态描述，不用最终持续时间判断谁已到末尾。 |
| A已有向上、向下两段，B仍只有一段向上 | 将A的两段分别对应到B当时所在部分，保留方向不一致的区间。不能按第几段机械配对，也不能合并A的线段掩盖差别。 |
| 当时看起来比较整齐，后来很快分化 | 记录候选从提出到改变的过程。后来确认的结束可以用于回看，但不能充当前面就知道的筛选理由。 |
| 某成员先满足条件，其他成员较晚加入或无法判断 | 说明每个时刻实际比较的是谁。是否先观察部分成员、后来怎样调整范围，要在看图时考虑，不能根据最终赢家事后固定成员。 |
| 找到的背景经常很短，或经常发生复杂错位 | 这是框架可能需要调整的发现。不能只留下少数容易讲的片段，再称这种背景大量存在。 |

共同观察区间与各品种自身的大尺度线段不是一回事。前者可覆盖后者的一部分，但选择范围的依据要说清；其结束只能随新信息逐渐确定，不能在开始时使用事后完整的区间。

**“这种情形是否经常出现”就放在上述查找过程中看。** 区分当时曾提出多少候选、后来怎样变化、哪些能够持续观察；同一过程的相邻切片不重复充当多个实例。第一版先形成对常见程度和常见困难的认识，不预设次数门槛或全面统计工程。

### 4. 候选背景已有所指后，再看其中的中尺度结构

这一步先检查“有没有足够的结构可以讲事情”，不提前研究“谁更好、怎样选”。

| 要看什么 | 具体要回答什么 |
|---|---|
| 当前可取得哪些中尺度对象 | 在各自大尺度背景及目前共同观察范围中，有多少已确认的中尺度转折和完整线段？哪些部分仍在发展？ |
| 结构怎样分布 | 中尺度变化分布在整个已观察过程，还是只集中于某一小段？不同品种的共同观察部分里是否都还有可供研究的结构？ |
| 边界怎样对应 | 中尺度线段是否跨越所选范围？保留完整对象及截入部分的区别，不把窗口内的一截冒作完整线段，也不默认不同尺度端点严格嵌套。 |
| 当前是否已值得进入细节观察 | 已知结构是否足以提出具体业务问题？若不足，继续随时间观察；不能因为后来补出了很多转折，就说较早时已足够丰富。新确认信息可以补充前面实际发生的对象，但从收到时才可使用。 |
| 框架是否需要调整 | 若反复找到的大尺度背景内确实只有极少中尺度结构，或可知时已经缺乏后续观察空间，应调整尺度搭配或场景，而不是强行凑出“多轮推进与回落”。 |

不需要等大尺度线段最终结束、证实它全程合适，才进入第二层。**当时已经能说明候选背景、且已有中尺度结构足以研究，就可以开始细看；后来背景改变，再返回第一层重新判断。** 回看完整过程有助于总结框架，但不能反过来筛掉当时合理提出、后来失效的候选。

## 四、第二层：在具体背景内，形成并修正用例细节

第一层提供的是“哪些品种、哪些大尺度对象、怎样的当前共同观察范围，以及其中已有的中尺度结构”。成员差异能否清楚表达、怎样利用规律选品种，放在这一层解决。

| 要观察什么 | 具体要回答什么 |
|---|---|
| 明确实际对象 | 本例的前一段推进、本次中尺度向下线段（回落）、当前未完成部分分别指哪些对象？用图上位置或对象标识与AI对齐。 |
| 找准现象与候选规律 | 哪些转折接近或错开，哪些向上线段延伸较多，哪些向下线段侵蚀较多？这些表现及其前后变化，有什么可利用的对应规律？不要求解释其形成原因。 |
| 提出当时的具体判断 | 截至T已知什么？利用这些信息，认为哪个或哪些品种在什么后续过程中可能推进更充分、反向负担更小，或者暂不选择？推进与反向分别判断，不相互冒充。 |
| 随时间更新 | 新行情和特征确认到来后，新增或修订了什么对象和属性？原判断应维持、削弱、撤销还是改选？背景本身变了也要重新处理，不能只在固定区间里比较数值。 |
| 对照实际后续 | 判断之后实际形成了什么推进、回吐和反复？哪项预期得到支持、哪项失败？已发生结果与当时前提分开，不能用最后涨了掩盖途中反向。 |

预期得到的是一个具体初版：**在怎样的大尺度背景中，哪些中尺度对象表现了什么现象；当时何种信息已可知；利用什么候选规律，对哪些品种的哪段后续作了什么判断；后来信息和结果又怎样改变这个判断。**

可以先通过人看图、与AI快速交流把一种情形讲实。不要求先穷尽反例、解释因果机制或证明普遍有效，也不能用未来信息把候选规律包装成已能提前判断。

## 五、图上初步需要怎样表达，才能看懂上述分析

**确认点必须从第一层查找背景时就画清楚，不能只在第二层检验判断时再补。** 下面是待核对现有能力的展示需求，不是已经实现的绘图方案。

| 图面需要表达的内容 | 希望人能直接理解什么 |
|---|---|
| 多品种共同时间轴与当前观察时刻T | AI这一步站在哪个时刻，正在比较哪些成员；T之后内容不能参与这一步判断。 |
| 大、中尺度转折及方向 | 哪个对象是哪个尺度、什么方向；优先使用已有特征方向含义，不能只凭图形高低猜方向。必要时再展开小尺度，避免全部叠加难以阅读。 |
| 实际点与确认点的明确对应 | 同一对象用可识别的编号或关联标记连接实际位置与确认时刻。确认信息有实际价格坐标才画在对应位置，没有则放时间标记区，不补造确认价格。 |
| 到T真正可用的对象与当前发展部分 | 在逐时观察视图中，未到确认时刻的最终转折不作为已知对象显示；已有候选输出可以单独标明。完成线段与未完成部分区分，未来终点不提前画出。 |
| 候选背景及其变化 | 展示“哪段实际过程被指向”与“何时开始获得这一背景认识”两个不同位置；观察区间随新信息更新，不预画事后才知道的结束边界。 |
| AI分析与图的对应 | 每次说明当前T、新取得的确认、受影响的点或线段、候选背景怎样变化及尚待判断处，使人能逐项在图上找到。 |

例如，一个实际低点发生在较早位置p，但到当前c才确认：在c之前的可知视图里，不能把p画成早已确认的转折；到c时，才显示这次确认所指向的p，并同时标出c。人于是能看懂“现在新知道了一个更早发生的转折”，而不是误解为p时就能据此判断。

完整历史特征图可另作回看参考，但须与当时可知视图区分，不用它的未来端点或后来才显现的整齐程度帮助当时选背景。未到T的最终特征若只是淡化、仍能看见，也可能影响选择，不能当作严格的当时可知视图。

初版不一定要新建完整回放工具；可先利用现有图和若干关键T的状态说明或快照。关键是确认对应、对象可知范围和未完成状态表达正确。若现有数据不能恢复某个时点的状态，应明确缺口，不把“能画最终历史图”当成“能还原当时”。

## 六、观察结果怎样反馈设想

**大尺度背景难以在当时识别，或其中中尺度结构普遍不足，先改框架；背景和结构可研究，具体现象或判断不对，就在第二层改用例。**

当初较简单、后来变复杂的过程，应保留“当时怎样理解、后来新增什么、如何改变认识”，不能为了第一版简单而抹去。可以先把当时可解释的部分讲清，再记下新出现的难题；是否换另一个候选，依据当下缺口决定，不按最后结果筛选。
