# 启动、管理调用与实际接续

执行修订：`2026-09-21-coordinator-dispatch-v2`。管理职责DR06，专业题DR12，工作/上下文DR13，结构DR14继续适用。协调者唯一操作与可发送正文为[Overlay08](../overlay/08_自然语言运行提示_v0.3.md)，本页不另维护共同立场模板。

## 1. 管理何时发生

任务启动/重大要求变化、方向需重判、阶段交付、质量或投入偏离、重复失败/长期无主体进展，交管理Pro。已有有效安排继续，不因恢复聊天重开启动会。每批绑定具名RESULT、CHANGE和EFFORT；专业者报告业务事实，主控依既有条件投递，不能临场裁重要性。小检查点不自动问全套管理题，同责任信号合并去重。

管理取得Owner完整目的、直接纠正、全工作位置和本次相关原文；地图/候选/待办都需核适用，不能预锁成修绿当前包。发现根本方向或主体遗漏即处理，不等旧循环结束。无新commit可能需管理，持续commit也可能无有效收拢。

## 2. 动态判断与固定输入分开

管理题沿DR13的M-START/M-REASSESS/M-CLOSE；兼任审查要满足真实独立性和负担，不硬塞重审与重型规划。固定运行职责/目标选源/模板由repo维护；管理者只交当前实际认识、首版/停止/继续取舍、全目标预测及后继要求，不每轮生成通用管理教程。

本轮可局部深读，完整目标责任不缩减。旧成果保留不锁旧路线；可以保持原计划但须有当前依据。管理未完继续同工作，不签依赖半份判断的新方向，无关合法工作继续。机械发布和格式补交不冒充全局管理。

## 3. 任务与正常续作

动态专业任务按DR14写既有BINDING：完整范围、当前结果/重点、题mode、必要原文、完成/预算和实际路线，字段引用必须有实质正文。直接用既有正文，不造缩水摘要；普通题外必要内容可有据处理，不凑方案/问卷。

BI-01 的执行 Pro 按当前具名特征及有权任务，围绕初始参数、特征展示、aidata 实际制图、正确性与普通投资者正常解读的观察，交真实结果和未完；四项可往返，不等于四个硬阶段。只有明确、有权 Worker 工单才用工程委派；管理 Pro 在接收时需要图/平台现场核验，按已授权限定工单交 Worker，技术结果回管理而非自动认定接收。上游交付必须经管理 Pro 认可，才可派发依赖该范围的下游；原任务内最新 continuation 由承办者交，但不越过未满足的依赖，不每轮管理重签；完整 scope/mode/Gate/预算和 RESULT/CHANGE/EFFORT 仍沿正式 Binding。

## 4. 审查与回修

独立审查读exact候选和专业方法，实际复做有影响判断，不信Builder自评。候选、只读探针、独立审查、管理接受和生产资格分开。旧判断在同版本/范围/依据下复用，新证据定向重审。finding可被有依据拒绝，根因关联修订可作，不能审查偏好变唯一解或普通返修全线停。

不同性质的工作不能互相冒充：参数或画法说明不等于真实制图，图/CSV 可读不等于形成专业观察判断，技术修复不等于投资业务结论或 Owner 接收。对BI-01有依赖的交接还须区分专业提交、管理认可、下游已签发与实际派发；原已交候选不能自动取得管理认可。旧 I2–I6 是历史方法和运行结果，不成为新任务阶段。错误要修真实任务和后继，不靠改名字/状态；完整义务保留。

## 5. 双责任与真实消费

解析主动作后核全部trigger；CONTINUE不消除到期非阻塞管理。无回答/恢复/时钟更新时也核原起点，重复或在途责任不再发，新证据附原责任。管理报告只有实际进入任务/地图/预算/后继或明确有据保持，才算消费。换SHA或周期不清零投入和义务。

## 6. 投递与发布

全部新消息按Overlay08、工具按12、回交按13。主控只搬已确定原文与真实位置；不能自行概括Owner目的、加禁令、改业务重点。字段缺定向补，主体缺实际续作，未知派发效果先对账。既有回交单次有限恢复保持。任务已成不因管理缺回执重做业务。

写前fresh核当前head/在途/任务版本，普通快进保留并行，提交后回读。记录准备、实际发送、结果消费的不同事实；本仓工具无手机或调度器，不虚报后台执行和自动语义通过。旧gate误挡具名处置，不静默绕过。规范采用从下一次合法调用起，不追造旧资格。
