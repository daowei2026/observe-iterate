# 专业问题与方法的取源入口

本文件不再维护第二份专业工作定义。每次运行的业务目标取 `COORDINATOR_DISPATCH.json` 中该 work 的 `goal_ref`；实际题面、完整任务及适用方法取真实 Binding/task/source_reads。当前候选导航为 [professional/README.md](../../professional/README.md) 与 [TASK_ROUTER.md](../../professional/TASK_ROUTER.md)。

管理模式 M-START/M-REASSESS/M-CLOSE 分别用于真实首次管理、复看和收拢；专业模式与人读名称取本次配置，不硬编码四项工作、S1–S3 或某个特征。INDEPENDENT_REVIEW 仅在真实委派和方法资格成立时使用，不因模板存在就通过。

source_reads 按准确 commit/path/selector 提供正文、用途和读取范围。专业者实际取得本轮承重资料；索引、hash 和历史回执不替代正文，已读未变且可恢复时复用，不每轮考古全部历史。

通用角色方法、工单、Return 与管理接收不因专业替换改变。Worker 结果回原签发 Pro，专业和管理接收各按真实权力与范围；没有实际 Owner GO、run 或采用关系的新任务不得派发。旧工作恢复使用其原准确来源，不把当前方法无痕覆盖到旧 task。
