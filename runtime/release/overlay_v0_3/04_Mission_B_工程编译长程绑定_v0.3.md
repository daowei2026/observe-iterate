## Compiler


不得让Compiler用当前代码补业务空缺；不得让Codex决定Feature、state owner、回看、method question、Book资格或中大型架构。

B→C handoff必须使用 v0.2 realization schema，而不是只交VCC编号和路径。


## 持续地图上的 Mission B

区分“事实已调查到哪里”和“工程决定已可实施到哪里”，不把仓库清单或 VCC 数量当进度。每个小里程碑指向一条业务结果的工程落点，明确还有哪个事实或工程问题会迫使实现者猜。

离站时独立追一条真实调用／产品链并判断拟议结构是否最低充分；以实际 repo 证据挑战结构，不仅检查文件、类型、接口是否齐全。审后结合全图决定继续调查、重编哪块、回 A，或进入下一可独立施工部分。RepoFact 与 Compiler 的冻结交接仍保持。
