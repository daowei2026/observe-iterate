# BI-01 观察迭代长程运行覆层（候选）

当前 BI-01 协调者入口沿用原 CYF 长程机制的可复用部分，具体专业目标与 Gate 以本仓 `professional/` 及真实有权任务为准。候选身份 human_led_candidate、validated_runnable:false 保持；通用工具和历史测试不证明 BI-01 真实运行成熟。

## 按角色读取

协调者/routine直接使用[08唯一日常操作入口](08_自然语言运行提示_v0.3.md)，固定规则和源配置由repo维护，详细字段查[13](13_角色回交与主控接续协议.md)，工具查[12](12_管理接收与地图校验.md)。正常搬运无需先读全套专业方法。

BI-01 执行 Pro 从[专业当前入口](../../professional/CURRENT_EXECUTION.md)、[六阶段合同](../../professional/source/00_AGENT_CHARTER_AND_STAGE_CONTRACT.md)、[专业来源索引](../../professional/source/INDEX.md)及本次有权 Binding 取得适用完整方法，并按[DR00](../dual_route_execution/DR00_START_HERE.md)、Overlay01/02/07/11履行对应运行要求。专业 TASK_ROUTER 尚缺时不以 CYF 的 A/B/C router 或 mode 补造授权。首次/新上下文/失效按专业原文读取，已读未变且可恢复时复用。执行者交真实成果、完整回答和证据，不维护全局图或自签 Gate；管理 Pro 负责推进图与阶段接收。

管理/审查使用DR06/DR08、适用管理题和专业方法；本覆层09维护完整图/投入，10专业审查与独立全局判断，11保存实物，12接收工具。先核完整Owner目的、全部重要剩余、旧路线和首版尺度，决定停止/继续/交接并落实后继。小检查点不加管理会，到期非阻塞管理仍须实际投递，管理未完接原事项。

## 完整专业责任

BI-01 以[总意图和 I1–I6 Input/Output/Gate](../../professional/source/00_AGENT_CHARTER_AND_STAGE_CONTRACT.md)为完整专业合同。管理 Pro 依据真实成果签发任务、判断 G1–G6 阶段使用资格和合法后继；执行 Pro 完成被委派阶段的实际观察、反证与自查；有真实技术工单时 Worker Codex 才补算、制图或处理工具；独立审查、管理 Gate 和 Owner 重要决定不得混为一谈。CYF Feature、Reflex、CEPS 或 A/B/C 的工程责任不是 BI-01 默认前置。

## 连续性与证据

CYF v0.2 继承说明仅作历史来源，不自动迁移为 BI-01 授权、已通过 Gate 或在途记录。真实 BI-01 任务采用时须核对已经形成的成果、完整 scope、预算与在途；存在的有效事实保留，未知不填。历史只作适用依据，不全量灌入。提示已有协调者归档时引用，不让专业者重复抄；必要原任务/parent缺口仍要取得，不以不补历史为由跳过。

规则发布、本地测试、真实采用、独立接受、生产完成分别报告。旧manifest/seal只证旧字节；新入口按exact提交使用。工具不自动调度/授权/接受业务，无现场记录不称不可绕过。本轮不新建服务、状态库、监督Agent或手机轮询。
