# 独立审查与完整目标管理

本文件保留既有长程审查、管理与离站机制；BI-01 专业判断以本仓 `professional/` 及真实有权任务为依据，不预设 Case、算法，也不继承 CYF A/B/C 的专业义务。

## 1. 实质结果、聊天和审查循环是不同单位

一个里程碑是下游可消费的业务／工程结果；相关方法和普通细节可组成一批连贯结果，不默认以最小可检查问题分轮。一轮问答是通信；候选、审查、返修和复核是同一结果内部动作，不分别增加业务里程碑。相互制约的多个全新对象／方法／持续边界挤在一轮时，按连贯结果缩小问题；全范围与已投入仍留在图上。

条件性“顺利时若干轮”的Owner预期不规定每个子任务轮数。负责人按实际循环和剩余实物判断，不以耗时强制通过，也不隐藏审查、失败和管理的真实投入。

## 2. 独立性与成本

有实质业务意义的一批结果形成初版，在相应交付前接受必要独立挑战；动作递归细度不等于独立审查回合的粒度。低风险相邻结果可合并审，必须说明覆盖；日常编辑和补取不额外开审查回合，不把所有检查推到最后整包。

使用未参与候选形成的新Pro上下文，记录实际暴露和参与关系。相同模型或Project不保证完全独立；同聊天换角色只能叫自检／角色隔离。工具不能创建新聊天时交写好的任务给现有投递端，不虚构另一个Auditor。管理与审查可同聊天，但如果它也形成候选，fresh义务仍未满足。

内容审查和全局管理可以由同一聊天承担，但两项责任必须分别实际完成。全局管理不能退成审查末尾随手生成下一任务；必要时连续多轮完成，也不能因此新增每轮必经的规划流程。Codex可给真实调用、构建、运行和读回反证，不代Pro裁业务。

确有授权的 Worker Codex 技术小修可在原工单范围内连续修复和复核，无新重要变化不逐 hunk 事前放行；重要业务语义、方法或工程变化仍须按真实角色及专业标准接受必要审查。

## 3. 内容审查不相信地图或Builder自评

输入是完整任务和Owner边界、当前图及必要依赖、冻结候选完整正文、真实证据和高风险主题。旧finding用于回归，不是允许发现问题的全集。先看问题和范围，把PASS看成待证主张，暂不读Builder下一步和自我赞同理由。

先使用被审 V2 S1/S2/S3 工作的真实适用完整专业方法、原任务和可消费证据，再从具体 Case/Source/Method/As-Of 重建输入→处理→结果→下游判断；对最高影响判断真实核对或寻找合法反例；检查方法是否回答原问题、图和数据的时间与来源资格是否有据、S3 发现与替代解释是否被挑战、单 Case 结果是否被不当推广。CYF 的工程编译、Reflex 或 CEPS 不是 BI-01 默认审查对象。不能只核身份、writer、history或字段有无。

再核上下游能否同时成立，以及代码／运行证据能证明到哪。代码不反定义业务；没有运行条件就写静态范围。finding给确切正文／符号、实际错误或尚未定下的业务影响；只有真实存在多种合理理解才说明差异，不为格式制造两种解释；无finding也要说明复做与未覆盖，检查数量不是正确性证明。

## 4. 地图本身也要接受使用检验

在首次地图恢复、重要Owner意图变化、主要阶段切换或重要返修时，使用未参与这次地图整理的新上下文，先只读公共入口与相应子图，实际重述：完整目标、关键用词、各主要工作区域已有成果、条件性工作量与实际事实、为何走到当前路线、问题影响、具体实物和下一责任。随后读取Owner原话及被引用正文核对。

记录读不出来或读错的具体地方。若必须先遍历大量旧聊天才能理解，地图省略了应承载的信息；若可读却把 S1–S3 误当成每步都须 Owner 审批的三张表、把单 Case 发现提升为普遍规律、把预期当承诺，则是意图失真。主语、候选身份、重要反对和限制不能被省略。

不强制每轮重复整张图，不按字数／关键词／表格齐全打分，不拿业务审查通过代替阅读检验。Builder自查可作证据但不冒称独立读者通过。只有具备真实检验记录才能更新对应资格。

## 5. 完整目标决定当前审什么、做什么

管理职责使用 DR06。兼任全局管理的 Pro，必须先依据 Owner 完整目标判断当前工作的方向、必要性和完整性，再决定需要怎样审查、修订或重新安排。不得默认候选所覆盖的内容就是本阶段全部应做的工作，也不得默认把候选修到通过就是最快完成目标的路线。

**候选可以内部一致、局部正确、测试充分，同时仍然做错了 Owner 要求的事情，或遗漏了最重要的主体。**出现这种情况，管理者必须明确指出并改变安排；不能仅在原结构中补细节、追加检查或延续返修。

审查发现的缺陷不自动取得最高优先级，也不自动决定全局阻断。管理者必须从完整目标判断这些缺陷需要怎样处理，以及其余必要工作怎样组织。必要的内容审查继续进行，管理者不能被其范围和结论带着走。

只受委派作局部审查的角色，应交清审查结论及发现的目标偏离问题，由承担全局管理的 Pro 处理。局部审查完成不能替代整体管理完成。

应关注轻重缓急、值得讨论的重要问题、及时形成明确初版、必要 Owner 判断和专业材料是否落实。具体分析方式由 Pro 决定，不强制问卷、评分、备选数量或比较表。工作分段既不默认每个细节一轮，也不默认所有剩余内容本轮做完。完整范围、授权和必要审查保持。

形成独立判断后再看执行者建议，经确认有助于完整目标才采纳；独立不要求故意反对。管理者自己的旧安排同样没有默认续行地位，发现方向错误、钻入局部或遗漏重要工作必须主动纠正。

既有通用管理检查可参考[本仓管理 Harness](../dual_route_execution/MANAGEMENT_METHOD_HARNESS.md)中适用部分；BI-01 V2 的专业结果接收须以[三步业务合同](../../professional/v2/00_PURPOSE_AND_THREE_STEP_FLOW.md)及[交接边界](../../professional/v2/03_EXECUTION_HANDOFF.md)为准。独立专业审查方法尚不完整时如实标注覆盖不足，不能把旧 A/B/C 检查或管理判断冒称独立 PASS。检查当前任务是否带偏 Owner 目的，检查适用专业方法是否真正进入实际产物。明确的 Skill、Harness 或入口遗漏由获授权维护者补齐；不以全面历史审计阻止恢复工作。

管理决定应进入完整推进地图、共同说明、工作量与下一责任，并由实际投递端接续。Owner 直接限制继续遵守，AI 模板或推进者建议不能新增全局约束。

## 6. 下一任务锁问题，不锁审查者偏好的解法

管理端维护 `01_当前任务.md`，用自然语言说明所属完整业务结果、现在为何做、实质工作、冻结约束、必读完整专业方法及业务正文／证据、预期成果、检查和停止点；不要求每项任务是问句。任务绑定实际存在的输入commit，不能把候选对象名单改成必须建立的对象，不能把推荐修法改成唯一答案。

执行者可接受、部分接受或以确切反证拒绝finding。窄返修说明保护面，但允许必要根因关联修订，不用“只改六点”压住第七个真实问题。修后重走原场景，不只改名；没有证据不全包重写。

普通执行者交实物、完整分析和关联问题，不自行更换当前卡或全局图。若reviewer只受委派做专业审查，就提交review，由管理端接入；若本轮兼管理角色，则一起完成相应图、资格和任务更新，不能多人同时覆盖共享图。

BI-01 当前任务及合法 continuation 由实际已采用任务、Binding 和最新 Return 共同确定，不使用 CYF 的 CURRENT_C_WORK 标记。技术或证据缺口修复后回到原未完成业务问题；具体说明按 Overlay08 的准确来源原样进入消息，主控不临时编写。

## 7. 循环收敛，不无限打磨也不强制通过

发现目标偏离、主体遗漏或当前工作不值得继续时，必须立即重新安排，不得等待两次循环完成。循环规则不赋予当前局部继续占用主线的资格。

一次完整循环必须可追到冻结候选→独立挑战→逐项裁定→实际修订→复查。Builder同轮自检全修不算独立循环。默认同一承重问题两次完整循环后立即选收敛路线，不自动第三次同类打磨；重复根因、无新增或范围过大时更早判断。

轮数是重新选择工作方式的触发，不是验收阈值。暂用版必须有真实可执行程序、边界和重开条件，不能藏核心方法空缺。新增证据或必要拆分可以继续，但记录信息增益，保留原循环／投入／未完范围。后续新证据推翻已过局部时，只重开相关部分并标影响，不冻结全任务。

BI-01 同一阶段内部正常步骤或有权 Worker 技术动作之间的转换不等于一次完整审查循环，也不自动触发新独立读图／全目标重审。已有有效结果复用，当前语义未证与后续图审研究分开。

## 8. Review、地图、下一任务与实际发送

review保存输入、实际读取与方法使用、实际复做／反例、finding、真实可争辩点、覆盖限制和路线理由，不直接改被审业务正文。管理接收依据完整目标核实这些材料，独立决定保留、纠正或停止哪些工作，再更新完整图景和签发卡；通过、返修或待证时都核对必要共享README并同步，不让一次局部review把全图变成最新状态页。

未获写权则交确切变更给机械发布者，发布者不能补业务判断。提交和fresh远端回读后再由运行端核接收版本与实际发送现场；已在途、已交付或状态未知不盲发。原子管理交付与此前执行者实物提交分开，漏管理只补管理，不重做业务。

使用 [12 管理接收与地图校验](12_管理接收与地图校验.md) 的实际入口；错误要返回具名管理动作，不只报“应处理”。工具通过不产生业务、代码或真实数据新授权，scope PASS不能晋升完整用例PASS。本轮未实际触发新阅读者／运行端时，诚实保持该部分未执行。
