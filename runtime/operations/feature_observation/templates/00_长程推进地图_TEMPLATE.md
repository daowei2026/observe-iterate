# 具体特征观察：非活动长程地图模板

**仅供取得真实新 Owner GO 后，由有权管理 Pro 结合当次任务填成真实地图。** 本模板不是地图、任务、业务成果、Workmap Intake 或运行授权。新 run ID 与源码/数据版本不能从旧 V2-02 自动继承。

<a id="goal"></a>
## 1. 完整业务目标及具体特征

由新的 Owner 完整目的、当前实际具名特征与其合法输入输出确定；参考 professional/feature_observation/00_PURPOSE_AND_FOUR_WORKS.md。

<a id="stage"></a>
## 2. 四项可往返专业工作及当前重点

初始合理参数、特征展示方式与实际Uplot画通、aidata平台观察交付、正确性与普通投资者正常解读观察。**这是工作内容不是四个阶段 Gate**；地图按真实依赖写出上游交付、管理Pro认可的确切范围以及可派下游，无依赖可并行，需返修可返回。

<a id="evidence"></a>
## 3. 实际特征、源码/数据与适用专业资料

准确写明具名特征、本次实际实现/方法及结果来源、实际能取得的输入/输出和条件；U2/U3、历史 S1–S3、旧 ZIP 等只按本次需要引用，不能默认绑定。

<a id="progress"></a>
## 4. 已取得的专业成果及可核对依据

记录四项专业工作实际完成的内容、相互影响、有效发现与附加分析；不因存在格式就假造全部完成。

<a id="remaining"></a>
## 5. 完整目标剩余与当前必要条件

写实际未完的专业问题、必要工具/数据/展示事项、对持续运行可能有影响的已知问题及待决。

<a id="management"></a>
## 6. 管理接收、Owner 待决、投入与复看

由真实有权管理根据专业进展形成。

<a id="next"></a>
## 7. 下一步实际签发与精确来源

仅记录真实任务、具体责任者及合法后继，不以模板预填承诺或授权。
