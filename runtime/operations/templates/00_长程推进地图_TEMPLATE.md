# 非活动长程地图模板

本模板只给结构；不是任务、成果、Intake 或授权。真实 Owner GO 后，由有权管理根据本次采用的完整专业目标填入。新 run 不继承另一运行的版本、状态或接收。

<a id="goal"></a>
## 1. 完整业务目标与预期产出

引用本次准确目标和专业方法，写清研究对象、完整终点与输出用途；不从模板推导业务。

<a id="stage"></a>
## 2. 实际工作关系与当前重点

以产出之间的真实依赖组织工作。方法内部步骤不自动成为阶段 Gate；有接收依赖时记录实际范围，无依赖可并行。

<a id="evidence"></a>
## 3. 实际输入、工具与适用来源

记录真实数据/代码/方法身份、可取得范围和缺项，不把技术准备写成专业成果。

<a id="progress"></a>
## 4. 已取得的专业成果

记录实物、已成立的认识、证据范围与接收；不预填完成。

<a id="remaining"></a>
## 5. 完整目标剩余

记录实际未完、直接依赖、重要待决和对后继的影响，不复制已撤任务。

<a id="management"></a>
## 6. 管理接收、Owner 事项与投入复看

由真实管理决定填写，保持原投入及真实触发关系。

<a id="next"></a>
## 7. 实际后继与准确来源

记录真正签发的责任者、工作和条件；不以模板授权。
