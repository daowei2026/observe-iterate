# 非活动当前任务模板

仅供真实 Owner GO 后有权管理形成任务；不是已签发消息。实际 task_id、run_id、版本、角色和引用必须真实填写，不把占位符发送。

## 完整目标和本次约定产出

保留本次完整目标、范围和完成含义；当前重点只决定顺序，不擅自缩小完整责任。

## 当前要完成的实质工作

依据已有成果及全部重要未完安排；具体工作名和方法取本次专业来源，不在通用模板预设。

## 输入、方法和实际依赖

列准确 source_refs/source_reads、已可消费的实物及限制；解释必要依赖，不为每个普通步骤新增 Gate。

## 技术工作与写权

需要 Worker 时给原签发 Pro、return_to、真实输入、环境、版本、输出及实际写权；无需技术工作时不创造一项。

## 交付和后继

说明实质产物、Owner 查看入口、实际回交位置及未完处理。格式、字段、触发与路由沿 DR14 和现有 Return 协议，不发明新 schema。

## 真实采用与 QUESTION_WORK_BINDING

由有权责任者填写真实 question-work/v2 Binding、完整任务位置和采用依据。模板不生成假 ADOPTED、Intake、派发或业务 PASS。
