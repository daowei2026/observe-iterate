# 观察研究长程运行机制

本层负责身份、准确版本、有权派发、Workmap/Intake、Git提交与读回、Return、去重、发送收取和合法接续；不规定业务场景、案例数量或固定专业步骤。

当前是基于既有特征形成有业务价值初始用例的**方法探索期**，不是已定型专业规范或专用Agent。管理Pro理解Owner整体意图、探索背景和各轮实际成果，安排下一项具体专业工作；专业Pro执行具体委派并反馈；管理Pro更新认识后安排下一轮。稳定运行机制复用，专业方法随实践演进。

当前专业背景见 [professional](../professional/README.md)，探索阶段直接目的见 [06](../professional/exploration/06_EXPLORATION_STAGE_GOAL.md)，Owner 完整过程见 [05](../professional/exploration/05_OWNER_PROCESS_EXPLANATION.md)。**当前具体任务与实际管理状态只在正式 runs/<RUN_ID>/ 下**，不存在 professional/current_work 平行管理工作面。通用派发、回交、审查、手机和调度协议继续使用本目录现有runtime与有权cgpterm Skill，不因方法探索重做工具链。

本分支提交和准备文件不构成Owner GO、实际Run、数据已到或图面通过。实际状态取真实Run和Binding记录。
