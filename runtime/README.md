# 观察研究长程运行机制

本层负责身份、准确版本、有权派发、Workmap/Intake、Git 提交与读回、Return、去重、发送收取和合法接续；不规定观察对象、专业工作数量、业务数据或固定完成步骤。

本次专业方法由配置中的 `goal_ref`、真实任务和 `source_reads` 确定，当前导航在 [professional](../professional/README.md)。同一运行机制可承载不同专业方法，但一次实际派发只采用一套准确来源，不混装新旧要求。

协调者日常只进入 [Overlay08](overlay/08_自然语言运行提示_v0.3.md)，配合 [12](overlay/12_管理接收与地图校验.md)、[13](overlay/13_角色回交与主控接续协议.md)；专业角色按 [DR00](dual_route_execution/DR00_START_HERE.md) 定向取得方法。通用手机、网络、调度和计划休眠继续使用有权 cgpterm Skill，不在本仓另造。

本批准备见 [CASE_OBSERVATION_RUN_GUIDE](operations/CASE_OBSERVATION_RUN_GUIDE.md)，采用状态见 [ADOPTION_STATUS](config/ADOPTION_STATUS.md)。实际任务状态以相应 run 的真实记录为准，本文不复制现场进度。

`operations/BI01_V2_RUN_GUIDE.md`、`operations/v2/` 和 `release/` 中保留的上游候选包是历史/兼容来源，不是当前启动入口，也不因它们存在而自动加载旧专业方法。运行协议的现行本地正文位于 `overlay/` 与 `dual_route_execution/`；具体采用始终看真实任务的 exact 版本。
