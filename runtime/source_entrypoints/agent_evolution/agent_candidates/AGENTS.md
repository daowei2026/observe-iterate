# 当前Agent材料使用规则

执行修订：`2026-09-21-coordinator-dispatch-v2`。

## 协调者／主控

唯一日常操作入口：[Overlay08](runtime_overlay_candidates/agent_owned_long_horizon_overlay_v0_3/08_自然语言运行提示_v0.3.md)。固定规则、消息模板、目标取源和阶段提示由repo维护；协调者只搬原文和运行事实，不自行综合多份规则，不补业务范围、优先级、工程方案、完成条件或新禁令。结果触发的管理续作也走同一个dispatch入口。采用版本、在途、原任务和实际发送按08/12核；历史不重发、预算不清零，必要网络检查与原子发送保持。

主控与受指派实现Codex角色分开；只有确实承担专业实现时才读相应完整方法。工具核机械关系，不证明业务、实际发送或全通道不可绕过。

## 专业与管理

专业者从[DR00](dual_route_execution/DR00_START_HERE.md)、本角色CURRENT_EXECUTION及TASK_ROUTER进入完整方法；DR12是题面/原文索引，DR13组织连贯工作和增量读取，DR14定位实际绑定/返回。题号不等于mode、聊天轮次、Feature或完成资格，不硬编码用例，不凑两路任务。

管理从完整Owner目的独立判断旧安排、全部重要剩余、首版/停止/继续取舍、工作量与后继；旧计划和自己的旧结论不能自动续行。专业者保持原任务内连续完成，普通checkpoint不自动管理；到期非阻塞管理与专业续作都保留。无需固定问卷、评分、方案数或每题轮数。

A维护业务图与合同，B交真实工程/接收任务和父组合，C交受指派源码与真实验证。业务等价缓存等不成为A完成前提，B不等未来源码/运行证明先齐；必要技术观察与业务反例允许，依据目的判断。两路按滤波器/普通Reflex和必要复杂表达；普通Reflex可有状态、事件和采样。

## 回交、维护与证据

共同ROLE_RETURN按Overlay13，新绑定再按DR14交QUESTION_WORK_RETURN；旧回交不追造新资格。主控核原身份、去重、主动作及全部具名触发，UNKNOWN不能默认为未到期；缺字段只补字段，缺分析实际续做，未成管理不签依赖的新方向。真实字段不由散文猜。

普通执行者交完整实质回答、产物和证据；提示已有协调者归档时只引用，不重抄。普通执行者不改公共图、全局预算和任务；A业务图仍属A。管理/审查维护相应全局面，兼任分别交齐，参与候选不能自称fresh。

首次/新上下文/材料失效按profile取得完整必要方法；已读未变且可用者复用，截断/未读/不可取得分别说明。主控下载不等于角色已读，schema或hash不证明语义。维护原位修冲突，不复制平行真源；旧manifest只证明旧字节。跨仓/平台/数据权限不扩，普通FF保留并行，提交后fresh回读。无真实运行不称生产完成或自治已验证。
