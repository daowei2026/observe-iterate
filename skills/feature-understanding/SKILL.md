# 特征结构、对象与行为理解

## 1. 定位

本 Skill 是以下工作的共享前置：

- 特征全量行为统计与结构疑点发现；
- CAEGraph 观察材料准备；
- 合理性场景选择与场景预期设计；
- 场景过程证据对照；
- 偏差根因诊断。

它回答：

```text
当前特征实例真正对应哪份实现；
它消费、形成和更新哪些业务对象、状态与事件；
哪些是业务主输出，哪些是中间处理结果；
关键中间判断怎样参与对象形成、更新、结束或引用；
参数在哪里定义并被哪些判断消费；
实际运行结果里能取得哪些对象、状态、事件和中间字段。
```

本 Skill 不判断这些设计是否合理，只形成可复用、可追溯的实现事实与当前可确认的业务语义。

## 2. 输入

至少需要：

- 特征名称；
- 特征代码版本；
- 特征实例或可解析的实例引用；
- 可由上述信息定位的真实源码、类型声明、实例构造和公开读取接口。

不得使用同名旧实现、其他分支、文档样例或显示层字段替代当前实例的真实实现。

字段级格式见 [IO_SPEC.md](IO_SPEC.md)。

## 3. 核心输出：`FeatureUnderstandingPackage`

### 3.1 当前实现来源

记录当前实例对应的仓库、提交、文件、类型、构造入口、公开读取接口及各来源职责。

### 3.2 业务对象模型

记录：

- 业务对象类型；
- 对象身份字段和作用域；
- 创建、更新、确认、结束或替代该对象的 occurrence；
- 对象之间真实存在的父子、成员或引用关系。

### 3.3 事件级 occurrence 模型

记录输入事件、业务主输出事件、中间处理事件，每次 occurrence 的业务含义、发生位置、携带位置、对象身份、payload、产生位置和消费位置。

### 3.4 状态模型

记录持续对象或处理器实际维护的状态、初始状态、终止状态、合法转换、触发 occurrence 及状态持续时间的含义。

状态当前值、Dynamic、Behavior 或调试值不因可读取就自动被称为 occurrence。

### 3.5 关键中间判断模型

记录实际参与业务主输出形成、更新、解释或结束的关键判断，例如候选资格、局部分类、距离判断、门、计数器和内部状态。明确：

- 输入字段；
- 输出字段；
- 业务作用；
- 消费位置；
- 是否在运行结果中持久化。

### 3.6 处理关系与信息变化

还原形成、更新、确认、结束、引用、修订／替代等真实关系，并说明对象身份、时间位置和信息怎样沿处理链映射。

### 3.7 参数与运行结果字段映射

分别记录：

- 参数定义、默认／派生关系、消费位置；
- 运行结果中的表、字段、对象键、状态列、事件列和中间判断列；
- 当前运行结果中缺失但后续统计或观察可能需要的字段。

### 3.8 未确认项

代码事实不足、业务语义尚不能确认或运行结果无法映射时，明确记录所需新增证据，不自行补齐。

## 4. 与下游的边界

### 4.1 对全量行为统计

本 Skill 提供对象、状态、事件、身份、合法转换和可统计字段；不计算数量、比例、持续时间、密度或跨品种差异。

### 4.2 对观察材料准备

本 Skill 提供要展示的业务主输出、中间处理结果、事件位置和处理关系；不选择最终品种、时间或 CAEGraph 画法。

### 4.3 对合理性分析

本 Skill 提供“当前实现实际上怎样工作”；不把实现行为写成天然业务预期，也不选择正例、反例或判断设计合理性。

## 6. 异常和缺口

- 找不到当前代码版本或实例实现：返回输入定位缺口，不用其他版本替代。
- 代码可运行但业务含义不清楚：记录代码事实、候选解释和未确认项，不自行定业务含义。
- 只有显示层字段而找不到源对象或 occurrence：标记来源缺口。
- 代码中存在中间判断，但运行结果没有该字段：在 `RunResultFieldMap` 中标记 `NOT_EXPOSED`，不能冒充可统计或可观察。
- 需求文档与当前实现不一致：分别记录，不以需求替代实现，也不以实现证明需求正确。

## 7. 完成条件

- 当前实例对应实现已定位或明确阻塞；
- 业务对象、身份、状态和 occurrence 已区分；
- 业务主输出与关键中间处理结果已按业务角色分类；
- 对象形成、更新、确认、结束和引用关系可追溯到代码；
- 参数定义、派生关系和消费位置已记录到可支持后续工作的程度；
- 运行结果字段已映射到对象、状态、事件和中间判断，缺失字段已具名；
- 所有未确认项没有被写成确定事实。

## 8. 不允许做的事

- 不运行特征，不做全量统计；
- 不选择最终观察位置，不设计 CAEGraph；
- 不从图形字段反推源对象语义；
- 不把函数数量机械等同于处理阶段数量；
- 不把普通参数、Behavior 当前值、Dynamic 当前状态和调试字段无依据地称为事件 occurrence；
- 不宣布 Feature 合理或不合理；
- 不提出参数值调整、实现修正或设计变更。
