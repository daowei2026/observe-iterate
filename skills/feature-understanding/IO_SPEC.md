# 特征结构、对象与行为理解｜字段级输入输出

> 本文件定义共享 `FeatureUnderstandingPackage` 的字段。字段名称先采用中文与稳定英文标识并列，后续可由 Owner 统一调整。

## 1. 输入

### 1.1 特征基本引用

| 字段 | 必填 | 含义 |
|---|---:|---|
| 特征名称 | 是 | 当前被理解的特征名称 |
| 特征代码版本 | 是 | 能唯一定位当前实现的版本引用 |
| 特征实例 | 是 | 当前实际实例或可解析的实例引用 |
| 代码来源清单 | 否 | 根据前三项解析出的仓库、路径、类型与入口；U1 形成时可为空 |

## 2. 内部记录

### 2.1 当前实现来源记录 `ImplementationSourceRecord`

| 字段 | 含义 |
|---|---|
| 来源编号 | 本 Skill 内稳定编号 |
| 仓库与代码版本 | 实际读取来源 |
| 文件路径 | 源文件路径 |
| 类型／函数／构造入口 | 与实例对应的实现位置 |
| 来源职责 | producer、FRP、绑定、实例构造、读取接口等 |
| 已核实状态 | 已核实／部分核实／未定位 |
| 证据引用 | 代码行、提交或文件引用 |

### 2.2 业务对象记录 `BusinessObjectRecord`

| 字段 | 含义 |
|---|---|
| 对象编号 | 包内唯一编号 |
| 对象类型 | 业务对象名称 |
| 对象业务含义 | 当前可确认的一次持续对象代表什么 |
| 身份字段 | 同一对象怎样识别 |
| 身份作用域 | 同 run、跨 chunk、跨 run 或公开稳定身份 |
| 创建 occurrence | 创建对象的事件引用 |
| 更新 occurrence | 更新对象的事件引用 |
| 终止 occurrence | 结束对象的事件引用 |
| 父／子／成员关系 | 与其他对象的真实关系 |
| 当前状态载体 | 状态存储位置 |
| 代码证据引用 | 定义与维护位置 |
| 未确认项 | 仍不能确定的对象语义 |

### 2.3 状态记录 `StateRecord`

| 字段 | 含义 |
|---|---|
| 状态编号 | 包内唯一编号 |
| 所属对象 | 业务对象编号 |
| 状态名称 | 代码与业务名称 |
| 状态业务含义 | 当前可确认含义 |
| 是否初始状态 | 是／否 |
| 是否终止状态 | 是／否 |
| 进入条件 | 代码条件或 occurrence |
| 退出条件 | 代码条件或 occurrence |
| 合法前驱／后继 | 已实现转换 |
| 状态持续位置 | 当前状态怎样沿时间保存 |
| 代码证据引用 | 定义与更新位置 |
| 未确认项 | 可达性或语义缺口 |

### 2.4 事件级 occurrence 记录 `OccurrenceRecord`

| 字段 | 含义 |
|---|---|
| 事件编号 | 包内唯一编号 |
| 事件名称 | 代码与业务名称 |
| 事件方向 | 输入事件／输出事件 |
| 输出业务角色 | 业务主输出／中间处理结果／不适用 |
| 事件载体 | Event 或其他经核实的离散载体 |
| occurrence 业务含义 | 一次发生代表什么 |
| occurrence 自身发生位置 | 实际点、确认点、更新点、结束点等 |
| occurrence 携带的其他位置 | payload 内其他位置 |
| 主体／对象范围 | 单对象、多对象、组、参数方案等 |
| 身份字段 | 与业务对象怎样绑定 |
| 修订／更新字段 | revision、previous、supersedes 等 |
| payload 字段清单 | 见下一表 |
| 产生位置 | 类型、函数或处理器 |
| 消费位置 | 主要下游 |
| 公开读取接口 | 如存在则记录 |
| 代码证据引用 | 对应实现引用 |
| 未确认项 | 尚不能确认的语义 |

### 2.5 occurrence payload 字段 `OccurrencePayloadField`

| 字段 | 含义 |
|---|---|
| 所属事件编号 | 对应 occurrence |
| 字段名称 | 代码字段名或结构位置 |
| 中文含义 | 当前核实语义 |
| 数据类型 | 实际类型 |
| 单位／取值范围 | 如适用 |
| 是否可缺失 | 是／否／待确认 |
| 缺失时含义 | 无事件、无数据、未确认、有效空等 |
| 是否为位置字段 | 是／否 |
| 来源代码引用 | 定义或赋值位置 |

### 2.6 关键中间判断记录 `IntermediateDecisionRecord`

| 字段 | 含义 |
|---|---|
| 判断编号 | 包内唯一编号 |
| 判断名称 | 候选、分类、门、距离、计数器或其他名称 |
| 业务作用 | 它怎样参与主输出形成、更新、结束或解释 |
| 输入字段／状态 | 当前判断读取什么 |
| 当前规则 | 代码实际执行规则 |
| 输出字段／状态 | 产出什么 |
| 消费位置 | 哪些后续规则或对象消费 |
| 是否持久化 | 是／部分／否／未确认 |
| 运行结果位置 | 表、结构和字段；未暴露时标记 |
| 代码证据引用 | 实现引用 |
| 未确认项 | 语义或字段缺口 |

### 2.7 处理关系记录 `ProcessingRelationRecord`

| 字段 | 含义 |
|---|---|
| 关系编号 | 包内唯一编号 |
| 上游对象／事件／判断 | 关系起点 |
| 下游对象／事件／判断 | 关系终点 |
| 关系类型 | 形成、更新、确认、结束、引用、修订／替代、过滤、重排等 |
| 处理条件 | 何时发生 |
| 身份映射 | 上下游怎样保持或改变身份 |
| 位置映射 | 发生位置和携带位置怎样对应 |
| 可能信息变化 | 过滤、压缩、延迟、覆盖、重排等 |
| 代码证据引用 | 实现引用 |
| 未确认项 | 尚不能确认的关系 |

### 2.8 参数记录 `ParameterRecord`

| 字段 | 含义 |
|---|---|
| 参数编号 | 包内唯一编号 |
| 参数名称 | 代码／配置名称 |
| 参数类别 | 自由参数／派生参数／固定 preset／工程安全常量／实例身份 |
| 当前值或默认值 | 当前实例值；无法确认时记录缺口 |
| 单位 | Tick、价格跳数、比例、金额等 |
| 派生关系 | 从哪些参数怎样派生 |
| 定义位置 | 代码／配置引用 |
| 消费位置 | 参与哪些判断、状态或输出 |
| 影响对象／字段 | 直接受影响项 |
| 代码证据引用 | 定义与消费引用 |
| 未确认项 | 当前实例绑定或语义缺口 |

### 2.9 运行结果字段记录 `RunResultFieldRecord`

| 字段 | 含义 |
|---|---|
| 业务项编号 | 对象、状态、事件或中间判断引用 |
| 结果载体 | 表、DataFrame、JSON、状态轨迹或其他结构 |
| 字段名称 | 实际字段 |
| 可用状态 | AVAILABLE／PARTIAL／NOT_EXPOSED／UNCONFIRMED |
| 对象分组键 | 如 wall_id、track_id、segment_id |
| 时间键 | UTI、timestamp、actual／confirm 等 |
| 去重／同刻规则 | 同一对象同一时刻怎样区分 |
| 缺失含义 | 无发生、未暴露、无数据、有效空等 |
| 读取接口 | 公开或实际读取位置 |
| 证据引用 | 运行结果或代码引用 |

## 3. 最终输出 `FeatureUnderstandingPackage`

```yaml
package_id:
feature_ref:
  feature_name:
  code_version:
  instance_ref:
implementation_sources: []
business_objects: []
states: []
occurrences: []
intermediate_decisions: []
processing_relations: []
parameters: []
run_result_field_map: []
business_main_outputs: []
intermediate_processing_results: []
unconfirmed_items: []
completion_status: COMPLETE | PARTIAL | BLOCKED
```

## 4. 完成状态

| 状态 | 含义 |
|---|---|
| `COMPLETE` | 当前版本中影响全量统计、观察材料和合理性分析的核心对象、状态、事件、关系、参数及结果字段均已说明 |
| `PARTIAL` | 主要链已说明，存在具名缺口，但至少一个下游可在明确范围内继续 |
| `BLOCKED` | 无法识别核心对象、业务主输出、状态或结果字段，下游不能可靠开展 |
