# A｜字段级输入输出

> 本文件只定义本阶段及内部步骤需要交换的字段。字段名称先采用中文，后续由 Owner 统一审阅和调整。

## 1. 阶段输入

### 1.1 特征基本引用

| 字段 | 必填 | 含义 |
|---|---:|---|
| 特征名称 | 是 | 当前被观察特征的名称 |
| 特征代码版本 | 是 | 当前实现的版本引用 |
| 特征实例 | 是 | 当前实际实例或可解析的实例引用 |
| 代码来源清单 | 否 | 根据前三项解析出的仓库、路径、类型和入口；由 A1 形成时可为空 |

## 2. 内部步骤产物

### 2.1 当前实现来源记录

| 字段 | 含义 |
|---|---|
| 来源编号 | 本阶段内部稳定编号 |
| 仓库与代码版本 | 实际读取的代码来源 |
| 文件路径 | 源文件路径 |
| 类型／函数／构造入口 | 与特征实例对应的实现位置 |
| 来源职责 | FRP 实现、Python 绑定、实例构造、公开读取等 |
| 已核实状态 | 已核实／部分核实／未定位 |
| 证据引用 | 代码行、提交或文件引用 |

### 2.2 事件级 occurrence 记录

| 字段 | 含义 |
|---|---|
| 事件编号 | 本阶段内唯一编号 |
| 事件名称 | 代码与业务中使用的名称 |
| 事件方向 | 输入事件／输出事件 |
| 输出业务角色 | 业务主输出／中间处理结果／不适用；输入事件留空 |
| 事件载体 | Event 或其他经核实的离散发生载体 |
| occurrence 业务含义 | 一次发生代表什么 |
| occurrence 自身发生位置 | 该事件真正触发和发表的位置语义 |
| occurrence 携带的其他位置 | occurrence payload 内包含的实际点、确认点、已知点等 |
| 主体／对象范围 | 单对象、多对象、组、参数方案等 |
| 身份字段 | 同一业务对象如何识别 |
| 修订／更新字段 | 若存在 revision、previous、supersedes 等则记录 |
| payload 字段清单 | 见下一张表 |
| 产生位置 | 形成该事件的类型、函数或处理器 |
| 消费位置 | 主要下游使用点 |
| 公开读取接口 | 如存在则记录；不存在不影响业务角色判断 |
| 代码证据引用 | 对应实现引用 |
| 未确认项 | 仍无法确定的语义 |

### 2.3 occurrence payload 字段

| 字段 | 含义 |
|---|---|
| 所属事件编号 | 对应事件 |
| 字段名称 | 代码字段名或结构位置 |
| 中文含义 | 当前核实的业务含义 |
| 数据类型 | 实际类型 |
| 单位／取值范围 | 如适用 |
| 是否可缺失 | 是／否／待确认 |
| 缺失时含义 | 无事件、无数据、未确认、有效空等，不能混同 |
| 是否为位置字段 | 是／否 |
| 来源代码引用 | 定义或赋值位置 |

### 2.4 处理关系记录

| 字段 | 含义 |
|---|---|
| 关系编号 | 本阶段内唯一编号 |
| 上游事件／结果编号 | 关系起点 |
| 下游事件／结果编号 | 关系终点 |
| 关系类型 | 形成、更新、确认、结束、引用、修订／替代或其他经核实关系 |
| 处理条件 | 在什么条件下发生 |
| 身份映射 | 上下游如何保持同一对象或成员身份 |
| 位置映射 | 上下游发生位置和携带位置如何对应 |
| 代码证据引用 | 实现关系的代码 |
| 未确认项 | 仍无法确定的关系 |

## 3. 阶段最终输出

### 3.1 特征事件级 occurrence 与发生位置说明

| 字段 | 含义 |
|---|---|
| 特征引用 | 特征名称、版本、实例 |
| 输入事件记录 | 事件级 occurrence 记录引用 |
| 业务主输出事件记录 | 被判定为特征业务主输出的记录引用 |
| 中间处理事件／结果记录 | 形成、更新或解释业务主输出的过程记录引用 |
| 事件位置总表 | 每类事件自身发生位置与携带位置 |
| 未确认项 | 尚不能确定的事件、位置或字段 |

### 3.2 特征处理关系说明

| 字段 | 含义 |
|---|---|
| 处理关系记录 | 上述关系清单 |
| 业务主输出追溯 | 每类业务主输出向上游的真实来源链 |
| 输入事件去向 | 每类输入事件可能参与的处理及结果 |
| 代码证据索引 | 所有来源和关系的统一索引 |

## 4. 阶段输出状态

| 状态 | 含义 |
|---|---|
| 完整 | 当前版本中影响 B、C、D 的事件、位置和关系均已说明 |
| 部分完整 | 主要链已说明，但存在明确且不妨碍部分后继的缺口 |
| 阻塞 | 无法识别核心输入、业务主输出或其发生位置，后继不能可靠开展 |
