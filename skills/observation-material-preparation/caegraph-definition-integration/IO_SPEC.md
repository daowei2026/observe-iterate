# D｜字段级输入输出

## 1. 阶段输入

| 字段 | 必填 | 含义 |
|---|---:|---|
| 特征实例 | 是 | 外层给定的实际实例或引用 |
| A 阶段产物引用 | 是 | 事件、位置、字段和处理关系 |
| B 阶段观察位置定义 | 是 | 真实品种、时间及按需的多层位置 |
| C 阶段展示方式定义 | 是 | 面板、图元、转换与交互 |
| C 阶段预期展示 HTML | 是 | E 最终图的展示核对基准 |
| 数据与运行依赖引用 | 条件 | 能由实例解析时只记录解析结果；无法解析时列为缺口 |

## 2. 绑定记录

### 2.1 特征与数据入口绑定

| 字段 | 含义 |
|---|---|
| 绑定编号 | 稳定编号 |
| 特征实例引用 | 当前实例 |
| 数据／Feature 入口 | 实际类、函数、公开读取接口或结果文件 |
| 代码版本和路径 | 入口所在版本 |
| 提供的数据 | 价格、输入事件、业务主输出或中间处理结果 |
| 是否需要重跑 | 否／是／待 E 核实 |
| 缺口 | 当前入口不能提供的内容 |

### 2.2 位置绑定

| 字段 | 含义 |
|---|---|
| 位置编号 | 对应 B 的位置 |
| 品种集绑定 | CAEGraph 对象／板块配置 |
| 开始与结束时间绑定 | PlotSet、timespans 或等价配置 |
| 多层位置绑定 | 按 B 方法版本映射；不适用可为空 |
| 日历／数据范围 | 从实例或运行依赖解析 |

### 2.3 展示绑定

| 字段 | 含义 |
|---|---|
| C 面板编号 | 展示定义中的面板 |
| CAEGraph 布局对象 | 实际布局类与配置 |
| C 图元编号 | 展示定义中的图元 |
| A 来源事件／结果编号 | 真实业务来源 |
| 真实数据字段 | 横轴、纵轴、身份、hover 等字段 |
| 显示派生处理 | 具体实现及原值保留方式 |
| 绑定状态 | 完整／部分／缺失 |

## 3. 完整 CAEGraph 定义

| 字段 | 含义 |
|---|---|
| 定义编号与版本 | 交给 E 的稳定版本 |
| Python 脚本引用 | 完整脚本文件 |
| 特征实例引用 | 实际实例 |
| A/B/C 产物版本 | 本定义使用的上游版本 |
| 数据入口与位置绑定 | 上述绑定记录引用 |
| 展示绑定 | 面板与图元绑定引用 |
| 预期输出 HTML 路径 | E 运行时应生成的位置 |
| 定义级检查结果 | 语法、结构、字段与覆盖检查 |
| 待 E 确认项 | 只有真实运行才能确认的事项 |

## 4. 定义级检查结果

| 字段 | 含义 |
|---|---|
| 检查项 | 语法、引用、字段、配置、覆盖等 |
| 结果 | 通过／不通过／未运行 |
| 证据 | 日志、命令或人工核对引用 |
| 影响 | 是否阻塞 E |
| 修订目标 | A、B、C 或 D |

## 5. 阶段最终输出状态

| 状态 | 含义 |
|---|---|
| 完整 | 已形成可直接交 E 尝试运行的完整定义 |
| 部分完整 | 只缺真实运行才能确认的非核心事项 |
| 阻塞 | 核心实例、位置、字段或展示绑定缺失，不能可靠进入 E |
