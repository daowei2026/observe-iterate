# D｜字段级输入输出

> D 当前是一个单一集成动作，本文件只定义这一动作的整体输入、仓库理解记录、完整定义及输出，不再按 D1～D8 拆字段。

## 1. 阶段输入

| 字段 | 必填 | 含义 |
|---|---:|---|
| 特征名称 | 是 | 外层 Workflow 给定的特征名称 |
| 特征代码版本 | 是 | 外层给定、能定位真实实现的版本 |
| 特征实例 | 是 | D 要正式绑定进完整定义的外层真实实例或实例引用 |
| A 阶段产物引用 | 是 | 事件、发生位置、业务角色、真实字段和处理关系 |
| B 阶段观察位置定义 | 是 | 普通位置，或 1d→30m→1m→5s→tick 多尺度位置路径 |
| C 阶段展示预期 | 是 | 页面、面板、图元、时间、身份和复杂点处理结果 |
| C 阶段可注入展示代码 | 是 | 未固化 B 最终位置和外层真实实例的 CAEGraph Python 定义 |
| C 阶段实例注入合同 | 是 | D 应怎样注入真实特征实例、Feature／数据入口和字段 |
| C 阶段预期展示 HTML | 是 | E 最终图的展示核对基准 |
| C 阶段能力缺口 | 否 | 仍未解决的真实工具限制 |
| 锁定 CAEGraph 仓库版本 | 是 | 当前完整定义采用的 uplot／CAEGraph repo、ref 或 commit |
| 运行依赖引用 | 条件 | 不能从特征实例和仓库解析时必须说明 |

## 2. CAEGraph 仓库理解记录

| 字段 | 含义 |
|---|---|
| 仓库与版本 | 实际读取的 uplot／CAEGraph 精确版本 |
| 已读文件 | `__init__..py`、手册、`utlv2.py`、`utkv2.py`、`pfw.py`、`pdt.py` 及本次实际涉及的其他文件 |
| 正式导出与导入路径 | 本次脚本采用的类从哪里正式导出 |
| CAEGraph／PlotSet 配置链 | 本次页面如何由顶层配置进入布局和绘图器 |
| 布局类源码理解 | 本次采用布局类及关键参数、对象组织方式 |
| 绘图类源码理解 | 本次采用绘图类及其 `feat`、`df_key`、时间／数值字段合同 |
| 特征实例进入路径 | 外层实例怎样进入绘图器、Feature 数据接口和 `PlotCtx` |
| 位置进入路径 | SOF、日历、品种、时间和多尺度位置怎样进入上下文／`timespans` |
| 数据到 CDS 路径 | DataFrame／Feature 数据怎样转换为 Bokeh CDS 和图元 |
| 构图数据树 | `PlotDataFolder / PlotDataNode` 怎样对应最终图数据 |
| 动态与前端路径 | 本次是否使用 DynStd、控件、JS 回调、server；若使用，真实代码路径是什么 |
| 尚待 E 运行确认 | 只能在真实环境确认的事项 |

## 3. 完整定义集成记录

| 字段 | 含义 |
|---|---|
| C 代码编号／版本 | 本次采用的 C 可注入代码 |
| C 展示预期版本 | 该代码必须保持的展示语义 |
| 预览实例绑定 | C 生成 HTML 时是否临时使用实例；D 如何替换 |
| 正式特征实例绑定 | 外层真实实例注入到哪些构造器、参数或数据入口 |
| Feature／数据入口绑定 | 价格、输入事件、业务主输出和中间结果的正式读取入口 |
| 普通位置绑定 | SOF、钢铁板块／任务指定品种、开始和结束时间怎样进入代码 |
| 多尺度位置绑定 | 1d、30m、1m、5s、tick 节点及父子关系怎样进入代码；不适用可为空 |
| A 字段绑定 | actual／confirm／known、身份、数值、hover 等真实字段如何进入图元 |
| C→D 代码差异 | 从参数／样例／占位变为真实绑定的全部改动 |
| 是否改变展示语义 | 应为“否”；若为“是”，必须返回 C |
| 能力缺口处理 | 保留、阻塞或按 C 已接受替代方案处理 |

## 4. 完整 CAEGraph 定义

| 字段 | 含义 |
|---|---|
| 定义编号与版本 | 交给 E 的稳定身份 |
| Python 脚本引用 | 可直接交 E 尝试运行的完整脚本 |
| 特征实例引用 | 已正式绑定的外层实例 |
| A／B／C 产物版本 | 本定义消费的准确上游版本 |
| CAEGraph 仓库版本 | 本定义所依据的锁定实现 |
| 数据入口与位置绑定 | 第 3 节的真实绑定记录 |
| 展示与字段绑定 | C 面板／图元到 A 字段的映射 |
| C→D 集成差异 | 本次完整修改记录 |
| 预期输出 HTML 路径 | E 运行时应生成的位置 |
| 定义级检查结果 | 语法、导入、占位、引用、字段和展示语义检查 |
| 待 E 确认项 | 真实环境、数据、回调或 server 运行事项 |

## 5. 定义级检查结果

| 字段 | 含义 |
|---|---|
| 检查项 | 语法、导入、占位、版本、字段、位置、配置、展示语义等 |
| 结果 | 通过／不通过／未运行 |
| 证据 | 日志、命令或人工核对引用 |
| 影响 | 是否阻塞 E |
| 修订目标 | A、B、C 或 D |

## 6. 阶段最终输出状态

| 状态 | 含义 |
|---|---|
| 完整 | 已理解本次所需 CAEGraph 仓库调用链，并形成可直接交 E 尝试运行的完整定义 |
| 部分完整 | 只缺真实运行才能确认的非核心事项 |
| 阻塞 | 核心实例、位置、字段、展示绑定或仓库能力未核实，不能可靠进入 E |
