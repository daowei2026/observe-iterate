# D｜字段级输入输出

## 1. 阶段输入

| 字段 | 必填 | 含义 |
|---|---:|---|
| 特征实例 | 是 | 外层给定的实际实例或引用 |
| A 阶段产物引用 | 是 | 事件、位置、字段和处理关系 |
| B 阶段观察位置定义 | 是 | 普通位置，或 1d→30m→1m→5s→tick 多尺度位置路径 |
| C 阶段展示预期 | 是 | 页面、面板、图元、时间、身份和复杂点处理结果 |
| C 阶段位置独立展示代码 | 是 | 尚未绑定 B 最终位置和真实实例字段的 CAEGraph Python 定义 |
| C 阶段预期展示 HTML | 是 | E 最终图的展示核对基准 |
| C 阶段能力缺口 | 否 | 仍未解决的真实工具限制 |
| 数据与运行依赖引用 | 条件 | 能由实例解析时只记录解析结果；无法解析时列为缺口 |

## 2. C 代码接入记录

| 字段 | 含义 |
|---|---|
| C 代码编号／版本 | 本次集成采用的代码 |
| 对应展示预期版本 | 该代码实现的 C7 版本 |
| 样例数据／位置 | C 为生成预期 HTML 使用的内容 |
| 需要替换的占位 | 品种、时间、实例、字段、数据入口等 |
| 保持不变的展示结构 | 面板、图元、视觉语义和交互 |
| 已知能力缺口 | D 不得无痕掩盖的限制 |

## 3. 绑定记录

### 3.1 特征与数据入口绑定

| 字段 | 含义 |
|---|---|
| 绑定编号 | 稳定编号 |
| 特征实例引用 | 当前实例 |
| 数据／Feature 入口 | 实际类、函数、公开读取接口或结果文件 |
| 代码版本和路径 | 入口所在版本 |
| 提供的数据 | 价格、输入事件、业务主输出或中间处理结果 |
| 是否需要重跑 | 否／是／待 E 核实 |
| 缺口 | 当前入口不能提供的内容 |

### 3.2 位置绑定

| 字段 | 含义 |
|---|---|
| 位置用法 | 普通默认／任务明确指定／高频多尺度 |
| SOF 引用 | 来自外层特征实例 |
| 品种集绑定 | CAEGraph 对象／板块配置 |
| 普通时间绑定 | PlotSet、timespans 或等价配置 |
| 多尺度位置路径 | 1d、30m、1m、5s、tick 节点与父子关系；不适用可为空 |
| 日历／数据范围 | 从实例或运行依赖解析 |

### 3.3 展示与字段绑定

| 字段 | 含义 |
|---|---|
| C 面板编号 | 展示预期中的面板 |
| CAEGraph 布局对象 | C 代码中的实际布局类与配置 |
| C 图元编号 | 展示预期中的图元 |
| A 来源事件／结果编号 | 真实业务来源 |
| 真实数据字段 | 横轴、纵轴、身份、hover 等字段 |
| C 代码占位替换 | 本次如何替换样例／参数 |
| 显示派生处理 | 具体实现及原值保留方式 |
| 绑定状态 | 完整／部分／缺失 |

## 4. C→D 集成差异

| 字段 | 含义 |
|---|---|
| 差异编号 | 稳定编号 |
| C 代码位置 | 被修改的类、参数或辅助代码 |
| 修改内容 | 从样例／占位变成什么真实绑定 |
| 修改原因 | 实例、字段、普通位置或多尺度位置绑定 |
| 是否改变展示语义 | 应为否；若为是必须返回 C |
| 核对结果 | 接受／返回 C／待 E 运行确认 |

## 5. 完整 CAEGraph 定义

| 字段 | 含义 |
|---|---|
| 定义编号与版本 | 交给 E 的稳定版本 |
| Python 脚本引用 | 完整脚本文件 |
| 特征实例引用 | 实际实例 |
| A/B/C 产物版本 | 本定义使用的上游版本 |
| C 位置独立代码版本 | 集成起点 |
| 数据入口与位置绑定 | 上述绑定记录引用 |
| 展示与字段绑定 | 面板、图元和真实字段引用 |
| C→D 集成差异 | 本次修改记录 |
| 预期输出 HTML 路径 | E 运行时应生成的位置 |
| 定义级检查结果 | 语法、结构、字段与覆盖检查 |
| 待 E 确认项 | 只有真实运行才能确认的事项 |

## 6. 定义级检查结果

| 字段 | 含义 |
|---|---|
| 检查项 | 语法、占位、引用、字段、位置、配置、展示语义等 |
| 结果 | 通过／不通过／未运行 |
| 证据 | 日志、命令或人工核对引用 |
| 影响 | 是否阻塞 E |
| 修订目标 | A、B、C 或 D |

## 7. 阶段最终输出状态

| 状态 | 含义 |
|---|---|
| 完整 | 已形成可直接交 E 尝试运行的完整定义 |
| 部分完整 | 只缺真实运行才能确认的非核心事项 |
| 阻塞 | 核心实例、位置、字段或展示绑定缺失，不能可靠进入 E |
