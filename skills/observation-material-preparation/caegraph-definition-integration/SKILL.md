# D｜CAEGraph 定义集成

## 定位

本阶段回答：怎样把真实特征实例、字段、品种、时间和展示方式绑定为一个完整 CAEGraph 定义。

本阶段不派 Worker、不执行最终图、不正式取图数据。

## 输入概览

- A 阶段事件、位置、业务角色和处理关系；
- B 阶段观察位置定义；
- C 阶段展示方式定义及预期展示 HTML；
- 外层特征实例；
- 可由实例解析的数据入口、日历和 CAEGraph 运行依赖。

字段级格式见 [IO_SPEC.md](IO_SPEC.md)。

## 最终输出概览

- 已绑定真实特征实例、字段、品种和时间的完整 CAEGraph Python 定义／脚本初稿；
- A、B、C 产物到代码配置的绑定表；
- 定义级检查结果；
- 尚待 E 真实运行确认的问题。

## 内部 Workflow

见 [WORKFLOW.md](WORKFLOW.md)。

## 完成条件

- 产物不是文字方案，而是可以直接交 E 尝试运行的完整定义／脚本初稿；
- 特征实例、品种、时间、字段、面板和图元均已绑定；
- 绑定关系能追溯到 A、B、C；
- 已通过语法／结构／静态字段等当前可做的定义级检查；
- 未把“静态检查通过”写成“实际运行通过”。

## 不允许做的事

- 不重新选择 B 的位置；
- 不自行改变 C 的展示业务语义；
- 不以近似新计算代替 A 的真实特征字段；
- 不派 Worker；
- 不把生成脚本初稿当作 E 已完成。
