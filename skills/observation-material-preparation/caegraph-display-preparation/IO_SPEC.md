# C｜字段级输入输出

## 1. 阶段输入

| 字段 | 必填 | 含义 |
|---|---:|---|
| A 阶段产物引用 | 是 | 事件、事件发生位置、业务角色和处理关系 |
| 特征实例 | 条件 | 需要读取真实数据形状或生成样例 HTML 时引用 |
| 展示设计用局部位置 | 否 | C 内部选取的真实或示意位置，不是 B 的最终位置 |
| CAEGraph 能力资料版本 | 是 | 本次采用的使用手册、源码或 Reference 版本 |

## 2. 待展示信息记录

| 字段 | 含义 |
|---|---|
| 信息编号 | 本阶段内部唯一编号 |
| 来源事件／结果编号 | 对应 A 的记录 |
| 业务角色 | 输入、业务主输出、中间处理结果 |
| 是否展示 | 是／否／条件展示 |
| 展示理由 | 为什么需要或不需要展示 |
| 位置字段 | 要表达的实际、确认、已知、更新等位置 |
| 身份字段 | 图中保持同一业务对象所需字段 |
| 原值字段 | 真实业务值来源 |
| 显示派生字段 | 仅为画图产生的字段及其转换 |

## 3. 展示方式定义

### 3.1 面板定义

| 字段 | 含义 |
|---|---|
| 面板编号 | 稳定编号 |
| 面板名称 | 人类可读标题 |
| 面板角色 | 主图／附图／明细 |
| 对象范围 | 单品种、多品种或组级 |
| 数据来源 | 来源事件、结果或价格数据 |
| 时间轴语义 | 使用哪个时间字段，是否与其他面板共享 |
| 纵轴语义 | 价格、类别、量测或其他业务含义 |
| 排列顺序 | 在页面中的顺序 |
| 采用的 CAEGraph 布局类 | 预期使用的类或能力 |

### 3.2 图元定义

| 字段 | 含义 |
|---|---|
| 图元编号 | 稳定编号 |
| 所属面板 | 面板编号 |
| 来源信息编号 | 对应待展示信息 |
| 图元类型 | 点、线、段、柱、区域或其他 |
| 横轴字段 | 使用的事件位置字段 |
| 纵轴字段 | 价格、类别或量测字段 |
| 身份编码 | 同一 occurrence／对象如何保持身份 |
| 颜色／符号／线型语义 | 每种视觉编码代表什么 |
| hover 字段 | 需要查看的身份、值和来源 |
| 图例 | 人类阅读标签及其对应关系 |
| 是否为显示派生 | 是／否；若是需记录派生规则 |

### 3.3 基准、转换和交互

| 字段 | 含义 |
|---|---|
| 处理对象 | 哪些字段参与 |
| 处理类型 | 原值、标准化、局部基准、裁剪或其他 |
| 处理规则 | 明确公式或工具配置 |
| 处理阶段 | Python 构图、前端动态或其他 |
| 可能损失 | 对原值、单位或比较意义的影响 |
| 交互方式 | 共享时间轴、显隐、hover、控件等 |

## 4. 预期展示 HTML 记录

| 字段 | 含义 |
|---|---|
| HTML 文件引用 | 预期展示文件路径或提交引用 |
| 生成代码引用 | 产生该 HTML 的定义或脚本 |
| 使用的数据性质 | 示意／真实样例 |
| 展示设计用位置 | 仅说明生成样例的位置，不等于 B 位置 |
| 应保持一致的内容 | 面板、图元、时间表达、身份和业务语义 |
| 最终图允许变化的内容 | 曲线形状、点数量、真实坐标范围等 |

## 5. CAEGraph 能力缺口

| 字段 | 含义 |
|---|---|
| 缺口编号 | 稳定编号 |
| 受影响展示信息 | 无法表达什么 |
| 已核实的现有能力 | 查过哪些类、参数或示例 |
| 使用问题还是能力缺失 | 明确分类 |
| 最低替代方案 | 不新增能力时怎样处理 |
| 替代的语义损失 | 会失去什么信息 |
| 建议的新能力 | 确有必要时填写 |

## 6. 阶段最终输出

| 字段 | 含义 |
|---|---|
| 展示方式定义 | 面板、图元、转换和交互的完整引用 |
| 预期展示 HTML | 可打开文件及生成引用 |
| 能力缺口 | 缺口清单 |
| 阶段状态 | 完整／部分完整／阻塞 |
