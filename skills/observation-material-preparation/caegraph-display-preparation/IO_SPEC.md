# C｜字段级输入输出

## 1. 阶段输入

| 字段 | 必填 | 含义 |
|---|---:|---|
| A 阶段产物引用 | 是 | 事件、事件发生位置、业务角色和处理关系 |
| 外层特征实例 | 条件、只读 | 仅用于理解真实数据形状、接口或生成 C2 预期 HTML；不得在 C3 正式代码中固化为最终实例 |
| CAEGraph 使用手册版本 | 是 | 本次直接阅读的 [`daowei2026/uplot@e6.2/CAEGraph使用手册.md`](https://github.com/daowei2026/uplot/blob/e6.2/CAEGraph使用手册.md) 或后续锁定版本 |
| CAEGraph 补充源码版本 | 条件 | 手册不足以判断当前复杂点时，实际查阅的类、参数、示例或源码版本 |
| 展示专业知识版本 | 是 | 本 Skill 当前采用的主附图、时序阅读和困难点处理经验 |

## 2. C1｜待展示信息清单

| 字段 | 含义 |
|---|---|
| 信息编号 | 本阶段内部唯一编号 |
| 来源事件／结果编号 | 对应 A 的记录 |
| 业务角色 | 输入、业务主输出、中间处理结果 |
| 是否纳入展示预期 | 是／否／条件展示 |
| 展示或不展示理由 | 为什么需要或不需要展示 |
| A 已确认的位置字段 | 实际、确认、已知、更新或其他位置；只记录 A 已确认存在的内容 |
| A 已确认的身份／引用字段 | 图中保持业务记录、成员或引用关系可追溯所需字段 |
| 原值字段 | 真实业务值来源 |
| 形成业务主输出的关系 | 该信息与其他输入／中间结果／主输出怎样关联 |

## 3. C2A｜CAEGraph 阅读与能力核实记录

| 字段 | 含义 |
|---|---|
| 手册版本 | 本轮直接阅读的锁定版本 |
| 已读章节 | 文档说明、名词定义、CAEGraph／PlotSet、布局类、绘图类、类关系、相关示例等实际阅读范围 |
| 候选布局类 | 本轮考虑的布局类及其适用理由 |
| 候选绘图类 | 本轮考虑的绘图类及其适用理由 |
| 补查源码 | 手册不足时实际查过的文件、类、参数或示例 |
| 已确认能力 | 当前能够直接采用的能力 |
| 尚未核实能力 | 仍需在 C2D 循环中查证的事项 |

## 4. 外层特征实例使用记录

| 字段 | 含义 |
|---|---|
| 是否读取外层实例 | 是／否 |
| 实例引用与版本 | 实际读取的实例 |
| 使用目的 | 数据形状核实／字段核实／C2 HTML 预览／其他 |
| 读取内容 | 读取了哪些接口、字段或样例结果 |
| 是否进入 C3 正式代码 | 只能以可替换注入接口进入，不能固化具体实例 |
| 预览实例绑定 | 若生成 HTML 时临时绑定实例，记录样例品种、时间和数据范围 |
| D 需要替换的内容 | 实例对象、Feature／数据入口、SOF、结果路径等 |

## 5. C2｜展示预期及预期 HTML

### 5.1 第一版展示预期与 HTML

| 字段 | 含义 |
|---|---|
| 第一版预期编号／版本 | C2B 的稳定身份 |
| 页面与阅读路径 | 页面组织及观察者怎样从输入读到业务主输出 |
| 主图、附图和明细 | 第一版面板结构 |
| C1 信息映射 | 每项待展示信息放在哪里 |
| A 已确认的位置／关系表达 | 只表达 A 已确认的多位置、成员或引用关系 |
| 图元、图例、hover 和交互 | 第一版视觉表达 |
| 使用的 CAEGraph 能力 | 已核实的布局类、绘图类和配置 |
| 原型代码引用 | 生成第一版 HTML 的临时代码 |
| 第一版 HTML 引用 | 可打开的第一版预期图 |
| 样例数据与预览绑定 | 示意／真实样例，以及临时实例、品种和时间 |

### 5.2 当前展示预期与当前 HTML

| 字段 | 含义 |
|---|---|
| 当前预期编号／版本 | C2D 每轮更新后的当前版本；循环结束时即 C2 最终版本 |
| 页面与阅读路径 | 当前页面组织和预期阅读方式 |
| 面板定义 | 面板编号、角色、承担的信息、时间轴、纵轴、顺序和布局类 |
| 图元定义 | 图元编号、来源信息、横纵轴、视觉语义、hover／图例和显示派生 |
| 基准、转换和交互 | 原值／标准化／局部基准／裁剪、处理阶段、损失和交互 |
| 当前原型代码引用 | 实际生成当前 HTML 的代码 |
| 当前预期 HTML 引用 | C2 当前可打开图；循环结束后是唯一预期 HTML |
| 当前允许变化 | D／E 的真实曲线、点数量、坐标范围、B 位置和正式实例绑定等 |
| 当前必须保持 | 页面、面板、图元、业务语义及 C1 关键内容 |

## 6. C2C／C2D｜复杂展示点循环记录

| 字段 | 含义 |
|---|---|
| 复杂点编号 | 稳定编号 |
| 要保留的业务信息 | 不能丢掉什么 |
| 当前 HTML 中的问题 | 具体哪里难读、无法表达或可能误解 |
| 轮次 | 第几轮处理 |
| 候选展示表达 | 本轮提出的想法 |
| 已核实的 CAEGraph 能力 | 查过的手册章节、类、参数、示例或源码 |
| 判断类型 | 直接支持／使用方式问题／换表达可实现／真实能力缺口 |
| 本轮决定 | 采用、调整、继续循环或记录缺口 |
| 语义损失 | 替代方案会失去什么 |
| 展示预期修订 | 更新了哪些面板、图元、转换或交互 |
| HTML 更新引用 | 本轮更新后的预期 HTML |
| 原型代码更新引用 | 本轮更新后的生成代码 |
| 当前状态 | 已解决／继续处理／能力缺口 |

## 7. C3｜位置与实例可注入的 CAEGraph 展示代码

| 字段 | 含义 |
|---|---|
| 代码编号／版本 | C3 代码版本 |
| Python 代码引用 | 具体 CAEGraph 定义及必要辅助代码 |
| 对应 C2 当前预期版本 | 该代码保持哪一版展示预期和 HTML |
| 代码来源 | 从 C2 当前原型整理而来，不另造展示语义 |
| 实例注入接口 | D 怎样传入外层真实特征实例或 Feature／数据入口映射 |
| 位置注入接口 | D 怎样传入 B 的品种、时间及多尺度位置 |
| 字段注入接口 | D 怎样传入 A 的真实字段映射 |
| 预览实例绑定 | 若 C2 临时绑定外层实例，记录其范围；C3 中必须可替换 |
| 是否固化外层实例 | 必须为“否” |
| 是否固化 B 最终位置 | 必须为“否” |
| CAEGraph 类映射 | `CAEGraph`、`PlotSet`、布局类、绘图类与 C2 预期的对应 |
| 与 C2 当前 HTML 核对 | 结构和语义是否保持一致；如不一致返回 C2D |
| 代码级检查 | 语法、结构、引用和必要样例运行结果 |

## 8. CAEGraph 能力缺口

| 字段 | 含义 |
|---|---|
| 缺口编号 | 稳定编号 |
| 受影响展示信息／复杂点 | 无法表达什么 |
| 已核实的现有能力 | 查过哪些手册章节、类、参数、示例或源码 |
| 为什么不是使用问题 | 排除已有组合方式的依据 |
| 最低替代方案 | 不新增能力时怎样处理 |
| 替代的语义损失 | 会失去什么信息 |
| 建议的新能力 | 确有必要时填写 |

## 9. 阶段最终输出

| 字段 | 含义 |
|---|---|
| C1 待展示信息清单 | C1 结果 |
| C2 当前展示预期 | 循环结束时的当前版本 |
| C2 当前预期 HTML | 唯一预期 HTML，不在 C3 重复生成 |
| C2 复杂点处理记录 | 各轮处理和结论 |
| C3 可注入展示代码 | 可交 D 集成的代码 |
| 实例／位置／字段注入合同 | D 的正式绑定接口 |
| 能力缺口 | 未解决的真实工具限制 |
| 阶段状态 | 完整／部分完整／阻塞 |
