# C｜字段级输入输出

## 1. 阶段输入

| 字段 | 必填 | 含义 |
|---|---:|---|
| A 阶段产物引用 | 是 | 事件、事件发生位置、业务角色和处理关系 |
| 外层特征实例 | 条件、只读 | 仅用于理解真实数据形状、接口或生成预期 HTML；不得在 C 正式代码中固化为最终实例 |
| CAEGraph 能力资料版本 | 是 | [CAEGraph 展示能力与构建速查](../references/CAEGraph展示能力与构建速查.md)、原手册及必要源码版本 |
| 展示专业知识版本 | 是 | 本 Skill 当前采用的主附图、时序阅读、身份和困难点处理原则 |

## 2. C1 待展示信息清单

| 字段 | 含义 |
|---|---|
| 信息编号 | 本阶段内部唯一编号 |
| 来源事件／结果编号 | 对应 A 的记录 |
| 业务角色 | 输入、业务主输出、中间处理结果 |
| 是否纳入展示预期 | 是／否／条件展示 |
| 展示或不展示理由 | 为什么需要或不需要展示 |
| 位置字段 | 要表达的实际、确认、已知、更新等位置 |
| 身份字段 | 图中保持同一 occurrence／对象所需字段 |
| 原值字段 | 真实业务值来源 |
| 形成业务主输出的关系 | 该信息与其他输入／中间结果／主输出怎样关联 |

## 3. CAEGraph 理解记录

| 字段 | 含义 |
|---|---|
| 手册／源码版本 | 本轮实际阅读的锁定版本 |
| 图表集成类 | 本轮涉及的 `CAEGraph`／`PlotSet` 能力 |
| 候选布局类 | `AllSymsMainFig`、`PerSymFigs`、`MainFig`、`SubFig` 等及适用理由 |
| 候选绘图类 | `KPriceLine`、`MulFieldsGlyphs`、`MulSegPlot` 等及适用理由 |
| 数据与运行链 | `PlotCtx`、Feature 数据读取、CDS、动态标准化、前端回调中本轮涉及的部分 |
| 参考示例／源码 | 实际查过的示例或代码引用 |
| 尚未核实的能力 | 不能凭速查确定、仍需查证的事项 |

## 4. 外层特征实例使用记录

| 字段 | 含义 |
|---|---|
| 是否读取外层实例 | 是／否 |
| 实例引用与版本 | 实际读取的实例 |
| 使用目的 | 数据形状核实／字段核实／预期 HTML 预览／其他 |
| 读取内容 | 读取了哪些接口、字段或样例结果 |
| 是否进入 C 正式代码 | 只能以可替换注入接口进入，不能固化具体实例 |
| 预览实例绑定 | 若生成 HTML 时临时绑定实例，记录具体范围 |
| D 需要替换的内容 | 实例对象、Feature／数据入口、SOF、结果路径等 |

## 5. 展示预期

### 5.1 页面与阅读路径

| 字段 | 含义 |
|---|---|
| 展示预期编号／版本 | 本轮稳定版本 |
| 页面结构 | 页面从上到下或从左到右的组织 |
| 预期阅读路径 | 观察者怎样从输入沿时间读到业务主输出 |
| 多品种组织 | 同图、独立价格面板或每品种主附图 |
| 常显与按需内容 | 哪些信息始终显示，哪些通过 hover／显隐／明细查看 |

### 5.2 面板预期

| 字段 | 含义 |
|---|---|
| 面板编号 | 稳定编号 |
| 面板名称 | 人类可读标题 |
| 面板角色 | 主图／附图／明细 |
| 承担的信息编号 | 来自 C1 的信息 |
| 时间轴语义 | 使用哪个位置字段，是否共享时间轴 |
| 纵轴语义 | 价格、类别、量测或其他业务含义 |
| 候选 CAEGraph 布局类 | 预期采用的现有能力 |
| 面板顺序及理由 | 为什么放在这个位置 |

### 5.3 图元与身份预期

| 字段 | 含义 |
|---|---|
| 图元编号 | 稳定编号 |
| 所属面板 | 面板编号 |
| 来源信息编号 | 对应待展示信息 |
| 图元类型 | 点、线、段、柱、区域、文字或其他 |
| 横轴位置 | actual／confirm／known／其他位置 |
| 纵轴含义 | 价格、类别或量测 |
| 同一 occurrence 的身份表达 | 多个位置、成员或图元怎样保持共同身份 |
| 颜色／符号／线型语义 | 视觉编码的业务含义 |
| hover／图例 | 阅读所需身份、值和来源 |
| 显示派生 | 是否为显示派生及其规则 |

### 5.4 基准、转换和交互预期

| 字段 | 含义 |
|---|---|
| 处理对象 | 哪些字段参与 |
| 处理类型 | 原值、标准化、局部基准、裁剪或其他 |
| 处理规则 | 公式或 CAEGraph 配置 |
| 处理阶段 | Python 构图、前端动态或其他 |
| 可能损失 | 对原值、单位或比较意义的影响 |
| 交互方式 | 共享时间轴、显隐、hover、控件等 |

## 6. 复杂展示点及循环处理记录

| 字段 | 含义 |
|---|---|
| 复杂点编号 | 稳定编号 |
| 要保留的业务信息 | 不能丢掉什么 |
| 当前困难 | 为什么常规画法不够 |
| 轮次 | 第几轮处理 |
| 候选展示表达 | 本轮提出的想法 |
| 已核实的 CAEGraph 能力 | 查过的类、参数、示例或源码 |
| 判断类型 | 直接支持／使用方式问题／换表达可实现／真实能力缺口 |
| 本轮决定 | 采用、调整、继续循环或记录缺口 |
| 语义损失 | 替代方案会失去什么 |
| 对展示预期的修订 | 更新了哪些面板、图元或交互 |
| 当前状态 | 已解决／继续处理／能力缺口 |

## 7. 位置与实例可注入的 CAEGraph 展示定义代码

| 字段 | 含义 |
|---|---|
| 代码编号／版本 | C 阶段代码版本 |
| Python 代码引用 | 具体 CAEGraph 定义及必要辅助代码 |
| 对应展示预期版本 | 该代码实现哪一版 C7 预期 |
| 样例数据性质 | 示意／真实样例 |
| 样例位置 | 仅用于生成 HTML，不等于 B 最终位置 |
| 实例注入接口 | D 怎样传入外层真实特征实例或 Feature／数据入口映射 |
| 位置注入接口 | D 怎样传入 B 的品种、时间及多尺度位置 |
| 字段注入接口 | D 怎样传入 A 的真实字段映射 |
| 预览实例绑定 | 若 C 临时绑定外层实例，记录其范围；正式代码中必须可替换 |
| 是否固化外层实例 | 必须为“否” |
| CAEGraph 类映射 | `PlotSet`、布局类、绘图类与展示预期的对应 |
| 代码级检查 | 语法、结构、引用和样例运行结果 |

## 8. 预期展示 HTML

| 字段 | 含义 |
|---|---|
| HTML 文件引用 | 可打开的预期展示文件 |
| 生成代码版本 | 与第 7 节代码一致 |
| 使用的数据性质 | 示意／真实样例 |
| 使用的实例性质 | 无实例／临时预览实例；不得写成最终绑定 |
| 展示预期版本 | 与 HTML 对应的 C7 版本 |
| 应保持一致的内容 | 面板、图元、时间表达、身份和业务语义 |
| 最终图允许变化的内容 | 真实曲线、点数量、具体坐标范围、B 位置和 D 实例绑定 |
| 核对结果 | HTML 是否真实实现展示预期 |

## 9. CAEGraph 能力缺口

| 字段 | 含义 |
|---|---|
| 缺口编号 | 稳定编号 |
| 受影响展示信息／复杂点 | 无法表达什么 |
| 已核实的现有能力 | 查过哪些类、参数、示例或源码 |
| 为什么不是使用问题 | 排除已有组合方式的依据 |
| 最低替代方案 | 不新增能力时怎样处理 |
| 替代的语义损失 | 会失去什么信息 |
| 建议的新能力 | 确有必要时填写 |

## 10. 阶段最终输出

| 字段 | 含义 |
|---|---|
| 待展示信息清单 | C1 结果 |

| 复杂点处理记录 | 循环过程和结论 |
