## 一句话定位

给定“想观察什么、已有特征及其处理过程、可访问的 CAEGraph/数据环境”，从业务目的决定**看哪些输入、实质中间过程、业务结果和参照信息**，优先复用已有专业观察方法和工具，**实际运行取数并核验**后交给业务合理性分析。不是只给出图设计或一份待办清单。

## 文件及阅读顺序

1. **[SKILL.md](SKILL.md)**：可直接交给执行 Agent 的上位 Skill；规定从规划到实际取数和交付的步骤、停止/降级规则。
2. **[候选观察方法索引](references/候选观察方法索引与选用规则.md)**：高频 S1–S4、EAW E1/E3 及 E2/E4 对应的复用关系，含适用问题和边界。
3. **[CAEGraph 运行取数说明](references/CAEGraph执行取数与验证.md)**：使用手册、源码接口、构图数据树/图对象/浏览器当前状态的区别，提供最小可核对调用示意。
4. **[观察准备任务单模板](templates/观察材料准备任务单.md)**：Owner/Agent 可直接复制填写的规划表、数据取得记录、缺口分级与交接门槛。
5. **[两用例示范](examples/标准化高频与EAW示范.md)**：只把**已读材料支持的部分**填入，展示如何确定值得看什么、哪部分缺证据；不虚构实际行情数据。

## 三种不同性质，禁止混淆

| 层次 | 性质 | 应由谁使用 |
|---|---|---|
| 上位观察材料规划与准备 Skill | **专业执行方法**：观察范围规划、挑选/设计处理、取数和验收 | 准备观察材料的 Agent / Pro |
| 具体观察方法（目前均为候选） | **可复用专业判断方法**：怎样比较、表达与防误读；可调用不同工具 | 上位 Skill 按需要选用；不强制四个全上 |
| CAEGraph 及其使用手册、Notebook、后处理器 | **既有技术能力与使用示例**：实际获取数据、变换、画点/线/柱、布局、交互 | 由执行者按实际版本调用，不再复制实现成第二套框架 |

## 当前使用原则

- 有现成完整图：**先复用图定义和运行数据**，不为“使用 Skill”而拆图重构。
- 没有现成方法：根据手册和源码自行组合；若真缺平台能力，提出具体需求，不把想象当成可用接口。
- **设计完成 ≠ 取数完成 ≠ 合理性分析完成**。必须分别报告状态。
- 缺少中间数据：先判断对本次结论的影响；并非所有内部状态都要画，更不是一缺就新增正式特征。
