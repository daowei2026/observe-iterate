# CAEGraph 展示能力与构建速查

> **来源**：[`daowei2026/uplot@e6.2/CAEGraph使用手册.md`](https://github.com/daowei2026/uplot/blob/e6.2/CAEGraph使用手册.md)。本文件只提取 C 阶段形成展示预期时最需要的结构和能力；具体参数、最新版 API 与完整示例仍以锁定版本的原手册和源码为准。

## 1. 先理解 CAEGraph 的构建层次

手册采用从顶层到具体绘制的链路：

```text
图表集成类
    CAEGraph / PlotSet
        ↓
图表布局类
    AllSymsMainFig / AllSymsFig / PerSymFigs / PerSymFigSet
    MainFig / SubFig / OneFig
        ↓
绘图类
    KPriceLine / TickPriceLine / VBarPlot / MulFieldsGlyphs
    MulSegPlot / SegsPlot / TextPlot / MulPointPlot / ...
        ↓
特征雷达、组件、主题与基础组件
```

- **CAEGraph**：整合一个或多个 PlotSet，形成完整可视化应用。
- **PlotSet**：组织日历、对象范围、时间段和图表布局；常见配置包括 `calendar_name`、`blk`、`timespans`、`timespans_fao`、`figs`。
- **图表布局类**：决定多品种、主图、附图和每品种独立图怎样排列。
- **绘图类**：把具体字段画成 K 线、Tick 线、柱、点、线段或文字。
- **特征雷达**：`ExtractTimespans`、`PerDPTimespans` 可从特征中抽取时间段；它们不是 B 的普通默认位置选择，也不能替代已明确的观察位置方法。
- **组件类**：`FigCtrls`、`BasePPChangeWidget` 等提供参数和交互控件。

## 2. 布局类快速选择

| 布局类 | 主要结构 | 适合表达 |
|---|---|---|
| `AllSymsMainFig` | 所有品种在同一主图 | 多品种价格／K 线及其上叠加的事件 |
| `AllSymsFig` | 所有品种在同一附图 | 多品种指标或量测对比 |
| `PerSymFigs` | 每个品种一张独立图 | 各品种绝对价格差异大、需要单独观察时 |
| `PerSymFigSet` | 每个品种各有一组主附图 | 多品种都需要完整主图＋附图组合时 |
| `MainFig` | 单个主图 | 单对象价格及贴近价格理解的内容 |
| `SubFig` | 单个附图 | 不适合叠在价格线上的输出、输入或中间量 |
| `OneFig` | 单一普通图 | 不需要主／附图语义的独立展示 |

这些是可用能力，不是自动的业务选择规则。C 仍需根据待展示信息和阅读目的形成展示预期。

## 3. 绘图类快速选择

| 绘图类 | 典型用途 | C 阶段应关注的能力 |
|---|---|---|
| `KPriceLine` | OHLC K 线 | 价格主图、频率、标准化和多品种比较 |
| `TickPriceLine` | Tick 价格线 | 高频短时价格路径 |
| `VBarPlot` | 柱状图 | 附图量测、强度、成交量等 |
| `MulFieldsGlyphs` | 多类离散点／事件 | 不同 occurrence、符号、颜色和大小编码 |
| `SegsPlot` | 单类线段 | 一种起止位置关系 |
| `MulSegPlot` | 多类／多条线段 | occurrence 的实际—确认连接、多个处理关系 |
| `TextPlot` | 文字标记 | 少量必要说明；不应用文字代替可视化结构 |
| `MulPointPlot` | 多个历史点 | 旧版或点数较少的离散位置 |
| `OneToGroupPointPlot` | 分组点、避免重叠 | 同时点较多且确实需要分组阅读时 |
| `SeqOfFieldsPlot` | 不定长字段序列 | 一个主记录携带变长相关值列表时 |

正式实现前应核对锁定版本的真实类名、参数和输入字段；不能只凭本速查猜 API。

## 4. C 阶段使用顺序

C 在形成展示预期前至少应完成：

1. 阅读本速查并按需打开原手册对应章节；
2. 理解 `CAEGraph → PlotSet → 布局类 → 绘图类` 的构建关系；
3. 根据 C1 的待展示信息，确认可能使用的布局类和绘图类；
4. 遇到复杂点时，先查现有类、参数、示例和源码；
5. 区分：
   - **使用问题**：现有能力可以表达，只需正确组合或重复绑定数据；
   - **表达调整**：原想法不直接支持，但换一种不损害业务含义的表达即可；
   - **真实能力缺口**：现有能力无法表达，且替代会造成不可接受的信息损失。

## 5. 主附图和多品种的常用起点

当前经验性起点：

- 价格、K 线、ZigZag、转折、低频 Boll 等贴近价格理解的内容，优先考虑主图；
- 不适合贴在价格上的输入、业务主输出和中间结果，优先考虑附图；
- 多品种特征需要共同时间语境，但不等于必须共用同一绝对价格轴；可在 `AllSymsMainFig`、`PerSymFigs`、`PerSymFigSet` 之间选择；
- 主图与附图共享时间轴通常已经提供必要联动，不先引入复杂点击、弹窗或跨图联动；
- 同一数据需要在多个面板出现时，可以分别绑定同一来源，不自动构成新增 CAEGraph 功能需求。

这些只是形成展示预期时的专业知识，不能替代对具体待展示信息的判断。
