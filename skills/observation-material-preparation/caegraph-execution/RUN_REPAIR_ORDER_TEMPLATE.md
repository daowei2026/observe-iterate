## C. 本次要执行的操作

1. 在指定真实环境运行 D 的完整定义；
2. 生成候选 HTML 和完整运行日志；
3. 对工单授权范围内的确定性错误进行最小修复；
4. 每次修复后重新运行并记录结果；
5. 将不能确定处理的问题原样返回 E，不自行改变业务语义。

## D. Worker 可自主修复范围

勾选或具体填写：

- [ ] Python 语法错误；
- [ ] 明确的 import／模块路径错误；
- [ ] 工作区、输入或输出路径拼接错误；
- [ ] 锁定版本中已经核实的 API 名称／参数差异；
- [ ] 不改变业务含义的明确类型转换；
- [ ] 输出目录、文件名和日志接线；
- [ ] 其他经 E 明确授权的机械修改：

每项修改都必须记录：文件与位置、修改前、修改后、原因、授权依据、是否可能影响业务语义。

## E. 必须停止并返回 E 的事项

- 品种、时间、多尺度位置或特征实例需要改变；
- A 的业务字段缺失，需删除、增加或用其他值替代；
- C 的主图／附图、图元、时间表达、标准化、交互或阅读路径需要改变；
- D 的实例／字段／位置绑定本身有误；
- 需要新增业务计算或近似重算；
- 无法判断属于位置、展示、集成还是机械问题；
- 动作可能超预算、不可逆或写入未授权位置；
- 执行效果未知，无法确认上次动作是否已经生效。

## G. 明确不交付

本 W1 不交付、也不授权：

- 最终图的专业接受结论；
- `DATA_READY`；
- 正式 CAEGraph 图数据包；
- 对 C／D 业务语义的修改决定。

## H. 失败、部分和重跑

- 失败／部分结果应保留已有脚本、HTML、日志和 patch，不抹掉事实；
- 效果未知时先对账，不直接重跑；
- D／C／实例／位置任一基准变化后，旧工单不得无痕续用；
- Worker 必须回原签单 executor，不直接向 manager 宣布专业完成。
