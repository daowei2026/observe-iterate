# E｜CAEGraph 执行／运行

## 定位

本阶段承担派单、真实运行、有限修复、问题回流、最终图核对、正式取图数据以及交付。

E 不是“脚本不报错”就完成。必须先确认最终图符合 D 的完整定义和 C 的预期展示，再正式取得进入观察材料的 CAEGraph 图数据。

## 输入概览

- D 阶段完整 CAEGraph 定义；
- C 阶段预期展示 HTML；
- 外层特征实例；
- 实际运行环境和数据入口（优先由特征实例与 D 定义解析）；
- 本 Skill 规定的 Worker 修改权限和反馈协议。

字段级格式见 [IO_SPEC.md](IO_SPEC.md)。

## 最终输出概览

- 实际可运行的最终脚本；
- 最终 CAEGraph HTML；
- 最终 CAEGraph 图的数据及元信息；
- 运行日志和 Worker 修改记录；
- 与 D 完整定义的核对结果；
- 与 C 预期展示 HTML 的核对结果；
- 图与数据的一致性核对；
- 已知限制和未解决问题。

## 内部 Workflow

见 [WORKFLOW.md](WORKFLOW.md)。

## 完成条件

- 最终脚本在真实环境完整运行并生成图；
- Worker 改动已与 D 核对，未发生未经授权的业务语义变化；
- 最终图已与 C 预期 HTML 核对并接受；
- 只有在图接受后才正式导出图数据；
- 最终脚本、HTML 和数据绑定同一有效版本和运行；
- 数据、图层、品种、时间和特征实例一致性检查通过，或限制明确。

## 不允许做的事

- 不让 Worker 自行选择业务观察位置或展示语义；
- 不以调试期间临时读取的数据冒充正式图数据；
- 不在最终图核对前正式取数交付；
- 不用脚本运行成功替代图形与业务语义核对；
- 不把图的数据只保存成前几行预览；
- 不从图像素或压缩显示值反推缺失原值。
