# E｜字段级输入输出

> 本文件将 E 的专业判断产物与 Worker 操作产物分开。工单正文使用 [W1 模板](RUN_REPAIR_ORDER_TEMPLATE.md)和 [W2 模板](DATA_EXPORT_ORDER_TEMPLATE.md)；本文件只规定它们怎样进入 E 的专业 Workflow。

## 1. 阶段输入

| 字段 | 必填 | 含义 |
|---|---:|---|
| D 完整 CAEGraph 定义 | 是 | 冻结的定义版本、完整脚本、仓库理解记录和绑定表 |
| C 展示预期 | 是 | 最终图应保持的页面、面板、图元、时间和业务语义 |
| C 预期展示 HTML | 是 | 最终图的可视化核对基准 |
| 特征实例 | 是 | 外层给定、已由 D 绑定的真实实例 |
| B 观察位置 | 是 | 普通位置或多尺度位置路径 |
| 运行环境引用 | 是 | 工作区、代码、数据、SOF、日历和依赖版本 |
| 输出目录 | 是 | 脚本、HTML、数据、日志和核对结果的目标位置 |
| Owner／D 操作授权 | 是 | Worker 可以执行、修改和写入的真实范围 |

## 2. E 专业基准

### 2.1 执行与核图基准

| 字段 | 含义 |
|---|---|
| 基准编号／版本 | E 当前专业基准 |
| D 定义版本 | 本轮运行唯一输入 |
| C 展示预期／HTML 版本 | 核图依据 |
| 实例、位置和环境 | 实际执行对象 |
| W1 可自主修复范围 | 允许的机械改动 |
| 必须返回 E 的问题 | 位置、展示、绑定或无法分类问题 |
| 候选输出路径 | 脚本、HTML、日志和 patch |
| 失效条件 | D／C／实例／位置／环境变化等 |

### 2.2 正式取数准入记录

| 字段 | 含义 |
|---|---|
| 准入编号／版本 | W2 的唯一专业前置 |
| 最终脚本版本／哈希 | E 已接受的脚本 |
| 最终 HTML 版本／哈希 | E 已接受的图 |
| 对应 D／C 版本 | 定义和展示依据 |
| 最终有效运行编号 | 数据必须绑定的运行 |
| 实例、位置和环境 | 取数对象 |
| 需要的数据阶段 | source／postprocessed／construction_snapshot／viewport_final |
| 完整性要求 | 全量／必要范围完整／其他 |
| 图层数据映射要求 | 面板、图元、Renderer、CDS／源表 |
| W2 禁止修改内容 | 脚本、定义、位置、字段和展示语义 |
| 失效条件 | 任一已接受基准变化 |

## 3. W1 工单与 Worker 回报

### 3.1 W1 工单引用

| 字段 | 含义 |
|---|---|
| 工单编号／引用 | 按 [W1 模板](RUN_REPAIR_ORDER_TEMPLATE.md)形成的实际工单 |
| 执行与核图基准 | 第 2.1 节引用 |
| 通用 V2 身份与授权 | `run_id / work_order_id / parent D / authority_quote` 等 |
| 当前 revision | 首次／返修／重跑 |

### 3.2 W1 Worker 回报

| 字段 | 含义 |
|---|---|
| 运行编号 | 唯一执行身份 |
| 输入定义和基准版本 | 对应 D 与 E 基准 |
| 实际脚本版本 | 本次执行脚本 |
| 实际环境和数据版本 | 工作区、SOF、日历、实例、依赖 |
| 结果 | 成功／部分／失败／效果未知 |
| 候选 HTML | 生成文件 |
| 日志 | 命令、stdout、stderr、开始结束 |
| patch 清单 | 修改前后、原因、权限依据和语义影响 |
| 未解决问题 | Worker 原样回报，不自行定性为 B／C／D |
| 重复／效果未知记录 | 防止无核对重跑 |

## 4. E 对 W1 的专业判断

### 4.1 W1 回报评价

| 字段 | 含义 |
|---|---|
| 输入是否一致 | 是否使用 D 指定实例、位置、字段和环境 |
| patch 是否在授权内 | 是／否／待判断 |
| 问题性质 | B 位置／C 展示／D 集成／机械问题／无法分类 |
| 当前可保留结果 | 脚本、HTML、日志、patch 中哪些仍有效 |
| 专业后继 | 接受候选／续发 W1／返回 B／返回 C／返回 D／阻塞 |
| 基准是否失效 | 是／否及原因 |

### 4.2 最终图核对

| 字段 | 含义 |
|---|---|
| 与 D 核对 | 实例、位置、字段、面板、图元、转换和 patch |
| 与 C 核对 | 页面、主附图、图元语义、事件位置、身份、交互和复杂点 |
| 允许的真实数据差异 | 曲线、点数量、坐标范围等 |
| 不允许的语义差异 | 缺图层、错时间、错身份、错字段、改变展示含义等 |
| 核对结果 | 接受／限域接受／返回 B／返回 C／返回 D／阻塞 |
| 最终脚本／HTML | 被 E 接受的版本和哈希 |
| 接受范围与限制 | 本次正式取数可依据的范围 |

## 5. W2 工单与 Worker 回报

### 5.1 W2 工单引用

| 字段 | 含义 |
|---|---|
| 工单编号／引用 | 按 [W2 模板](DATA_EXPORT_ORDER_TEMPLATE.md)形成的实际工单 |
| 正式取数准入 | 第 2.2 节引用，必须存在且有效 |
| 通用 V2 身份与授权 | `run_id / work_order_id / parent D / authority_quote` 等 |
| 当前 revision | 首次／导出返修／重跑 |

### 5.2 W2 Worker 回报

| 字段 | 含义 |
|---|---|
| 所绑定脚本／HTML／运行 | 必须与正式取数准入一致 |
| 数据文件清单 | 源、后处理、构图 CDS、视窗最终值等 |
| 数据 manifest | 文件、字段、阶段、对象、时间、行数和完整性 |
| 图层到数据源映射 | 面板、图元、Renderer、CDS／源表 |
| 原值与显示值关系 | 标准化、裁剪、动态回调和可能损失 |
| 缺失与空值含义 | 有效空、无 occurrence、缺数据、未确认等 |
| 文件哈希 | 可复核身份 |
| 导出日志 | 命令、环境、开始结束和错误 |
| 结果 | 完整／部分／失败／效果未知 |
| 停止原因 | 需要修改图／脚本、权限不足或其他 |

## 6. E 对正式数据的专业判断

### 6.1 图与数据一致性核对

| 字段 | 含义 |
|---|---|
| 脚本／HTML／运行绑定 | 是否对应正式取数准入 |
| 图层与数据源 | 面板、图元、Renderer、CDS／源表是否一致 |
| 字段与身份 | 时间、数值、occurrence 身份和 hover 字段 |
| 对象和时间 | 品种、时间范围、多尺度节点 |
| 数量与完整性 | 行数、对象数、全量／必要范围完整 |
| 数据阶段 | source／postprocessed／construction_snapshot／viewport_final 是否准确 |
| 原值与显示值 | 转换、基准、裁剪及损失是否可解释 |
| 缺失语义 | 有效空、无 occurrence、缺数据、未确认是否区分 |
| 重复业务事件 | 同一 occurrence 多图元未重复计数 |
| 结果 | 一致／限域一致／不一致／无法检查 |
| 专业后继 | 接受／续发 W2／返回 E2／阻塞 |

## 7. 阶段最终输出

| 字段 | 含义 |
|---|---|
| 最终运行脚本 | E 接受的实际可复现脚本 |
| 最终 CAEGraph HTML | E 接受的图 |
| 执行与核图基准 | W1 前置 |
| W1 工单与回报 | 运行、patch 和日志事实 |
| W1 专业评价 | 问题分类和最终图核对 |
| 正式取数准入 | W2 前置 |
| W2 工单与回报 | 正式图数据和导出证据 |
| 图与数据一致性核对 | E 最终专业判断 |
| 已知限制 | 仍存在的边界和影响 |
| 阶段状态 | `DATA_READY`／`PARTIAL_WITH_LIMITS`／`BLOCKED` |
