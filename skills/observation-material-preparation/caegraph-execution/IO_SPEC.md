# E｜字段级输入输出

> 本文件只保留 E 推进所需的最小字段。身份、授权、工作区和 Return 由通用 Worker 工单负责；环境快照、哈希、全量血缘、详细缺失说明等默认不填，只有触发实际需要时再补。

## 1. 阶段输入

| 字段 | 必填 | 含义 |
|---|---:|---|
| D 完整 CAEGraph 脚本 | 是 | W1 的实际运行输入 |
| C2 当前预期 HTML | 是 | 最终图核对基准 |
| 工作区／运行入口 | 是 | Worker 能直接运行的位置或命令 |
| 输出目录 | 是 | 脚本、HTML、数据和日志位置 |
| 特征实例与 B 位置引用 | 是 | 已由 D 绑定，供 E 核对 |
| 操作授权引用 | 是 | 指向通用 Worker 工单／Owner 授权，不在本文件重抄 |

## 2. E1｜最小执行与核图基准

| 字段 | 含义 |
|---|---|
| D 脚本引用 | 唯一运行输入 |
| C2 预期 HTML 引用 | 核图依据 |
| 工作区／运行入口 | W1 怎样开始实际运行 |
| 输出目录 | HTML、日志和脚本输出位置 |
| W1 可直接修范围 | 机械问题的简短列表 |
| 必须返回事项 | 位置、展示、绑定或无法判断的问题 |

该记录应能在一小段文字或一张短卡内完成，不另写长报告。

## 3. W1 短执行卡与回报

### 3.1 W1 输入

| 字段 | 含义 |
|---|---|
| 通用工单引用 | 身份和授权来源 |
| D 完整脚本 | 要运行的文件 |
| 工作区与运行命令 | 实际入口 |
| 输出目录 | 候选 HTML 和日志位置 |

### 3.2 W1 最小回报

| 字段 | 含义 |
|---|---|
| 状态 | `SUCCESS / PARTIAL / BLOCKED / EFFECT_UNKNOWN` |
| 最终脚本 | path 或 commit |
| 候选 HTML | path；没有则写无 |
| 运行日志 | path |
| 实际修改 | `git diff` 引用；没有则写无 |
| 当前阻断 | 首个真实阻断；没有则写无 |

### 3.3 条件补充

仅在触发时增加：

- 环境／数据版本：仅当它导致差异、失败或无法复现；
- patch 解释：仅当 `git diff` 不能说明是否影响业务语义；
- 重复／效果未知记录：仅当需要先对账。

## 4. E2／E3｜候选运行评价和最终图核对

| 字段 | 含义 |
|---|---|
| 是否生成可打开 HTML | 是／否 |
| 首个真实阻断 | 没有则写无 |
| D 输入是否保持 | 实例、位置、字段和数据入口 |
| diff 是否在授权内 | 是／否／待判断 |
| 问题性质 | B 位置／C 展示／D 集成／机械问题／无法分类 |
| 与 D 核对结果 | 通过／限域／返回／阻塞 |
| 与 C2 核对结果 | 通过／限域／返回／阻塞 |
| 被接受的脚本和 HTML | path／commit |
| 接受范围与限制 | 本次正式取数的有效范围 |

## 5. E4｜最小正式取数准入

| 字段 | 含义 |
|---|---|
| 被接受的最终脚本 | path／commit |
| 被接受的最终 HTML／运行 | path／运行引用 |
| 导出清单 | 图层／对象及需要的数据阶段 |
| 输出目录 | 数据文件位置 |
| 禁止修改 | 脚本、图、位置、字段和展示语义 |

默认不要求：全部数据阶段、完整血缘、所有文件哈希或完整环境快照。

## 6. W2 短执行卡与回报

### 6.1 W2 输入

| 字段 | 含义 |
|---|---|
| 通用工单引用 | 身份和授权来源 |
| 最终脚本 | 已接受版本 |
| 最终 HTML／运行 | 已接受结果 |
| 导出清单 | 本次只导出这些内容 |
| 输出目录 | 数据文件位置 |

### 6.2 W2 最小回报

| 字段 | 含义 |
|---|---|
| 状态 | `SUCCESS / PARTIAL / BLOCKED / EFFECT_UNKNOWN` |
| 数据文件 | 实际文件列表 |
| 最小映射 | `图层／对象 → 文件 → 数据阶段 → 行数` |
| 未取得项 | 项目及原因；没有则写无 |
| 导出日志 | path |

### 6.3 条件补充

仅在触发时增加：

- Renderer／CDS／源表血缘：下游明确需要或图数据不一致；
- `viewport_final`：本轮明确需要浏览器回调后的值；
- 原值／显示值关系：转换影响本轮判断；
- 缺失语义：空值或缺失影响本轮判断；
- 文件哈希：任务明确要求、文件不受版本库管理或身份有争议。

## 7. E5｜必要的一致性核对

| 字段 | 含义 |
|---|---|
| 是否绑定已接受脚本／HTML／运行 | 是／否 |
| 图层／对象与文件是否对应 | 是／否／限域 |
| 数据阶段是否正确 | 是／否／不适用 |
| 品种、时间和行数是否合理 | 是／否／需说明 |
| 影响本轮判断的缺失／转换 | 没有则写无 |
| 结果 | 一致／限域一致／不一致／无法检查 |
| 后继 | 接受／重试 W2／返回 E2／阻塞 |

## 8. E6｜阶段最终输出

| 字段 | 含义 |
|---|---|
| 最终脚本 | E 接受的脚本 |
| 最终 HTML | E 接受的图 |
| W1 最小回报 | 状态、日志、diff、阻断 |
| 最终图核对 | 与 D／C2 的结果 |
| 正式取数准入 | E4 最小记录 |
| W2 数据文件和最小映射 | 正式数据事实 |
| 必要一致性核对 | E5 结果 |
| 已知限制 | 对下游用途的影响 |
| 阶段状态 | `DATA_READY / PARTIAL_WITH_LIMITS / BLOCKED` |
