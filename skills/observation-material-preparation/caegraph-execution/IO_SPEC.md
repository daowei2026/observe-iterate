# E｜字段级输入输出

## 1. 阶段输入

| 字段 | 必填 | 含义 |
|---|---:|---|
| D 完整 CAEGraph 定义 | 是 | 冻结的定义版本、脚本和绑定表 |
| C 预期展示 HTML | 是 | 最终图核对基准 |
| 特征实例 | 是 | 外层给定的实际实例 |
| 运行环境引用 | 条件 | 若不能从实例／D 解析，则必须补充或阻塞 |
| 输出目录 | 是 | 脚本、HTML、数据、日志和核对结果的目标位置 |

## 2. Worker 派单

| 字段 | 含义 |
|---|---|
| 派单编号 | 本次执行身份 |
| D 定义版本 | 唯一输入版本 |
| 脚本引用 | 要运行的完整脚本 |
| 特征实例与数据入口 | 实际运行对象 |
| 品种和时间 | 从 B／D 继承，不由 Worker 修改 |
| 运行环境 | 工作区、依赖和必要上下文 |
| 输出要求 | 初步 HTML、日志、错误、最终产物位置 |
| 可自主修改范围 | 明确允许的确定性修复 |
| 必须返回的改动 | 会影响位置、展示或绑定的事项 |
| 成本和停止条件 | 高成本、不可逆或失败时如何停 |

## 3. Worker 运行与修改记录

### 3.1 运行记录

| 字段 | 含义 |
|---|---|
| 运行编号 | 唯一执行身份 |
| 输入定义版本 | 对应 D |
| 实际脚本版本 | 本次运行脚本 |
| 开始与结束时间 | 执行时间 |
| 环境与数据版本 | 实际使用内容 |
| 结果 | 成功／部分／失败／效果未知 |
| HTML 引用 | 生成文件 |
| 日志引用 | 标准输出、错误和运行记录 |
| 未解决问题 | 需要返回的事项 |

### 3.2 修改记录

| 字段 | 含义 |
|---|---|
| 修改编号 | 稳定编号 |
| 文件与位置 | 被修改内容 |
| 修改前 | 原定义／代码 |
| 修改后 | 最终内容 |
| 修改原因 | 错误或兼容问题 |
| 权限依据 | 派单中的授权范围 |
| 是否改变业务语义 | 否／是／待判断；后两者不得自行接受 |
| 返回目标 | B／C／D／不适用 |

## 4. 最终图核对

### 4.1 与 D 定义核对

| 字段 | 含义 |
|---|---|
| 核对项 | 实例、品种、时间、字段、面板、图元、转换、输出路径等 |
| D 预期 | 定义中的内容 |
| 最终实际 | 最终脚本／图中的内容 |
| 差异 | 具体差异 |
| 是否在授权范围 | 是／否 |
| 处理结果 | 接受／返回 B／C／D／阻塞 |

### 4.2 与 C 预期 HTML 核对

| 字段 | 含义 |
|---|---|
| 核对项 | 面板结构、主附图、图元语义、事件位置、多品种组织、图例／hover 等 |
| 预期展示 | C 的定义和 HTML |
| 最终展示 | 实际 HTML |
| 差异 | 结构或语义差异 |
| 是否属于真实数据允许变化 | 是／否 |
| 处理结果 | 接受／返回 C／阻塞 |

### 4.3 最终图接受记录

| 字段 | 含义 |
|---|---|
| 最终脚本版本 | 被接受的脚本 |
| 最终 HTML 引用 | 被接受的图 |
| D 核对结果 | 引用 |
| C 核对结果 | 引用 |
| 接受范围与限制 | 对本次用途的有效范围 |
| 是否允许正式取数 | 是／否 |

## 5. CAEGraph 图数据包

| 字段 | 含义 |
|---|---|
| 数据包编号 | 唯一身份 |
| 最终脚本／HTML／定义版本 | 三者绑定 |
| 特征实例 | 实际实例 |
| 品种和时间范围 | 实际观察位置 |
| 数据文件清单 | 源、后处理、构图 CDS、视窗最终值等 |
| 每项数据阶段 | source／postprocessed／construction_snapshot／viewport_final |
| 图层与数据源映射 | 面板、图元、Renderer、CDS／源表关系 |
| 原值与显示值关系 | 转换、基准、裁剪和可能损失 |
| 数据量 | 行数、时间范围和对象数 |
| 缺失与空值含义 | 有效空、无 occurrence、缺数据、未确认等 |
| 完整性 | 完整／必要范围完整／部分／失败 |
| 文件与校验引用 | 路径、哈希或仓库引用 |

## 6. 图与数据一致性核对

| 字段 | 含义 |
|---|---|
| 核对项 | 图层、字段、品种、时间、数量、转换、图例等 |
| 图中实际 | 最终 HTML／模型中的内容 |
| 数据包实际 | 正式导出内容 |
| 结果 | 一致／不一致／无法检查 |
| 影响与处理 | 返修、限域接受或阻塞 |

## 7. 阶段最终输出

| 字段 | 含义 |
|---|---|
| 最终运行脚本 | 实际可复现脚本 |
| 最终 CAEGraph HTML | 通过核对的图 |
| CAEGraph 图数据包 | 正式导出数据及元信息 |
| Worker 运行和修改记录 | 全部执行证据 |
| D 核对结果 | 防止越权修改 |
| C 核对结果 | 展示结构和语义检查 |
| 图与数据一致性核对 | 最终一致性检查 |
| 已知限制 | 仍存在的边界 |
| 阶段状态 | `DATA_READY`／`PARTIAL_WITH_LIMITS`／`BLOCKED` |
