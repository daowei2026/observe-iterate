# E｜字段级输入输出（Codex 直接执行）

> 保留原专业 E1～E6 的输入、图接受及正式取数边界。执行操作不经单独 W1/W2 工单；机读 C/D、Owner 权限和真实回执依长程 V2 协议。

## 1. 阶段输入

| 字段 | 必填 | 含义 |
|---|---:|---|
| FeatureUnderstandingPackage | 是 | 本次 Feature 的对象、事件、状态、字段及处理关系共享语义基准 |
| D 完整 CAEGraph 定义与脚本 | 是 | 唯一正式执行输入及已确定的上游集成 |
| C2 当前展示预期和唯一预期 HTML | 是 | E3 的专业核图基准 |
| 外层特征实例与 B 位置 | 是 | 已由 D 正式绑定的真实对象与范围 |
| 工作区、实际运行入口、输出位置 | 是 | Codex E 可直接定位与执行的场所 |
| Owner/D 操作授权与锁定版本 | 是 | 真实操作边界，独立于专业结果 |

## 2. E1｜最小执行与核图基准

保留 D/C2/实例/位置的精确引用、真实入口、输出位置、授权及已知必要前置；不要求预先形成完整环境报告。E1 基准内容变化时须标记旧候选结果是否失效。

## 3. 直接运行与工程修复事实（E2）

| 字段 | 含义 |
|---|---|
| 运行结果 | 实际成功、部分、阻断或效果未知 |
| 最终脚本和运行 | path/版本、实际命令与入口、日志和退出状态 |
| 候选 HTML | path；未生成写无 |
| 实际修改 | git diff 或 run-local patch；无修改写无 |
| 当前错误及修复证据 | 实际问题、权限内尝试、剩余阻断 |
| 专业分类与后继 | 可继续工程处理／返回共享理解或 B、C、D／请求授权／阻塞 |

不以每次诊断重新签 W。环境和数据版本、详细来源与哈希仅在影响可复现性、语义、权限或出现真实问题时展开。

## 4. E3｜最终图核对与接受

| 字段 | 含义 |
|---|---|
| 与 D 核对 | 实例、位置、字段、数据入口和所有 diff |
| 与 C2 核对 | 页面、主附图、图元、时间/业务语义、hover、必要中间结果 |
| 实际视觉/图层核验证据 | 渲染图、截图或可核查数据；无法完成的范围须说明 |
| 结果 | 接受／限域接受／返回 B/C/D／阻塞 |
| 已接受版本 | 最终脚本、HTML、有效运行引用及接受范围 |

## 5. E4｜正式取数准入与直接导出

只有 E3 有效接受后才形成：已接受脚本/HTML/运行及对应 D/C2 版本、需要的图层/对象、适用的数据阶段（source / postprocessed / construction_snapshot / viewport_final）、输出目录和禁止修改的图定义/业务语义。

直接导出所得最小事实：正式文件列表；`图层／对象 → 文件 → 数据阶段 → 行数` 映射；未取得项与原因；必要的导出日志。不得用候选调试表、预览或显示反推值代替正式数据。

## 6. E5｜必要的一致性核对

核对正式文件是否绑定已接受脚本/HTML/运行，图层/对象与文件及数据阶段是否对应，品种/时间/行数是否合理，本轮判断涉及的缺失/裁剪/转换是否有解释。结果为一致／限域一致／不一致／无法检查，后继为接受／重新导出／返回 E2／阻塞。

## 7. E6｜最终交付

| 字段 | 含义 |
|---|---|
| 最终脚本与 HTML | 实际接受的可复现成果 |
| 运行与修复证据 | 真实日志、diff、错误及处理 |
| E3 图核对 | 与 D/C2 的接受范围与视觉/数据证据 |
| E4 正式取数准入 | 已接受版本和数据选择 |
| 正式数据及最小映射 | 实际文件、阶段、图层、行数 |
| E5 核对 | 本次必要的一致性结论 |
| 限制与剩余工作 | 对下游用途的实际影响 |
| E 阶段状态 | `DATA_READY / PARTIAL_WITH_LIMITS / BLOCKED` |

没有独立 W 工单或 Worker Return 不是缺项；但缺少真实图核对、正式取数和一致性核对时不得声称 DATA_READY。
