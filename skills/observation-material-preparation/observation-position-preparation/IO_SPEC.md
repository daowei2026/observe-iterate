# B｜字段级输入输出

> B 当前采用经验性默认值和既有高频多尺度位置层级，不声称已有通用案例选择模型。

## 1. 阶段输入

| 字段 | 必填 | 含义 |
|---|---:|---|
| 特征实例 | 是 | 外层 Workflow 给定的实例或实例引用；SOF 由该实例确定 |
| FeatureUnderstandingPackage 引用 | 是 | 与实例一致的对象、事件、状态及事件发生位置说明；用于位置范围和多尺度节点对齐 |
| 任务明确指定的位置 | 否 | 若任务已给品种和时间，优先使用 |
| 位置用法 | 是 | `普通默认`／`高频多尺度`／`任务明确指定` |

## 2. 普通位置定义

| 字段 | 必填 | 含义 |
|---|---:|---|
| SOF 引用 | 是 | 直接引用特征实例已绑定的 SOF；B 不修改 |
| 品种集 | 是 | 默认钢铁板块；任务明确指定时使用指定值 |
| 开始时间 | 是 | 默认 `2021-01-01` |
| 结束时间 | 是 | 默认 `2022-12-31`；边界解释由 D 的日历／PlotSet 绑定确定 |
| 位置来源 | 是 | 当前默认／任务明确指定 |
| 缺口与限制 | 否 | 默认位置在当前实例中不可用时说明 |

## 3. 高频多尺度位置定义

| 字段 | 必填 | 含义 |
|---|---:|---|
| SOF 引用 | 是 | 特征实例已经绑定的 SOF |
| 品种集 | 是 | 本次多尺度观察使用的对象集合 |
| 位置路径编号 | 是 | 一条 1d→30m→1m→5s→tick 路径的稳定编号 |
| 1d 概览范围 | 是 | 长期概览时间范围或其引用 |
| 30m 节点 | 是 | 大尺度节点身份及时间范围 |
| 1m 节点 | 条件 | 30m 节点下选中的中尺度子节点及时间范围 |
| 5s 节点 | 条件 | 1m 节点下选中的小尺度子节点及时间范围 |
| tick 节点 | 条件 | 5s 节点下选中的 tick 子节点及时间范围 |
| 父子关系引用 | 是 | 节点间 `parent_node_id` 关系或等价引用 |
| 方法来源 | 是 | [高频多尺度观察位置参考](MULTISCALE_POSITION_REFERENCE.md) 及实际脚本版本 |
| 缺口与限制 | 否 | 缺少某层节点、时间或数据时说明 |

## 4. 阶段最终输出

| 字段 | 含义 |
|---|---|
| 位置用法 | 普通默认／高频多尺度／任务明确指定 |
| 普通位置或多尺度位置路径 | D 可直接绑定的位置产物 |
| 特征实例与 SOF 引用 | 证明位置属于哪个实际实例 |
| FeatureUnderstandingPackage 引用 | 证明位置与哪个对象／事件理解版本对齐 |
| 来源说明 | 默认约定、任务明确输入或高频参考脚本 |
| 未完成位置 | 无法应用当前用法的范围及原因 |
| 阶段状态 | 完整／部分完整／阻塞 |

B 不输出合理性正式案例集。图完成后的正例、负例、误报、漏报、参数边界和覆盖外场景由合理性 Skill 1 选择。
