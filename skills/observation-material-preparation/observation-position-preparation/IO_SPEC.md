# B｜字段级输入输出

> 字段名称先采用中文。多层数据位置字段等待 Owner 提供方法后补充，本文件不提前猜测。

## 1. 阶段输入

| 字段 | 必填 | 含义 |
|---|---:|---|
| 特征实例 | 是 | 外层 Workflow 给定的实例或实例引用 |
| A 阶段产物引用 | 是 | 事件、事件发生位置和处理关系说明 |
| 实例 occurrence／索引入口 | 否 | 已有公开读取结果、索引或查询入口；可由特征实例解析 |
| 本次位置选择对象 | 否 | 如任务已经明确要围绕某类主输出或现象选位置则填写；否则在 B2 形成 |

## 2. 普通观察位置定义

| 字段 | 必填 | 含义 |
|---|---:|---|
| 位置编号 | 是 | 本阶段内部稳定编号 |
| 特征实例引用 | 是 | 该位置属于哪个实例 |
| 品种集 | 是 | CAEGraph 需要绑定的品种／对象集合 |
| 开始时间 | 是 | 观察时间范围起点 |
| 结束时间 | 是 | 观察时间范围终点 |
| 位置选择对象 | 是 | 围绕哪类事件、主输出或处理现象选择 |
| 选择规则 | 是 | 可复核的选择方法；不能只写“典型案例” |
| 选择依据引用 | 否 | 对应 occurrence、查询结果或索引引用 |
| 位置核实状态 | 是 | 已核实／部分核实／无法取得 |
| 缺口与限制 | 否 | 位置中缺失的数据、事件或上下文 |

## 3. 多层数据位置定义

当前仅保留：

| 字段 | 必填 | 含义 |
|---|---:|---|
| 是否为多层位置 | 是 | 是／否 |
| 多层位置方法版本 | 条件 | 采用 Owner 后续提供的专门方法时填写 |
| 多层位置内容 | 条件 | 具体字段待专门方法确定 |
| 未补齐原因 | 条件 | 方法尚未提供或本次无法应用时说明 |

在专门方法落地前，不得用本占位字段声称多层位置已经完成。

## 4. 阶段最终输出

| 字段 | 含义 |
|---|---|
| 观察位置定义列表 | 一项或多项普通／多层位置定义 |
| 特征实例引用 | 所有位置对应的实际实例 |
| 核实记录 | 位置存在性、数据范围和 occurrence 覆盖的检查 |
| 未完成位置 | 因数据或方法缺失尚未形成的位置 |
| 阶段状态 | 完整／部分完整／阻塞 |
