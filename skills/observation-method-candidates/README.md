## 方法选择速查

| 问题触发条件（不是图元类型） | 使用哪一候选 | 保持的核心业务关系 | 不应误做 |
|---|---|---|---|
| 同一时间背景下，多套方案各自产生的**同类事件流**要比较发生位置、方向、疏密或强度 | **S1 高频：多组事件序列同口径比较** | 事件与真实方案/参数身份；统一时间口径；原值与显示值 | 不因图例重号认错参数；不同语义强度不可直接比较；截断后的值非原值 |
| 某段历史用来形成选择，选择之后又用于过滤/切换事件 | **S2 高频：评价依据、判断已知、应用时段分离** | 历史评价段、选择事实、选择何时已知、实际何时应用 | 不把绘于历史段的横线当作当时已知；没有 trace 不推断精确生效次序 |
| 同一业务对象有实际位置、代表位置、确认/完成位置等 | **S3 高频；EAW E2 是另一实例** | 一个对象可在多个时间角色上有多个图标，但**仍是一个业务对象** | 不把多图元算多个事件；事后回指不等于当时已知 |
| 局部窗口下多个价格层需有一致价格基准 | **S4 高频；EAW E4 是另一实例** | 加载范围、可见范围、锚点、价格实体、动态/静态处理阶段 | ratio 不等于百分比涨幅；非价格字段不能跟随；不同品种不能用同一绝对价格数 |
| **同一份判断结果**包含多种互相竞争的语义支持度、差额，要看彼此区别与重合 | **E1 新候选：同一判断的竞争支持度对照** | 同一个判断/阶段的各支持度及差额，同值重叠也不能丢失 | 不能等同多套参数方案事件流 S1；差额不是第四类支持度 |
| 某个离散判断位置需要与不同频率的 K 线在同一时间背景中对照 | **E3 待核新候选：事件与多分辨率行情共时观察** | 事件时点与 K 线时间**区间**、各尺度窗口、实际 K 线粒度 | K 线图元中心 x 不能代替 bar 起止；不同 CAEGraph 页不自动完全同窗 |

**S1 与 E1 不应强行合并**：前者比较多套方案产出的事件序列，后者比较一个判断里的竞争语义分量。共用某些绘图技巧不足以证明专业方法同一。

**S2 与 S3 不应强行合并**：S3 关注一个对象的多时间角色；S2 还必须回答历史依据怎样形成结论、何时应用到后续事件。EAW 的锚/确认图仅能支撑 S3，不能自动算 S2 的验证。

## “方法”与“落地”的分层描述

每次套用具体方法，单独记录三个方面，避免用具体画法反向定义专业方法：

1. **业务来源与输入数据**：是什么特征/实例/字段、有什么身份和时间含义；
2. **特征之后的观察数据处理**：原字段直接使用、FeatDFProcessor/FeatADTProcessor 或其他变换；是否丢失信息；
3. **CAEGraph 定义/运行**：PlotSet、主/附图、点/柱/线段图元、参数、图例/标题、动态窗口行为。

- [高频原 Notebook cell 9](https://github.com/daowei2026/viewer/blob/e6.2/frp/同步(多对象)/密集与板块密集的简单标准化.ipynb)提供 S1–S4 的原图组合证据。
- [CAEGraph 使用手册](https://github.com/daowei2026/uplot/blob/e6.2/CAEGraph使用手册.md)提供参数与组件用法，**不负责决定业务上应该观察什么**。
- [EAW 专题来源](eaw/EAW_CAEGraph观察准备Skill候选_原图落地与复用边界_20261112.md)区分 T056 真正 CAEGraph、T059 剩余 CAEGraph 和正式看板；非 CAEGraph/Bokeh 的 EAW 专属计算不得混入该索引。

## 什么时候不使用上述候选

不满足其专业输入条件时，保持问题原样：先看 CAEGraph 既有完整用例 → 修改参数/组合现成绘图类 → 使用特征后数据处理或简单函数 → 如确有必要提出新组件/新平台能力。记录新处理的使用理由和取数验证；**暂时只叫本次新配方，不凭一例自动命名为成熟 Skill**。

## 方法成熟度怎样更新

每项独立记录四种证据：
- **方法成立**：能说清触发问题、核心不变关系、反例/不适用条件；
- **实现可用**：相关构图/处理代码已核对且在实际版本运行；
- **真实取数可用**：按所需窗口、字段、身份获得实际材料，并完成对照；
- **跨例复用**：第二实例只改变对象/字段/策略等可变部件，无需改写核心解释。

不把“第二份文档出现同名方法”自动等同于全部四项成熟。
